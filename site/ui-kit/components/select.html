Триггер · закрытое состояние .select / .select--sm
Список рендерится через .select-popup — см. ниже
Когда <select>, а когда .select-popup: нативный <select> рендерит выпадающий список средствами ОС/браузера — это нельзя стилизовать (цвет выбранной строки, шрифт, отступы зависят от системной темы). Поэтому для основного UI используем .select-popup с триггером-кнопкой .select. Нативный <select> оставляем только для коротких фильтров и read-only/disabled случаев, где визуал списка не критичен — color-scheme: light + accent-color на .select приведут его к светлой теме и primary-подсветке выбранной строки.
