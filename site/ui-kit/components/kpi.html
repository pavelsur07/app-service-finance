Best practice
Акцент — для метрик с явным направлением: success = поступления / прибыль, danger = списания / убытки, warning = требует внимания / на согласовании, primary = нейтральный итог / общий счётчик.
.kpi-units идёт сразу после .kpi-value — крупная сумма + количество операций, которые её сформировали. Число — <b> (strong), единица измерения приглушённая.
Не комбинируй .kpi--accent-* с .kpi--dark — hero-карточка ведёт визуально сама.
Не дублируй акцентом то, что уже передаёт .delta--up/--down — это разные слои информации.
Цвет — только из токенов --success-dot, --danger-dot, --warning-dot, --color-primary. Никаких новых hex.
.kpi-head — обёртка над .kpi-label, когда карточке нужен .status. Метка слева, пилюля справа, прижаты к верхнему краю карточки.
Семантика акцентной полосы и пилюли должна совпадать (--accent-success + .status--success), либо пилюля — нейтральная (.status--neutral) когда нужен только тэг состояния, не направление.
Не ставь больше одной пилюли в .kpi-head — для нескольких атрибутов используй обычный ряд статусов под значением.
