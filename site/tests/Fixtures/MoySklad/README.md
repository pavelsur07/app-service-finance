# Ответы МойСклад для тестов

## Контрагенты

Файлы `Counterparty/*.json` получены из ответов `GET /entity/counterparty`
JSON API 1.2 тестового аккаунта 2026-09-20. Использовались
`Accept: application/json;charset=utf-8`, `limit=2`, `order=id,asc` и
явный `filter=archived=false|true`. Запрос без фильтра на этом аккаунте
не возвращал архивные записи.

| Файл | Выборка |
| --- | --- |
| `counterparties_active_page_0.json` | Активные, `offset=0`; две организации. |
| `counterparties_active_page_2.json` | Активные, `offset=2`; ИП и физическое лицо с различающимися наборами реквизитов. |
| `counterparties_active_empty.json` | Активные, пустая страница за концом выборки. |
| `counterparties_archived_page_0.json` | Архивные, `offset=0`; два контрагента. |
| `counterparties_archived_empty.json` | Архивные, пустая страница за концом выборки. |

Сохранены все ключи, вложенность, типы JSON, признаки `archived`, коды
`companyType`, формат дат и метаданные страниц. Идентификаторы, имена,
контакты, адреса, реквизиты, коды и прочие текстовые значения заменены
тестовыми; числовые бизнес-значения обнулены. `meta.size` и `meta.offset`
оставлены как в ответах: это отдельные образцы страниц, а не полный
непрерывный набор для воспроизведения всех страниц аккаунта.

Каталог `captured/` игнорируется Git; сырые ответы удалены после проверки
обезличенных копий. Фикстуры не содержат токен и не требуют сетевого доступа
при запуске тестов.

## Товары и модификации

Файлы `Product/*.json` и `Variant/*.json` получены из ответов
`GET /entity/product` и `GET /entity/variant` JSON API 1.2 тестового
аккаунта 2026-09-20. Использовались `Accept: application/json;charset=utf-8`,
`Accept-Encoding: gzip`, `limit=2`, явный `filter=archived=false|true` и
`order=id,asc`. Отдельный запрос модификаций использовал
`filter=productid=<UUID товара>`.

| Файлы | Выборка |
| --- | --- |
| `Product/products_active_page_0.json`, `products_active_page_2.json`, `products_active_empty.json` | Активные товары: страницы с `offset=0`, `2` и пустая с `offset=1340`; `meta.size=1340`. |
| `Product/products_archived_page_0.json`, `products_archived_page_2.json`, `products_archived_empty.json` | Архивные товары: страницы с `offset=0`, `2` и пустая с `offset=33`; `meta.size=33`. |
| `Variant/variants_active_empty.json`, `variants_archived_empty.json` | Обе архивные выборки модификаций пусты; `meta.size=0`. |
| `Variant/variants_by_product_empty.json` | Фильтр `productid` по товару из первой активной страницы; пустой ответ. |

Сохранены ключи, вложенность, типы JSON, отсутствующие поля, `meta.size`,
`limit`, `offset` и связь синтетического ID товара с фильтром `productid`.
Исходные UUID, названия, коды, штрихкоды, значения дополнительных полей,
даты и коммерческие числа заменены тестовыми. Фикстуры являются отдельными
образцами страниц, а не всем списком из 1340 и 33 товаров. В тестовом
аккаунте нет модификаций, поэтому непустой ответ и ссылку `variant.product`
эти файлы не покрывают. Сырые ответы удалены после сверки; токен в фикстуры
не записывался.

`Variant/variants_documented_page_0.json` — синтетический непустой образец
по документированной схеме API 1.2. В тестовом аккаунте модификаций нет;
этот файл не является живым ответом.

## Склады и остатки

`Store/stores_active_page_0.json`, `Store/stores_archived_page_0.json` и
`Stock/stock_bystore_page_0.json` — обезличенные синтетические ответы по
официальному контракту JSON API 1.2, ревизия документации
`74f6a4fa1c0021dba2df927bdd688900e97cb736`. Тестовый ключ, доступный во время
подготовки, возвращал 401, поэтому эти файлы не обозначаются как живые ответы.

`Stock/stock_bystore_live_page_0.json` и
`Stock/stock_bystore_live_page_2.json` — обезличенные реальные ответы
`GET /report/stock/bystore`, снятые 23.09.2026 с `limit=2` для первой и
последней страниц. Сохранены фактическая вложенность, набор полей и query-часть
`?expand=...` в `meta.href`. UUID, названия складов, количества, размер выборки
и смещения заменены согласованными тестовыми значениями; сырой ответ и токен в
Git не попадают.

Фикстуры покрывают активные и архивные склады, товар и модификацию, несколько
складов, нулевой, отрицательный и дробный остаток, резерв и товар в пути.
UUID, названия, коды и количества являются тестовыми. Токенов, контактов,
адресов, цен и произвольного исходного JSON в файлах нет.
