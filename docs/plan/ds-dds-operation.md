## 1. Аудит (кратко, полностью — `stages/stage-0.md`)
- Страница — `cash_transaction_edit`, шаблон `transaction/edit.html.twig`,
  форма `CashTransactionType` (общая с созданием), сохранение —
  `UpdateCashTransactionAction`. IDOR закрыт (`findOneByIdAndCompanyId`).
- Статьи ДДС — дерево по `parent_id`, глубина не ограничена; направление
  статьи — `operationType` (наследуется от родителя), системные
  `CF_TECH_IN/OUT`. «Не распределено» — пустое значение.
- Удаление — soft delete, связь с документами ОПиУ **не снимается**;
  восстановление есть.
- Источник операции — `importSource` (`alfa`, `file`, `telegram`), выписка 1С —
  `externalId` без `importSource`.
