## Решения Владельца (вне рамок — PHP)

1. **Поиск не находит кириллицу с заглавной.** `findByFilters` понижает запрос `strtolower`, а он
   с PHP 8.2 понижает только ASCII: «Альфа» не находит «Альфа-Банк», «альфа» — находит.
   Исправление — `mb_strtolower` в одной строке репозитория + регрессионный тест (XS).
2. **Пагинация** — сделана 2026-10-13 (ветка `feat/counterparty-pagination`): Pagerfanta по 50,
   `?page&limit` (лимит 1–200, неверные `page`/`limit` и несуществующая страница — 422, как
   `settings_api_index`), сортировка «название, id», «Найдено N» — `pager.nbResults`, «из них в
   архиве K» — отдельный COUNT по тем же фильтрам; партиал `partials/_pagination` в подвале
   карточки; смена фильтра сбрасывает страницу. Поиск с заглавной кириллицей исправлен в #2665.

## Ревью

Внутреннее в свежем контексте: BLOCKER 0, IMPORTANT 1 — фокус после закрытия диалога падал на
`body` (Bootstrap возвращает его только видимому триггеру, а пункт меню скрыт) → возвращается на
«⋯» строки. MINOR исправлены: отступ Tabler слева от переключателя; пустое состояние при одном
«Показывать архив» было «Ничего не найдено» (переключатель расширяет выборку) → «пока нет»;
«Найдено 0» над «пока нет» убрано; кнопка подтверждения `disabled`, пока JS не заполнил форму;
`role=menu/menuitem` у меню строки; hover у архивного названия; тип — приглушённым текстом.
`_confirm_modal` добавлен в список партиалов легаси в `CLAUDE.frontend.md`.

FOLLOW-UP (не в этой задаче): кнопки «Добавить / Редактировать / В архив» видны и без
`FINANCE_WRITE` (POST вернёт 403) — так было и до; неверный CSRF при архивации молча редиректит
без flash (PHP); поиск строки «0» игнорируется (`if ($q)` в репозитории).
