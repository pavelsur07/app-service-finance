## Решения Владельца (вне рамок — PHP)

1. **Поиск не находит кириллицу с заглавной.** `findByFilters` понижает запрос `strtolower`, а он
   с PHP 8.2 понижает только ASCII: «Альфа» не находит «Альфа-Банк», «альфа» — находит.
   Исправление — `mb_strtolower` в одной строке репозитория + регрессионный тест (XS).
2. **Пагинация** — сделана 2026-10-13 (ветка `feat/counterparty-pagination`): Pagerfanta по 50,
   `?page&limit` (лимит 1–200, неверные `page`/`limit` и несуществующая страница — 422, как
   `settings_api_index`), сортировка «название, id», «Найдено N» — `pager.nbResults`, «из них в
   архиве K» — отдельный COUNT по тем же фильтрам; партиал `partials/_pagination` в подвале
   карточки; смена фильтра сбрасывает страницу. Архивация и возврат возвращают на ту же страницу с
   теми же фильтрами (страница ограничивается последней существующей, а не 422). «Сбросить всё»
   сбрасывает и нестандартный `limit` — намеренно. Поиск с заглавной кириллицей исправлен в #2665.
   Не сделано: «Отмена»/сохранение формы редактирования возвращают на первую страницу без фильтров
   (как и до пагинации); индекс `(company_id, name, id)` — только если у компании ~10 тыс. контрагентов.

## Ревью

Внутреннее в свежем контексте: BLOCKER 0, IMPORTANT 1 — фокус после закрытия диалога падал на
`body` (Bootstrap возвращает его только видимому триггеру, а пункт меню скрыт) → возвращается на
«⋯» строки. MINOR исправлены: отступ Tabler слева от переключателя; пустое состояние при одном
«Показывать архив» было «Ничего не найдено» (переключатель расширяет выборку) → «пока нет»;
«Найдено 0» над «пока нет» убрано; кнопка подтверждения `disabled`, пока JS не заполнил форму;
`role=menu/menuitem` у меню строки; hover у архивного названия; тип — приглушённым текстом.
`_confirm_modal` добавлен в список партиалов легаси в `CLAUDE.frontend.md`.

FOLLOW-UP (не в этой задаче): кнопки «Добавить / Редактировать / В архив» видны и без
`FINANCE_WRITE` (POST вернёт 403) — так было и до; неверный CSRF при архивации молча редиректит
без flash (PHP); поиск строки «0» игнорируется (`if ($q)` в репозитории).

### План

- `CounterpartyDisplayNameSuggestion` (Domain): единственная точка условий показа — правила вернули
  не `null`, отличается от показанного (`displayName ?? name`), источник не `manual`, не в архиве.
- `ApplyCounterpartyDisplayNameAction` / `ResetCounterpartyDisplayNameAction`: предложение
  пересчитывается на сервере из `name`; запись — условным UPDATE в `CounterpartyDisplayNameWriter`
  (компания, `name` как прочитано, источник не `manual`, не архив) с `updated_at`; повтор с тем же
  результатом — успех; `null`, ручное другое, архив, параллельная правка — «Предложение больше не
  актуально» / причина во flash. «Вернуть исходное» — только для `manual`.
- Два однo-action контроллера (`__invoke`, POST, CSRF на id, `FINANCE_WRITE`), редирект на список
  с теми же `q`, `type`, `show_archived`, `page`, `limit`.
- Список: название — `displayName ?? name`; если есть `displayName` — «Исходное: …» приглушённо
  (+ «Вернуть исходное» у ручного); подсказка — вторая строка, warn-тон, одна строка с обрезкой.

### Риски

- Поиск по-прежнему по сырому `name` (и ИНН) — по `display_name` вне объёма; совпадения находятся,
  т. к. правила меняют только ОПФ, кавычки и регистр ФИО.
- «Вернуть исходное» у авто-названия (после массового запуска Владельцем) не даём: следующий запуск
  вернул бы его; для авто — только «Исходное: …».
- Аватары-инициалы из эталона не вводятся (решение §«Отклонения» выше: цвета не токены DS).

### Сделано

- `CounterpartyDisplayNameSuggestion` (Domain) — условия показа и проверки при «Применить».
- `ApplyCounterpartyDisplayNameAction` / `ResetCounterpartyDisplayNameAction` + контроллеры
  `Counterparty\ApplyCounterpartyDisplayNameController` (`POST /counterparties/{id}/display-name/apply`,
  `counterparty_apply_display_name`, CSRF `apply_display_name{id}`) и `…Reset…`
  (`/display-name/reset`, `counterparty_reset_display_name`, CSRF `reset_display_name{id}`);

  `updated_at`. Повтор «Применить» с тем же результатом — успех; своё ручное название другим не
  перезаписывается («Название уже задано вручную»); `null` → «Предложение больше не актуально»;
