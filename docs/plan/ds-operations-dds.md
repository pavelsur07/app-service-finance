## 3. Отклонение от листа: граница полей

Лист DS-Controls: граница поля Navy 300 `#c3c8d6` = **1,67:1** на белом, ниже
WCAG 1.4.11 (3:1 для границ контролов). По поручению на этой странице поля,
select и checkbox получают `#8590a8` (**3,20:1**); декоративные разделители
остаются `#dde1ec`. Глобально значение не меняется: это затронуло бы 143
страницы и требует решения Владельца (follow-up).
