# Перевод нового интерфейса на DS «Ваш Финдир» — план

Дата: 2026-10-12, база — `master` `accc2999`. Документ ничего не меняет в коде.
Эталон — листы `docs/design-system/sheets/` (решение Владельца при выводе кита:
DS — для обоих интерфейсов, CSS нового слоя — только реализация).

## 1. Главный вывод

Новый слой почти целиком красится через токены кита (`assets/styles/kit/tokens/`):
в компонентах и паттернах всего 3 цвета в обход токенов. Поэтому **палитра и шрифт
меняются одним PR для всех ~40 страниц сразу**: подменить значения токенов на DS.
Перевести по палитре один Баланс — значит оставить его внутри шапки и сайдбара
старого цвета, это хуже, чем сразу всё.

Содержимое страниц (деньги, даты, вкладки, пагинация, статусы) переводится по модулям.
**Баланс — первый и самый крупный модуль (21 шаблон)**, на нём отрабатываются
компоненты для остальных.

(`pages/marketplace-coverage.css`). Смена токенов затронет и её, и это ожидаемо.

## 3. Расхождения с DS

### 3.1 Токены (`kit/tokens/*.css`)

| Токен кита | Сейчас | DS |
|---|---|---|
| `--color-primary` / `-hover` | `#1A56DB` / `#1E40AF` | Action blue `#1d4ed8` / `#1a40b0` |
| `--color-primary-tint` | `#EEF3FE` | Blue 50 `#e8effd` |
| `--text-strong` | `#0B1220` | Navy 900 `#0b1020` |
| `--text-secondary` / `--text-tertiary` / `--text-muted` | `#475569` / `#64748B` / `#8B95A7` | muted `#525b78`; шкала Navy |
| `--border` / `--border-hover` | `#E8ECF3` / `#D8DEE8` | `#dde1ec` / `#c3c8d6` |
| `--bg-page` | `#F4F6FA` | `#f7f8fc` |
| `--danger-text/bg/border` | `#B91C1C` / `#FEF2F2` / `#FECACA` | `#9a001b` / `#fdecee` / `#f0c2c9` |
| `--success-text/bg` | `#047857` / `#ECFDF5` | OK `#1d7a30` / `#e4f5e7` |
| `--warning-text/bg` | `#92400E` / `#FFFBEB` | Warn `#9a4a00` / `#fff4e5` |
| info | нет | `#164f94` / `#e3eefb` |
| `--font-family` | Manrope | Inter (как в легаси) — **решение Владельца №1** |
| Таблица: шапка | `#FAFBFD`, 10,5 px | `#f4f6fb`, 11 px uppercase |

Цвета банков, маркетплейсов, категорий и источников — фирменные, не меняются.

### 3.2 Компоненты кита

- `money.css`: `.money--out` красный, а по DS красный у сумм запрещён, расход — обычный цвет.
- Кнопки, бейджи, алерты, поля, модалки — привести к листам DS-Controls и DS-Feedback.
  Классы не трогать, правится только CSS.
- Вкладок и пагинации по DS в ките нет — нужны новые партиалы для нового слоя
  (`app/_ui/_tabs`, `app/_ui/_pagination`) на листах DS-Tabs и DS-Table.

### 3.3 Баланс — содержимое

| Что | Сейчас | По DS |
|---|---|---|
| Суммы | `format_minor_currency`: обычный пробел, дефис-минус, «₽» в каждой ячейке | `vf_minor` + `vf_amount`: U+00A0, U+2212, приглушённые копейки, «₽» в заголовке колонки (у книги одна валюта) |
| Выравнивание сумм | часть колонок не вправо (документ, ведомость: заголовки) | все суммы и их заголовки вправо |
| Разделы (9 штук) | ряд кнопок `btn-secondary` с `aria-current` | вкладки DS; больше 6 → «Ещё» (**решение №3**) |
| Пагинация | «Назад · Страница X из Y · Вперед» | кнопки 30 px, шевроны, «Показано с X по Y из N» |
| Статусы документа | текст «Черновик / Проведен · Сторнирован» | бейджи DS (нейтральный / OK / Warn) |
| Даты | сырые из БД: `2026-10-12`, `posted_at` с секундами | `дд.мм.гггг`, время `дд.мм.гггг чч:мм` |
| Актив / Пассив / Расхождение | `h2` + `p` в карточках | KPI-карточки до копейки (Баланс без сокращений); ненулевое расхождение — красным, с пояснением, какая сторона больше (**решение №4**) |
| Пустые состояния | местами голый текст в `card` | пустая таблица — строка-пояснение по центру (`td.t-empty`), пустой отчёт — empty state DS |

Не меняются: маршруты, имена полей форм, `id`, `data-*` (Stimulus `balance-lines`),
бизнес-логика. `format_minor_currency` используется только в Балансе. После перевода
фильтр остаётся (`format_currency` из того же класса нужен в 3 местах), удалить
`format_minor_currency` — отдельно, если не понадобится.

## 5. Решения Владельца

| # | Вопрос | Рекомендация |
|---|---|---|
| 1 | Шрифт нового слоя: Manrope → Inter | **Да**: в DS Inter, легаси уже на нём, иначе два шрифта в одном продукте |
| 2 | Палитру менять сразу для всего нового слоя, а не только для Баланса | **Да**: см. §1. Баланс — первый по содержимому |
| 3 | 9 разделов Баланса во вкладках: «Ещё» после 6-го по правилу DS | **Да**: «Баланс, Статьи, Счета, Документы, Движения, Сравнение» видны, «Периоды, Настройка, Права» — в «Ещё» |
| 4 | Ненулевое «Расхождение» актива и пассива подсвечивать красным | **Да**: это сигнал ошибки учёта, а не сумма-расход; правило DS это допускает |

## 6. Риски

- **Визуальные регрессии сразу на ~40 страницах** на этапе 1: контроль — скриншоты
  до/после каждой группы, этап 1 ничего не меняет в разметке.
- **React-обёртки** (`assets/react/ui-kit/`) напрямую токены кита не читают (0 вхождений),
  но используют классы кита и перекрасятся вместе с ними. Смоук: настройки API, админка, вход.
- **«Покрытие» маркетплейсов** (легаси) перекрасится. Это ближе к DS, но страницу
  нужно проверить отдельно.
- **Тесты на текст**: в тестах Баланса проверяются `h1.wz-title` и сумма
  `100 000,00` — классы заголовков сохраняются, ожидание суммы обновляется под NBSP.

## 7. Проверки

- Каждый этап: `npm run lint`, `npm run build`, скриншоты затронутых страниц.
- Этапы 3–4: `make site-test` (функциональные Баланса, админки, API), PHPStan, CS.
- Handoff: внутреннее ревью свежей сессией и внешнее ревью Codex.
- После деплоя: образы healthy, хеши CSS на проде, GlitchTip без новых ошибок.
