# ADR-001: Financial Event как неизменяемый факт и единый вход в ядро

- Статус: Принято на Stage 0 (2026-10-04); к пересмотру только через новый ADR
- Контекст: `00`, `03`, `05`

## Контекст

Финансовый эффект сейчас возникает как побочный результат записи в разные
таблицы (`documents`, `cash_transaction`, `marketplace_*`), а связи между ними
выражены вызовами Facade и пользовательскими кнопками. Нет записи «что
произошло», по которой можно (а) восстановить результат, (б) отследить
происхождение суммы, (в) повторить обработку.

## Решение

1. Введён **Financial Event** — неизменяемая запись факта (`05`), хранится в
   `fincore_events`, идентифицируется `idempotency_key`
   (`source_type:source_id:event_type:r{revision}`).
2. Любой модуль-продюсер вызывает `FinancialCoreFacade::recordEvent()` внутри
   своей бизнес-транзакции.
3. Исправление факта — новое событие (`source_revision+1`, `corrects_event_id`).
4. Деньги — целые minor units + валюта на каждой сумме, FX — первоклассные
   поля, исходная валюта не теряется (ADR-008); payload самодостаточен (не читает
   изменяемый источник). Событие различает `occurred_at` (когда случился факт),
   `effective_date` (в какой период относится) и `recorded_at` (когда записано);
   период определяется только `effective_date` (ADR-006).
5. События версионируются (`event_version`), upcaster'ы в оркестраторе.

## Рассмотренные альтернативы

| Вариант | Почему отвергнут |
|---|---|
| Symfony-события / Doctrine lifecycle listener | не сохраняются, не реплеятся; listener в `postPersist` уже даёт гонки (Cash, C1) |
| Event sourcing всех модулей | несоразмерно; бизнес-модули остаются state-based |
| Выводить факты из состояния таблиц (CDC) | теряется намерение/причина; сложно с мягкими удалениями и пересчётами |
| Использовать `audit_log` | это журнал изменений сущностей, не бизнес-факт; без версий и ключа идемпотентности |

## Последствия

+ единая точка происхождения суммы (`correlation_id`/`causation_id`);
+ replay и reconciliation становятся возможны;
− каждый продюсер обязан поддерживать контракт; payload-снимок дублирует часть данных;
− нужна дисциплина версий.

## Инварианты
