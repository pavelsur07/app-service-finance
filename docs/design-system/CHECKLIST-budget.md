# Чек-лист готовности: «Бюджет ОПиУ» (варианты, ввод плана, план–факт)

Отмечай пункт только с доказательством (скриншот, селектор, тест, строка кода).

## A. Границы
- [ ] Затронут легаси-слой (`_layout/legacy.html.twig`), Twig + Tabler + токены `--vf-*`; `_layout/app.html.twig`, прочий React, `site/ui-kit/` без изменений
- [ ] React — только остров сетки ввода плана (экран 3); остальное Twig
- [ ] Меню: «Бюджет ОПиУ» в «Деньги и отчёты»; «План–факт» — вкладка `_tabs` внутри раздела
- [ ] Демо-панель, фейковые данные, тосты-заглушки макета не перенесены
- [ ] Доменные правила, права, модель данных — по ТЗ/`TASK.md`, не изменены без согласования; миграции — только по согласованию

## B. Права и подтверждения
- [ ] Три роли (чтение / запись / владелец) работают по таблице ТЗ §0
- [ ] Недоступное действие видно неактивным с причиной (текстом, не только `title`)
- [ ] Подтверждения — `_confirm_modal` с названием варианта, не `confirm()`
- [ ] Ошибки сервера — текстом рядом с местом ошибки, не в тултипе

## C. Деньги и знак
- [ ] Суммы через форматтеры DS (`vf_money` / `vf_amount`, в React тот же формат); NBSP, запятая, минус U+2212; «₽» в заголовке колонки
- [ ] Красного цвета для сумм нет; отклонение — ▲/▼ и подсветка
- [ ] Расход вводится положительным и хранится/показывается со знаком «−»; доход как есть; `NONE` как ввёл (или иное решение владельца — записано в отчёте)

## D. Список вариантов
- [ ] Порядок: утверждённый, черновики по дате изменения, архив свёрнут «Архив (N)»
- [ ] Бейджи статусов; «Итог года» по решению владельца; колонка скрыта, если строки итога нет
- [ ] Меню «⋯»: Открыть, Копировать, Утвердить/Вернуть, В архив/Восстановить — с проверкой прав
- [ ] Отказ при втором утверждённом варианте с точным текстом; старый автоматически не снимается
- [ ] Пустой год: «На {год} год вариантов нет», «Создать пустой», «Заполнить из факта» (неактивна до этапа 3)
- [ ] Переключатель года: годы с вариантами + текущий и следующий
- [ ] Загрузка, ошибка, только чтение — сняты; ≤760 px карточки

## E. Окно «Новый вариант»
- [ ] Название обязательно, ≤120, по умолчанию «Вариант N»; ошибки под полями; окно не закрывается
- [ ] «Пустой» (+год) / «Копия» (+источник, год из источника не редактируется)
- [ ] Скрытый UUID: двойной клик «Создать» — один вариант; после создания переход на экран бюджета

## F. Ввод плана — шапка, баннеры, разрез
- [ ] Название правится по клику только в черновике; индикатор сохранения трёх состояний, `aria-live`
- [ ] Кнопки по статусу (черновик/утверждён/архив) как в спецификации; «⋯» с Копировать (и В архив в черновике)
- [ ] Баннеры: утверждён (разные тексты владельцу/не владельцу), архив, чтение, конфликт
- [ ] Фильтр разреза: пилюли, ограничение пар, режим суммы только для просмотра с подсказкой, адрес с `project`/`center`; одна пара — фильтра нет

## G. Сетка
- [ ] Дерево ОПиУ в порядке отчёта, отступы, свёртка запоминается, скрытые статьи не показаны
- [ ] Листья редактируются; итоги и KPI пересчитываются сразу, итоги совпадают с правилами отчёта ОПиУ (вес в родителе)
- [ ] «Итого» — сумма месяцев (KPI — отношение сумм); закреплены первая колонка и шапка
- [ ] Клавиатура: клик/Enter/F2, цифры, Enter/Tab (+Shift), стрелки, Esc, Delete, Shift+Enter; весь сценарий без мыши
- [ ] Форматы ввода «600000», «600 000», «600000,50»; иное — ошибка рамкой + текст под сеткой, значение не сохранено
- [ ] Вставка из Excel: старт с текущей ячейки, пропуск нередактируемых/нечисловых, «Вставлено N ячеек, пропущено M»
- [ ] Автосохранение пачкой ~1 с и при уходе; повтор безопасен; ошибка — «не сохранено» + «Повторить» + предупреждение при уходе
- [ ] Утвердили в другой вкладке: отказ при сохранении → режим чтения, баннер, список несохранённых ячеек
- [ ] Комментарий: Shift+Enter/контекстное меню, ≤500, уголок-маркер, текст по наведению; ноль без комментария = пусто, с комментарием хранится
- [ ] Нет статей: «Сначала настройте статьи ОПиУ» + ссылка; удалённая статья не показывается, итоги считаются без неё

## H. Быстрое заполнение
- [ ] Активно только в черновике при выбранной паре; иначе неактивно с причиной
- [ ] Окно двухшаговое: «Настройка» → «Проверка»; Esc закрывает, фокус возвращается на кнопку «Помощники»
- [ ] Пять помощников; параметры с ошибками под полями
- [ ] Статьи: поиск, «все/ни одной» на найденные, группы с трёхсостоянным чекбоксом, счётчик, работает на 50+ статей
- [ ] Месяцы: чипы кварталов, «Все», «Сбросить»; для «Распределить»/«Копировать вправо» — пояснение вместо выбора
- [ ] Предпросмотр: новое и «было …» по ячейкам, итог по статье, счётчики; предупреждение о перезаписи заполненных
- [ ] Применяются только изменившиеся ячейки; «Заполнено N ячеек»; строки «план продаж» не изменяются
- [ ] Расчёты — на сервере; «Отмены» нет — вернуться можно только на шаге 2 кнопкой «Назад»

## I. План–факт
- [ ] Фильтры: год, вариант (по умолчанию утверждённый + подсказка), проект и ЦФО мультивыбор, период месяцы/кварталы
- [ ] Показатель План/Факт/Отклонение/%; блок «Итого» из четырёх колонок в конце таблицы; закреплена только колонка статей
- [ ] «Все показатели»: раскладка «Колонками» (двухуровневая шапка) и «Строками» (3 строки на статью); выбор запоминается

- [ ] Отклонение = факт − план в знаке отчёта; % пусто при плане 0; ▲/▼ с текстовым эквивалентом; подсветка > 10%
- [ ] Будущие месяцы: факт пуст, отклонение не считается
- [ ] Клик по факту → отчёт ОПиУ за период с теми же фильтрами; **факт совпадает с отчётом, расхождение 0**; «Не задано» ЦФО как в отчёте
- [ ] Мобильная ширина: только итог периода, «Отклонение» видно без прокрутки
