Правила DS — `docs/design-system/sheets/` (Tokens, Controls, Table, Money, Feedback), планы `docs/plan/ds-legacy-tabler-audit.md`, `docs/plan/ds-operations-dds.md`, `docs/plan/entity-picker.md`, `docs/plan/ds-counterparties.md`.
Эталон — пакет: `docs/design-system/DDS-OPERATION-SPEC.md` (**прочитай целиком**), `screens/OperationDds.dc.html`, `OperationDdsBank.dc.html`, `DdsCategoryPicker.dc.html`, `screens/dds-refs/*.png`, `components/dds-tree-picker/*` (эталонные CSS/JS/Twig). Критерии готовности — `CHECKLIST-dds-operation-edit.md`.

## Цель
Страница «Редактирование транзакции» (операция ДДС) оформляется по макету, а выпадающий список «Статья ДДС» заменяется переиспользуемым виджетом — выбор листа дерева (до 4 уровней групп) с поиском, в одном стиле с выбором контрагента.

## Рамки
- Только legacy-слой: `templates/_layout/legacy.html.twig`, Tabler, токены `--vf-*`, `legacy-app.css/js`. Не трогать `_layout/app.html.twig`, `assets/react/**`, `site/ui-kit/`; не брать их за образец.
- Роуты, имена роутов, имена полей формы, CSRF, `data-*`-хуки, существующие тесты — не менять. Серверная валидация остаётся источником истины.
- Схема БД/миграции — не менять без необходимости. Если макет требует то, чего нет в модели (восстановление, история, валюта операции, блокировка выписочных полей) — **не изобретай**: выбери безопасный вариант из SPEC §7 или вынеси вопрос в отчёт.
- Прототипы — не код: не копируй их разметку. Берёшь размеры, тексты, состояния, поведение. Эталонные `dds-pickers.css`/`dds-tree-picker.js` — отправная точка; допустимо адаптировать под сборку проекта, но поведение и вид должны совпасть.
- Прототип содержит демо-данные и нерабочие пункты («Дублировать», «История изменений») — переносить только то, что есть в бэкенде (SPEC §6).

## Stage 1 — виджет «Статья ДДС» (PR 1)
- Провайдер дерева (Facade/сервис модуля справочников) → массив `[{id,name,children}|{id,name,flow}]`, id листа == value option; один запрос на страницу; фильтрация по `company`.
- CSS в legacy-слой (алиасы токенов сопоставь с `--vf-*` в одном блоке), JS-модуль подключи к legacy-цепочке, Twig-partial в `templates/partials/`.
- Поведение строго по SPEC §3: выбор только листьев; 4 уровня групп; направляющие линии; поиск (подсветка, раскрытие, пустое состояние); ↑ ↓ Enter Esc; фильтр по направлению + «Показать все»; сброс несовместимой статьи; ARIA; без JS — обычный select.
- Тест: перенеси `dds-tree-picker.e2e.js` под проектный раннер (или оставь как ручной сценарий в отчёте), добавь unit-тест провайдера (вложенность, `flow`, изоляция по компании).
