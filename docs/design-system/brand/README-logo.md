# Логотип «Ваш Финдир»

| Файл | Назначение |
|---|---|
| `logo-full.svg` | знак + название, тёмный текст — светлые фоны (шапки страниц, письма, документы) |
| `logo-full-white.svg` | знак + название, белый текст — тёмные фоны (боковое меню `#0b1020`) |
| `logo-mark.svg` | только знак 32×32 — узкие места, аватар, иконка приложения |
| `favicon.svg` | то же, для `<link rel="icon" type="image/svg+xml">` |
| `logo-mark-512.png`, `logo-mark-192.png` | растровый знак с прозрачным фоном (PWA/OG/почтовые клиенты) |
| `logo-full@4x.png`, `logo-full-white@4x.png` | растровые версии (текст в письмах, PDF, презентации) |

## Состав
- Знак: скруглённый квадрат (radius 8 при стороне 32) цвета **`#b00020`**, внутри белые буквы **«ВФ»**, Inter Bold 13 px, по центру.
- Название «Ваш Финдир»: Inter Bold 16 px, цвет `#0b1020` (на тёмном — `#ffffff`), отступ от знака 10 px.
- Тексты в SVG переведены в контуры — **шрифт не нужен**, внешний вид одинаков везде.

## Правила
- Минимальная высота: 24 px для полного логотипа, 16 px для знака. Охранное поле — высота буквы «В» вокруг логотипа.
- Не менять цвет знака, пропорции, начертание; не добавлять тени, обводки, градиенты; не вращать.
- Знак всегда `#b00020` — на красных фонах использовать белую версию знака с красными буквами (отдельный файл запросить у дизайнера).
- Размеры в интерфейсе: шапка страниц входа/регистрации — полный логотип высотой 32 px; боковое меню — `logo-full-white.svg` 32 px; favicon — `favicon.svg`.
- `alt="Ваш Финдир"`; если логотип — ссылка на главную, `aria-label="Ваш Финдир — на главную"`, а `alt` у картинки не дублируй.
- Красный `#b00020` — цвет бренда, **не** цвет ошибки. Ошибки — `#9a001b` (токен danger).

## Подключение
```html
<link rel="icon" type="image/svg+xml" href="/brand/favicon.svg">
<link rel="apple-touch-icon" href="/brand/logo-mark-192.png">
<meta property="og:image" content="https://…/brand/logo-mark-512.png">
```
Файлы положи в `public/brand/` (или в `assets/` под версионирование). Старые логотипы и favicon заменить, обновить `manifest`.
