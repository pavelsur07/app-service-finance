## Что привести к эталону
1. **Токены**: цвета/радиусы/шрифт — через переменные; Action blue `#1d4ed8`; красный только для деструктивных действий («Удалить»). Убрать инлайновые `style=` там, где есть токен/класс.
2. **Таблица** (DS-Table): заголовок, плотность строк, hover, выбор строк, строка итогов, пустое состояние, sticky-шапка.
3. **Деньги** (DS-Money): тысячи — неразрывный пробел, десятичная запятая, минус `−` (U+2212), приглушённые копейки, числа вправо с `tabular-nums`. Приход — зелёный, расход — обычный цвет. Сейчас в ячейке выводится `+/-` + `number_format(2, ',', ' ')` + код валюты: заменить на один Twig-макрос/фильтр. Валюту в заголовок колонки выноси только если все строки в одной валюте; при смешанных валютах оставь код валюты в ячейке и опиши решение в отчёте.
4. **Вкладки**: «Все / История / Удалённые / Авто-правило прим.» — это переходы между страницами (разные роуты), не переключатель содержимого. Оформи по DS-Tabs (подчёркивание 2px, счётчики), семантику ссылок сохрани.
5. **Фильтры** (`_filters.html.twig`): по Filters.dc.html и DS-Controls: поля, select, пресеты периода, состояния, кнопка применения.
6. **Пагинация**: стандартная Tabler, подпись «Показано с X по Y из N». Проверь, как пагинация устроена сейчас; не меняй логику выборки.
7. **Состояния и обратная связь** (DS-Feedback): флэши, пустое состояние, ошибки, модалка удаления.
8. **Доступность**: контраст текста ≥ AA; фокус виден; границы полей — см. замечание: `#c3c8d6` на белом = 1,67:1 (< 3:1 для границ контролов). Для границ полей/select/checkbox используй `#8590a8` (≈3,2:1), декоративные разделители оставь `#dde1ec`; зафиксируй это в отчёте как отклонение от листа.
