# Дизайн-система «Ваш Финдир» — эталон для легаси-слоя (Tabler)

Источник истины для визуала легаси-страниц (шаблоны на `_layout/legacy.html.twig`).
Старый `site/ui-kit/` для легаси не актуален (см. промпт внедрения, Stage 6).

## Листы (`sheets/*.dc.html`)
Исходники листов из дизайн-канваса. Это HTML с разметкой Design Component:
- `{{...}}`, `<sc-for>`, `<sc-if>`, `<x-dc>`, `class Component extends DCLogic` — служебная часть канваса, её игнорировать;
- значения берутся из `<style>` и инлайновых стилей (цвета, размеры, отступы, радиусы), тексты правил — из разметки.

| Лист | О чём |
|---|---|
| DS-Tokens | цвета, типографика, отступы, радиусы, тени |
| DS-Controls | кнопки, поля, select, checkbox и т. п. |
| DS-Table | таблицы: заголовки, плотность, итоги, пустое состояние |
| DS-Money | форматирование денег и чисел |
| DS-Tabs | вкладки и счётчики |
| DS-Feedback | алерты, статусы, пустые состояния |

Просмотр: открыть в браузере не получится без канваса — читать как исходник.
Если лист читается плохо, приложить скриншот листа из канваса вместе с файлом.
