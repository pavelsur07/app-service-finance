# Дизайн-система «Ваш Финдир» — эталон визуала

Источник истины для визуала обоих интерфейсов (решения Владельца 2026-10-11 и 2026-11-15 — ДС v3.4):
легаси (`_layout/legacy.html.twig`, Tabler) и нового слоя (`_layout/app.html.twig`,
React). Старый `site/ui-kit/` удалён; CSS нового слоя — реализация в
`site/assets/styles/kit/`. С 2026-10-12 новый слой тоже на DS: значения токенов
кита взяты с листов (`docs/plan/ds-new-layer.md`, реестр — `ds-new-layer-pages.md`).

## Листы (`sheets/DS-*.html`) — ДС v3.4

С 2026-11-15 эталон — UI Kit v3.4 (решение Владельца, план внедрения —
`docs/plan/ds-v3.md`). Листы — обычный HTML: открываются в браузере. Значения
берутся из `sheets/ds-kit.css` (токены — в `:root`, компоненты — классы кита) и
из разметки листа. Скриншоты листов — `sheets/png/*.jpg`. Листы сгенерированы из
канваса — вручную не править: правка вносится в UI Kit и листы перегенерируются.

| Лист | О чём |
|---|---|
| DS-Tokens | архитектура токенов (primitives → semantic → component), палитра, цвета, типографика, отступы, радиусы, тени, анимация, z-index, фокус, сетка, брейкпоинты |
| DS-Controls | Button (+ `.btn-icon`), Form field, Input, Поле с дополнением, Textarea, Select, Checkbox, Radio, Toggle, Tags, EntityPicker, TreePicker |
| DS-Data | Badge/Chip, Marketplace badge, StatusPill, ABC-pill, Avatar, KPI, Card, Account card |
| DS-Table | строки, сортировка, итоги, пагинация, отчёт, тяжёлая аналитическая таблица |
| DS-Money | форматы сумм, направление операции, сумма + пояснение (см. открытый вопрос §6.1 плана) |
| DS-Tabs | вкладки-сегментер (в т. ч. в пикерах) |
| DS-Feedback | toast, inline alert, пустое состояние, подтверждение |
| DS-Overlays | модалки S/M/L, drawer 680 |
| DS-Layout | AppHeader + хлебные крошки, сайдбар, меню, App Shell, ритм страницы |
| DS-Decisions | решения ДС (действующие и архив) и changelog |

Тёмная тема в листах есть (токены `[data-theme="dark"]`), в продукт пока не
внедряется — `docs/plan/ds-v3.md` §1.3.

## Tailwind (`tailwind/`)
Референс для нового React-слоя: `tailwind.config.js` (цвета, шрифт, радиусы, тени,
z-index — ссылки на CSS-переменные кита; preflight выключен) и `app.css`
(точка входа, только утилиты). Легаси и CSS кита на Tailwind не переводятся.

## Экраны (`screens/`)
- `App-Layout.html` — каркас приложения v3.4 на Tailwind: шапка, сайдбар с вложенностью и свёртыванием, пользователь + выход, футер. Открывается в браузере. Это визуальный эталон: в продукте каркас собирается из классов кита (`.app-header`, `.sb`, `.app-workzone`) и утилит Tailwind, собственные компоненты прототипа (`.nav-item` и т. п.) не переносить.
- Экраны `*.dc.html` ниже нарисованы до v3.4: структура и поведение — эталон, значения визуала (цвета, шрифт) — из листов v3.4.
- `Operations.dc.html` — эталон страницы «Операции ДДС» (таблица, итоги, пагинация, вкладки).
- `Filters.dc.html` — эталон панели фильтров этой страницы.
Это целевой вид; реальная страница — `site/templates/transaction/index.html.twig` и `_filters.html.twig`.
