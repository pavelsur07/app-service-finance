# Промпт приёмки: «Документ ОПиУ» (редактирование + создание) и виджет «Категория ОПиУ»

Ты — независимый ревьюер. Ничего не чини, пока не закончишь проверку: сначала отчёт, правки — отдельным шагом по запросу.
Прочитай `docs/design-system/PNL-DOCUMENT-SPEC.md`, `CHECKLIST-pnl-document.md`, `screens/pnl-refs/*.png`. Сверяй реализацию **с эталонными скриншотами и SPEC**, а не с прототипами `*.dc.html`.

## Что сделать
1. Подними приложение, открой форму редактирования документа ОПиУ с 2+ операциями и форму создания (из операции ДДС). Сними скриншоты 1440, 1280, 390 для состояний 01–12 и положи рядом с эталонами (одинаковые состояния, одинаковые данные).
2. Пройди чек-лист пункт за пунктом; к каждому — «выполнено / частично / нет» + доказательство (скриншот, селектор, номер строки кода, вывод теста). Без доказательства пункт — «нет».
3. Три главных сценария проверь вручную, пошагово:
   - **Проект/ЦФО шапки:** смени Проект в шапке → у операций без ручных правок значение меняется, у «Изменён» — нет; уведомление «подставлен в N из M»; «Как в шапке» возвращает; новая и дублированная операция получают нужные значения; сохрани и открой снова — значения операций сохранились.
   - **Описание:** введи, сохрани, перезагрузи — на месте; 200 символов — предел; пустое не ломает сохранение.
   - **Категория ОПиУ:** выбрать можно только лист; 4 уровня групп — отступы и линии; поиск («цех») раскрывает ветки и подсвечивает; ↑ ↓ Enter Esc; смена типа операции сбрасывает несовместимую категорию с заметкой; ошибка «Выберите категорию ОПиУ»; несколько строк — работают независимо; строка, добавленная кнопкой, тоже; без JS форма отправляется обычным select.
4. Регресс: сверка с основанием, расчёт итогов, валидация сумм, модалки, `beforeunload`, права доступа и изоляция по компании (IDOR: чужой id документа/статьи), существующие тесты.
5. Гейты: `make site-stan`, `make site-cs-check`, `make site-cs-strict-types`, `make site-test`, `npm run lint`, `npm run build`, `npm run check:ui-kit`. Не прогнан — так и пиши.
6. Проверь границы: не изменены `_layout/app.html.twig`, `assets/react/**`, `site/ui-kit/`, имена роутов и полей, нет новых миграций без согласования.
