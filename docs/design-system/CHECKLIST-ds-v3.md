# Чек-лист: ДС «Ваш Финдир» v3.4 в apps

Отмечай `[x]` только после проверки; к каждому пункту — доказательство (вывод
команды, скриншот, ссылка на тест или diff). Эталон: `docs/design-system/v3/`; план —
`docs/plan/ds-v3.md`. Пункты с ⛔ блокируют релиз.

## A. Рамки
- [ ] ⛔ `site/` не изменён: `git diff --stat origin/master -- site/` пуст
- [ ] ⛔ В CSS apps и пакета нет `[data-theme="dark"]` и `@media (prefers-color-scheme: dark)` (`rg`)
- [ ] ⛔ Apps не импортируют `@vashfindir/ui/styles.css` и CSS из `site/assets` (`rg`)
- [ ] Новые зависимости — только из списка промпта; lock-файлы обновлены в контейнере

## B. Пакет и токены (Stage 1)
- [ ] `apps/packages/ds` (`@vashfindir/ds`), exports: `.`, `./tokens.css`, `./styles.css`
- [ ] `tokens.css` генерируется из `tokens/ds-v3.tokens.json` (Style Dictionary), префикс `--ds-`, без тёмной темы
- [ ] Тест: все semantic- и component-токены JSON есть в `tokens.css`; значения = `v3/sheets/ds-kit.css`
- [ ] Хардкода цветов в пакете и apps нет, кроме сгенерированного `tokens.css` (`rg "#[0-9a-fA-F]{3,8}"`)

## C. Tailwind и стили (Stage 2)
- [ ] Tailwind v4 через `@tailwindcss/vite` в обоих приложениях; тема по `v3/tailwind/app.css`
- [ ] Палитра, кегли, радиусы, тени по умолчанию сброшены: `bg-blue-500`, `text-base` не собираются
- [ ] Нет произвольных цветов в классах (`rg "\[#"`)
- [ ] Шрифт Manrope, body 13px, `tabular-nums`; `rem` не переопределён (отступы — шаг 4px)
- [ ] Вход, главная, about, 404 в обоих приложениях — по v3.4 (скриншоты)

## D. Компоненты (Stage 3, 5)
- [ ] Компоненты §3.1 плана: API в TS-интерфейсе над компонентом, Vitest на состояния и клавиатуру
- [ ] Button: primary — navy, красного фона кнопки нет нигде (`rg "color-accent"` — только логотип/промо)
- [ ] Кнопка-иконка требует `aria-label` (типом или проверкой)
- [ ] Поля: hover / focus / error / disabled как в DS-Controls; граница ≥3:1; ошибки связаны `aria-describedby`
- [ ] Modal и Drawer: фокус-ловушка, Esc, возврат фокуса, `aria-modal`, блок прокрутки фона
- [ ] Table: сортировка (`aria-sort`), итоги, пагинация кита
- [ ] ⛔ `formatMoney`: U+00A0 между разрядами, минус U+2212, запятая, «₽» суффиксом; тесты на ноль, отрицательные, копейки
- [ ] Экраны apps не используют `Button`/`EmptyState` из `@vashfindir/ui`

## E. Каркас (Stage 4)
- [ ] Шапка 60px на всю ширину, логотип в колонке сайдбара; крошки, период, поиск, уведомления
- [ ] Сайдбар 264px: группы, вложенные пункты (`aria-expanded`/`aria-controls`), активный — `aria-current="page"`
- [ ] Свёртывание в рейку 72px: подписи `sr-only`, состояние запоминается, клик по группе в рейке разворачивает меню
- [ ] Пользователь (аватар, имя, роль) + «Выйти» через существующий выход сессии apps
- [ ] ⛔ Нет прыжка контента при появлении полосы прокрутки (`scroll-stable` у сайдбара и рабочей зоны; проверено с обычными полосами прокрутки)
- [ ] Ссылка «Перейти к содержимому»; единое кольцо фокуса
- [ ] Меню `apps/admin` — своё, каркас общий из пакета
