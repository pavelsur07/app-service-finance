# Чек-лист готовности: «Документ ОПиУ» — редактирование и создание

Отмечай пункт только с доказательством (скриншот, селектор, тест, строка кода).

## A. Границы
- [ ] Затронут только legacy-слой; `_layout/app.html.twig`, `assets/react/**`, `site/ui-kit/` без изменений
- [ ] Роуты, имена роутов, имена полей формы, CSRF, `data-*`-хуки не изменены; существующие тесты зелёные
- [ ] Миграции только по согласованию (поле «Описание» операции и т. п. — SPEC §8)
- [ ] Виджет дерева переиспользован из пакета ДДС, второй копии нет

## B. Шапка (пункт 1)
- [ ] «Проект \*» и «ЦФО» в карточке «Основные данные», подпись-плашка на месте
- [ ] Проект обязателен: «Шапка: выберите проект»; ЦФО необязателен
- [ ] Смена Проекта/ЦФО в шапке обновляет только операции, наследующие значение
- [ ] Уведомление «подставлен в N из M операций. В K задан вручную»
- [ ] В изменённой операции — пометка «Изменён» + «Как в шапке»; при совпадении с шапкой пометка пропадает
- [ ] Новая операция берёт значения шапки; дубль копирует значения исходной
- [ ] Новый документ: Проект/ЦФО предзаполнены из операции ДДС
- [ ] Существующий документ: начальное значение шапки по SPEC §8.1; сохранение не ломает значения операций
- [ ] Поля Проект/ЦФО/Контрагент выглядят как на странице операции ДДС (`.dds-field`), логика поиска сохранена

## C. Описание операции (пункт 2)
- [ ] Вторая строка операции: подпись «Описание» + поле, maxlength 200, placeholder по SPEC
- [ ] Сохраняется и читается; перезагрузка — значение на месте
- [ ] Необязательное; `aria-label="Описание, операция N"`
- [ ] Новая и дублированная строка получают корректное значение (пусто / копия)

## D. Виджет «Категория ОПиУ» (пункт 3)
- [ ] Заменил select «Статья ОПиУ» в каждой строке; под полем виден путь выбранной категории
- [ ] Выбрать можно только лист; клик по группе лишь раскрывает/сворачивает
- [ ] Вложенность до 4 групп + лист: шаг 22 px, направляющие линии, у групп счётчик листьев
- [ ] Поиск: подсветка, авто-раскрытие, пустое состояние; совпала группа → видны её листья
- [ ] ↑ ↓ Enter Esc; фокус в поиск при открытии и на кнопку при закрытии
- [ ] Фильтр по типу строки + «Показать все» (теги «Доход/Расход»)
- [ ] Смена типа строки сбрасывает несовместимую категорию, заметка по SPEC
- [ ] Ошибка «Выберите категорию ОПиУ» + красная рамка; категория обязательна на сервере
- [ ] Несколько экземпляров независимы; открыт один popover; клик вне/Esc закрывает
- [ ] Строки, добавленные «Добавить операцию» и «Дублировать», получают рабочий виджет
- [ ] Без JS форма отправляется обычным select
- [ ] Дерево строится одним запросом на страницу, фильтр по `company`; unit-тест провайдера
- [ ] XSS-безопасно (названия через `textContent`)
