# Чек-лист готовности переноса дизайна «Операция ДДС» + виджет «Статья ДДС»

Отмечай `[x]` только после проверки; к каждому пункту — доказательство (скриншот, вывод команды, ссылка на тест). Эталон: `docs/design-system/screens/` и `dds-refs/*.png`. Пункты с ⛔ блокируют релиз.

## A. Рамки и безопасность изменений
- [ ] ⛔ Изменён только legacy-слой; `_layout/app.html.twig`, `assets/react/**`, `site/ui-kit/` не тронуты (`git diff --stat`)
- [ ] ⛔ Роуты, их имена, имена полей формы, CSRF, `data-*`-хуки и существующие тесты не изменены
- [ ] ⛔ Схема БД и миграции не менялись (или есть согласованное обоснование)
- [ ] Нет нерабочих элементов (кнопок/пунктов меню без бэкенда)
- [ ] Название «Операция ДДС» в заголовке, breadcrumbs, `<title>`; найдены и обновлены все старые упоминания «Редактирование транзакции» (меню, тесты, e2e-селекторы)

## B. Токены и стиль
- [ ] Нет хардкода цветов вне блока алиасов; все цвета через `--vf-*`
- [ ] Шрифт Inter 14/20; высота полей и кнопок 36 px; радиусы 4 (карточки/поля) и 8 (popover/модалки)
- [ ] Фокус: `outline 2px` primary, offset 2, виден на всех интерактивных элементах (в т.ч. «×» и строках дерева)
- [ ] Деньги: NBSP-разряды, десятичная запятая, минус U+2212, знак валюты в «кармашке»/заголовке колонки; доход зелёный, расход обычный
- [ ] Бейджи (направление, «Из выписки», «Разнесено…») — цвета и границы как в `dds-refs/01, 05`

## C. Страница — структура и поля
- [ ] Раскладка 2 колонки (основная + «Сведения» 320 px, sticky) — сверено со скриншотом 01 в 1440
- [ ] Карточки «Операция», «Аналитика», «Документы ОПиУ на основании операции»; порядок и подписи полей как в спеке §2.2
- [ ] Направление — segmented radio «Приток/Отток» (`role=radiogroup`), значение уходит в форму как раньше
- [ ] Сумма: вправо, tabular-nums, на blur форматируется, знак валюты из счёта; подпись «Валюта берётся из счёта…»
- [ ] Проект/ЦФО/Контрагент — тот же вид поля (`.dds-field`), «×» только при значении; прежняя логика поиска и сохранения не сломана
- [ ] Описание: maxlength 500, счётчик «N из 500»
- [ ] Sticky-панель «Сохранить / Отмена»; «Сохранить» неактивна без изменений

## D. Виджет «Статья ДДС»
- [ ] ⛔ Выбираются только листья; клик по группе лишь раскрывает/сворачивает (проверено кликом и Enter)
- [ ] Поддержано 4 уровня групп + лист: отступы 22 px, направляющие линии по уровням — сверено со скриншотами 02, 11
- [ ] Счётчик группы = число листьев внутри, включая вложенные
- [ ] Поиск: подсветка совпадения, раскрытие групп, скрытие пустых, активная первая строка, пустое состояние — скриншоты 03, 12
- [ ] Клавиатура: ↑ ↓ Enter Esc; Esc возвращает фокус на кнопку; клик вне закрывает
- [ ] Фильтр по направлению (+ «Показать все»); `flow=both` показывается всегда
- [ ] Смена направления сбрасывает несовместимую статью и показывает заметку (скрин 09); событие `change` на select срабатывает
- [ ] Исходный `<select>` остаётся в форме и отправляется; без JS страница сохраняется как раньше
- [ ] ARIA: `aria-haspopup/expanded` на кнопке, `role=tree/treeitem`, `aria-selected`, `aria-activedescendant` (проверено axe/ручным обходом)
- [ ] Названия статей выводятся как текст (проверка на `<script>`/`&` в имени)
- [ ] Виджет подключается повторно на других формах без правок кода (проверено на второй форме или в `demo.html`)

## E. Поведение страницы

- [ ] ⛔ Уход с несохранёнными правками: модалка «Выйти без сохранения?» и `beforeunload`; без правок — уходит сразу
- [ ] Удаление: модалка, баннер «Операция удалена», «Восстановить» (если есть в бэкенде)
