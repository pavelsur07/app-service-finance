# Чек-лист готовности: «Вход», «Регистрация», логотип, юридический блок

Отмечай пункт только с доказательством (скриншот, селектор, тест, строка кода).

## A. Границы
- [ ] Затронут только legacy-слой; `_layout/app.html.twig`, `assets/react/**`, `site/ui-kit/` без изменений
- [ ] Роуты, имена роутов и полей, CSRF, Security, FormType, подтверждение email, сброс пароля — без изменений; существующие тесты зелёные
- [ ] Миграции только по согласованию (согласие на рассылку и т. п.)
- [ ] Демо-логика прототипа (`wrong`, `busy@company.ru`, таймеры, фейковые экраны) не перенесена

## B. Логотип и бренд
- [ ] Логотип — SVG-файл из `brand/`, не текст в div; положен в `public/brand/` (или assets)
- [ ] Заменён во всех местах из аудита: шапка входа, шапка регистрации, боковое меню (белая версия), письма (PNG), заголовки
- [ ] favicon.svg + apple-touch-icon + OG-картинка подключены; manifest обновлён
- [ ] Размеры: полный 145×32, знак 32×32; охранное поле; цвет знака `#b00020` не менялся
- [ ] `alt`/`aria-label` без дублирования, ссылка ведёт на главную
- [ ] Красный `#b00020` не используется как цвет ошибок (ошибки — `#9a001b`)

## C. Общая раскладка
- [ ] Фон `#f7f8fc`, Inter, подвал внизу при коротком контенте
- [ ] Шапка: логотип слева, ссылка на соседнюю страницу справа (отступы 20×40; ≤560 — 16×20)
- [ ] Карточка: radius 8, тень, padding 36×40×32; ширина 440 (вход) / 520 (регистрация)
- [ ] ≤560 px: карточка на всю ширину без radius/границ/тени; h1 24; без горизонтального скролла
- [ ] Заголовок 28/34 700, подзаголовок 14/20 muted, отступы 8/28

## D. Вход
- [ ] Email, Пароль («глаз» с `aria-pressed`, «Забыли пароль?»), «Запомнить меня» (включено)
- [ ] Ошибки полей после первой отправки; фокус на первое невалидное
- [ ] Плашка «Неверный email или пароль…» с `role=alert`, без раскрытия, что именно неверно
- [ ] Кнопка «Войти» 44 px; при отправке блокируется, `aria-busy`, «Входим…»
- [ ] Юр. строка «Входя в сервис…» со ссылками на соглашение и политику
- [ ] Блок «Ещё нет аккаунта? Создать — 7 дней бесплатно»

## E. Регистрация
- [ ] Поля: компания, «Как вы продаёте?» (радио-карточки, по умолчанию «Базовый»), email, пароль
- [ ] Индикатор надёжности (4 сегмента) и три правила; правила совпадают с серверными
- [ ] Два **отдельных** обязательных согласия (условия+оферта+политика; обработка ПДн) с ошибками
- [ ] Необязательное согласие на рассылку: выключено по умолчанию, не блокирует регистрацию, хранится отдельно (или вопрос владельцу §10.3)
- [ ] Юридическое примечание: оператор, РФ, отзыв согласия, 18+, права от имени компании/ИП
- [ ] Плашка «Этот email уже зарегистрирован» со ссылками «Войти» и «восстановить пароль»
- [ ] Экран после отправки соответствует реальному потоку подтверждения email
- [ ] Кнопка «Создать аккаунт» 44 px, состояние загрузки

## F. Юридический блок
- [ ] 5 ссылок: оферта, соглашение, конфиденциальность, обработка ПДн, cookie; в новой вкладке, `rel=noopener`; страницы существуют
- [ ] «Сведения о компании»: наименование, ИНН/КПП, ОГРН, адрес, поддержка, контакт по ПДн, реестр ПО, реестр операторов ПДн
- [ ] Реквизиты — из конфигурации; пустая строка реестра скрывается; демо-значения помечены в отчёте
- [ ] Оговорка про хранение ПДн в РФ и «не консультация»; копирайт с годом и организацией
- [ ] Тексты и состав блока проверены юристом

## G. Баннер cookie
- [ ] Показывается при первом заходе, закреплён снизу, не перекрывает форму (проверено на 390)
- [ ] «Только необходимые» / «Принять все» сохраняют `vf_cookie_consent` на 180 дней; баннер больше не показывается
- [ ] Аналитика/маркетинг не грузятся до «Принять все» (проверено в Network)
- [ ] Доступен с клавиатуры, `role=region`, есть ссылка на Политику cookie

## H. Адаптив и доступность
- [ ] 1440 / 1280 / 1100 / 390 по скриншотам
- [ ] Label у каждого поля, `aria-describedby` для ошибок, `role=alert`
- [ ] Радио в `fieldset/legend`, фокус-кольца 2 px, контраст ≥ 4.5:1
- [ ] Всё работает с клавиатуры и без JS (кроме «глаза», индикатора и баннера)
- [ ] `prefers-reduced-motion` отключает спиннер

- [ ] Rate limit/защита от перебора входа не ослаблены; сообщение об ошибке не раскрывает существование аккаунта
- [ ] Контроллеры тонкие; `strict_types`; baseline PHPStan не вырос
- [ ] Гейты: `make site-stan`, `make site-cs-check`, `make site-cs-strict-types`, `make site-test`, `npm run lint`, `npm run build`, `npm run check:ui-kit`
