Архитектура токенов

Три слоя. Компонент ссылается только на semantic или component-токен, никогда на примитив или hex. Тема переопределяет только semantic-слой — компоненты не меняются.

1 · Primitives

Палитра и сырые шкалы. Не используются в компонентах напрямую.

--gray-500
--blue-600
--fs-md · --s-3 · --r-md
2 · Semantic

Роль цвета. Единственный слой, который меняет тема.

--text-tertiary → --gray-500
--color-primary → --blue-600
--danger-text → --red-700
3 · Component

Роль внутри компонента. Позволяет точечно менять компонент без побочных эффектов.

--input-border → --border-strong
--button-primary-bg → --color-primary
Имена v2.6 сохранены — semantic-слой = прежние --text-*, --bg-*, --border*, --success-*… Код продукта не ломается. Устаревшие --font-9_5…--font-14 и --r-1…--r-4 оставлены алиасами до v4.

Focus

Индикатор клавиатурного фокуса — показывает, на каком элементе сейчас находится пользователь, который работает с клавиатуры (Tab, Shift+Tab, Enter). Мышью он не появляется: правило висит на :focus-visible, браузер включает его только при навигации с клавиатуры. Нужен бухгалтерам и финдирам, которые вводят операции без мыши, и обязателен по WCAG 2.4.7.

Focus ring :focus-visible · .is-focus Один стиль на весь продукт. .is-focus — только для документации: показывает состояние без нажатия Tab.
Кнопки, табы, chip — outline 2px · offset 2px · --focus-ring-color
Ссылка в тексте — то же кольцо, переносится вместе со строкой

Подробности — в справке по разметке операций.

Поля — граница primary + мягкое кольцо (своё правило, outline не используется)
Живая проверка — кликните сюда и нажимайте Tab

Ссылка в тексте тоже получает фокус: правила разметки операций.

Правила: никогда не писать outline: none без замены · кольцо контрастирует с фоном ≥3:1 (поэтому сплошной navy, а не полупрозрачное свечение, как было в v3.1 у .is-focus) · offset 2px, чтобы кольцо не сливалось с заливкой кнопки · фокус не красный и не оранжевый — эти цвета заняты ошибками.

Breakpoints

Токены --bp-sm … --bp-xl — справочные: CSS-переменные не работают внутри @media. В коде — @custom-media --md (min-width: 960px) через PostCSS или SCSS-переменные с теми же значениями. Sidebar (264px) скрывается за drawer ниже md.

< 768 --bp-sm
Mobile · 4 колонки · sidebar скрыт (drawer) · карточки в ряду стекуются в 1 колонку
768–959 --bp-sm…md

960–1279 --bp-md…lg
Tablet landscape / малый ноутбук · 8 колонок · sidebar раскрыт (264px)

≥ 1440 --bp-xl
