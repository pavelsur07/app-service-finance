Heavy analytical table pattern · v1.5 Шаблон сложной аналитической таблицы. Применять, когда: ≥15 колонок, разные группы колонок, нужны раскрывающиеся строки. Канонический живой пример — UnitEconomics.dc.html.
Архитектура (снаружи внутрь)
1. .app-header + sticky thead под ней (top: var(--app-header-height))
2. Двухярусная sticky-шапка: верхний tier — группы колонок (.t-tier1), нижний — сами колонки
3. Sticky-left колонка (SKU) + sticky-right колонка (Прибыль) + горизонтально скроллящая середина
4. Sync'нутый горизонтальный скроллбар сверху (.t-scrollbar--top) + sticky-viewport снизу (.t-scrollbar--bottom)
5. .t-row--totals в конце (Decision 21)
6. .t-pagination под таблицей
Контролы: .cols-popover (видимость колонок + пресеты), .tabs (фильтрация по ABC-классу), .t-sort-th на сортируемых колонках
Внутри ячеек: .mp-mark--sm, .abc-pill, .t-expand-btn, .t-profit-bar, .money
Развёрнутая строка: .t-breakdown — sub-таблица внутри строки с группированными подсуммами
