Состояния пункта

· default — серый текст + приглушённая иконка
· hover — фон --bg-page, текст тёмнее
· active — фон --color-primary-tint, текст --color-primary-hover, иконка --color-primary, weight 700
· counter-badge — выравнивание по правой стороне, tabular-nums
· collapsible group — chev поворачивается на −90° при состоянии collapsed
Dropdown menu .menu Меню действий на строке таблицы или у виджета. Разделители — для смены смысловой группы. В строке таблицы открывается по кнопке «⋯» в последней колонке и выравнивается по её правому краю.

Каркас страницы

App Shell

Каркас всех страниц приложения: header сверху, sidebar 264px слева, рабочая зона справа. Внутрь .app-workzone вкладывается контент страницы. Компонует существующие .app-header + .sb, ничего в них не меняя.
AppShell .app · .app-body · .app-sidebar · .app-workzone Внешняя обёртка страницы. .app (колонка) → .app-header + .app-body(.app-sidebar + .app-workzone). Sidebar sticky от top:60px, workzone — flex:1, padding s-6 / s-7.

Page scaffold

Вертикальный ритм контента внутри .app-workzone: заголовок страницы → ряд KPI → ряды секций. Семейство wz-* (Decision 26). Заголовок 28px/700, отбивка s-5. Gap в ряду s-4, между рядами s-5. Карточки в ряду равные, переносятся на узком экране.
Page scaffold .wz-head · .wz-title · .wz-row Раскладка страницы: .wz-head (заголовок + слот действий) → .wz-row (ряд KPI) → .wz-row (две карточки-секции) → карточка с таблицей. Ряды переносятся при < ~200px на карточку.
