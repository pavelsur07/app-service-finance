Вкладки (Tabs)

Вкладки делят один список на разделы: «Все», «Не распределено», «Архив». Основаны на nav-tabs из Tabler; активная вкладка отмечена синей линией цвета действия, красный остаётся только для бренда и ошибок.

Состояния

Вкладка меняет только цвет текста и линию. Размер и жирность постоянны, поэтому соседние вкладки не сдвигаются.

Правила использования

Когда использовать
Вкладки делят один набор данных на разделы (все / не распределено / архив). Каждый раздел — это отдельный список с теми же столбцами и фильтрами. Если меняется структура страницы, это уже навигация, а не вкладки.
Первая — «Все»
Первая вкладка всегда показывает весь набор и открыта по умолчанию. Остальные — подмножества. Порядок: от общего к частному, «Архив» и «Удалённые» — в конце.
Количество
От 2 до 6 вкладок. Больше — прячем редкие в пункт «Ещё» с выпадающим списком. Одна строка, без переноса на узких экранах: вкладки прокручиваются по горизонтали.
Названия
Существительное или короткая фраза, 1–3 слова, без точки и без глаголов («Не распределено», не «Показать не распределённые»). Регистр предложения: заглавная только первая буква. Без иконок и эмодзи.
Счётчики
Показываем число записей, если оно помогает решить, куда идти (контрагенты, операции). Для «История» и «Удалённые» счётчик не нужен. Ноль показываем как «0», а не скрываем: так видно, что раздел пуст.
Состояние вкладки
Активная вкладка хранится в адресе страницы (?tab=unalloc), чтобы ссылку можно было отправить коллеге, а «Назад» работал. Смена вкладки сохраняет поиск и период, но сбрасывает страницу пагинации на первую.
Пустой раздел
Вкладка остаётся доступной, внутри — пустое состояние с пояснением и действием («Здесь появятся операции, как только для них возникнут события»).
Один уровень
На странице один набор вкладок. Вложенные вкладки запрещены; для второго измерения (период, направление) используем переключатель-сегмент или фильтр.

Делаем и не делаем

Не делаем
Больше шести вкладок
Вкладки не помещаются, названия сокращены («Юр. лица»), смысл разделов размыт.
Делаем
Лишнее уходит в «Ещё»
Пять частых разделов видны сразу, редкие спрятаны. Названия полные.
Не делаем
Вкладки вместо фильтра
«Приход / Расход» — параметр списка, а не раздел. Для него есть переключатель-сегмент.
Делаем
Параметр списка — сегмент
Направление, период и группировка живут в панели фильтров.
Не делаем
Несколько оранжевых счётчиков
Когда внимание привлекает всё, оно не привлекает ничего.
Делаем
Один сигнал внимания
Оранжевым выделен только раздел, где нужны действия.

Вкладки, сегмент или чипы

Три похожих элемента с разной ролью. Если сомневаетесь, ответьте на вопрос: «Что меняется на экране?»

Вкладки
Разделы данных
Смена набора записей: все / не распределено / архив. Над таблицей, под заголовком.
Переключатель-сегмент
Режим просмотра
Параметр того же списка: период, направление, группировка. Находится в панели фильтров.
Чипы фильтров
Выбранные условия
Результат работы фильтров. Можно удалить, нельзя «переключить».

Доступность и клавиатура

Свойство
Значение
Правило
Роли
tablist → tab
Контейнер role="tablist" с aria-label («Представления»); каждая вкладка role="tab" и aria-selected="true|false"
Связь с содержимым
aria-controls
Вкладка указывает на панель со списком (role="tabpanel", aria-labelledby на вкладку)
Клавиатура
← → · Home · End
Стрелки переключают фокус между вкладками, Home и End — на первую и последнюю. Активируется вкладка по Enter или пробелу; в списках данных автоактивация по стрелкам запрещена, чтобы не гонять запросы
Tab
tabindex 0 / −1
В порядок обхода попадает только активная вкладка, остальные имеют tabindex="-1" и достижимы стрелками
Счётчик
aria-label
Читается вместе с названием: «Не распределено, 4». Число для «внимания» не опирается только на цвет
Контраст
≥ 4.5 : 1
