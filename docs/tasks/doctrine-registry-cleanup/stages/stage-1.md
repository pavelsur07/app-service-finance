# Этап 1. Миграция реестра

Риск HIGH-LOCAL. База `dae5c04d9`. Работы 1.1 и 1.2.

- Добавлен `site/migrations/Version20261119150000.php`. Транзакция Doctrine удерживает блокировку записи реестра между проверками и удалением. DDL и обращения к прикладным данным отсутствуют.
- `DoctrineRegistryCleanupMigrationTest` проверяет исполнитель Doctrine, точные имена, сохранность всех остальных полей и строк, схему, повторный прогон, dry-run и откат при каждом из семи отдельных нарушений предусловий.
- На исходном коммите PostgreSQL 15 применила с нуля 334 миграции. Новые тесты до реализации завершились отказом `MigrationClassNotFound`.
- После реализации проверены чистая установка 335 миграций с нулём недоступных и ожидающих версий, пустой diff `pg_dump --schema-only` и 14 интеграционных тестов Doctrine с 48 проверками.
- Репетиция обновления через CLI с четырьмя тестовыми записями дала переход 338 → 335 строк. SHA-256 остальных записей совпала, схема совпала, повторный `migrate` подтвердил актуальность.
- PHPStan, PHP CS Fixer, strict types и 5014 unit-тестов прошли. Тесты pipeline выпуска прошли, включая резервное копирование на PostgreSQL 15. Итог полного прогона указан в PR.
- Read-only сверка production показала 338 зарегистрированных версий при 334 классах в `master`. Подтверждены ровно четыре согласованные недоступные версии, ноль ожидающих, обе обязательные записи и отсутствие пяти старых таблиц. Проверена SHA-256 закрытой копии всех четырёх строк. Сверку и экспорт нужно повторить перед выпуском.

Внутреннее ревью в отдельной сессии Codex — `REVIEW_GREEN`, 0 BLOCKER и 0 IMPORTANT. По MINOR добавлен dry-run. Внешнее ревью — один завершённый раунд Codex, `REVIEW_GREEN`, 0 BLOCKER и 0 IMPORTANT. По MINOR уточнены счётчики проверок в документах. Claude CLI остановился на отсутствии авторизации. Обе сессии проверили переданные материалы статически, локальный shell ревьюера ограничен песочницей.
