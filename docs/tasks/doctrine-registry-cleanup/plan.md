# Очистка реестра миграций Doctrine

Исходная проверка на PostgreSQL 15: установка с нуля до `Version20261119140000` прошла, выполнено 334 миграции, недоступных и ожидающих версий 0. Имена четырёх устаревших версий сверены с файлами в Git-истории.

## Stage 1. Миграция реестра и приёмка

- Риск HIGH-LOCAL. База этапа `dae5c04d9`.
- Работа 1.1 — добавить интеграционные тесты и воспроизвести целевой отказ до реализации.
- Работа 1.2 — добавить транзакционную миграцию, проверить её на PostgreSQL и подготовить выпуск.

### Критерии приёмки

- Doctrine удаляет только четыре утверждённых полных имени. Схема и значения остальных строк реестра совпадают до и после.
- Установка с нуля и повторная очистка проходят. Каждое из двух отсутствующих зарегистрированных имён и каждая из пяти оставшихся таблиц отдельно приводят к полному откату при наличии устаревшей записи.
- В инструкции выпуска есть повторная сверка, проверяемый экспорт всех полей четырёх строк, проверка реестра и сервисов после релиза.

Проверки этапа — интеграционные тесты миграции и схемы, полный чистый прогон миграций, сравнение дампов схемы и штатные гейты. Ревью проверяет границу транзакции, точность сравнения версий и восстановление по экспорту. Строгий гейт `--fail-on-unregistered` оформляется отдельной задачей после выпуска.
