# Stage 1: сворачивание строк в предпросмотре ОПиУ

stage_base_commit: `26bcd26af`

## План этапа

### Какую задачу решаем

Таблица «Статья × колонки» на `/marketplace/pl-preview` всегда показывает дерево статей ОПиУ
целиком: на длинном дереве не видно картины верхнего уровня. Нужно открывать отчёт свёрнутым до
уровня 1 и раскрывать только нужные статьи.

### Что будет результатом

Только шаблон `templates/marketplace/pl_preview/index.html.twig`:

1. Страница открывается свёрнутой: видны строки уровня 1, вложенные скрыты.
2. Статья с потомками — кнопка со стрелкой (▶ / ▼): клик раскрывает её прямых потомков, повторный
   клик сворачивает всю её ветку. Механика и вид — как в отчёте ОПиУ
   (`finance/report/preview.html.twig`).
3. Над таблицей две кнопки: «Развернуть все» и «Свернуть до уровня 1».

Сервер, фильтры, теги, xlsx, блоки под таблицей, суммы и формат ячеек не меняются. Без JS таблица
показывается развёрнутой (скрытие делает скрипт).

### Что считаем выполненной работой

- У строк таблицы есть `data-level`, у статей с потомками — кнопка-переключатель.
- Начальное состояние — свёрнуто до уровня 1; по клику раскрывается только выбранная статья.
- Кнопки «Развернуть все» / «Свернуть до уровня 1» работают.
- Существующие тесты страницы зелёные, добавлен functional-тест на разметку дерева.
