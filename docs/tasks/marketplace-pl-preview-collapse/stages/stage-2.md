# Stage 2: ширина списка «Теги» в фильтре предпросмотра ОПиУ

stage_base_commit: `522558508`

## План этапа

### Какую задачу решаем

В фильтре `/marketplace/pl-preview` раскрытый список «Теги» не показывает чекбоксы: пункт несёт
`form-check` и `dropdown-item` одновременно, отступ `dropdown-item` перебивает место под чекбокс
от `form-check`, чекбокс уходит за левый край меню и обрезается прокруткой (`overflow-y: auto`).
Ширина меню не задана и зависит от содержимого.

### Что будет результатом

Только стили списка тегов в `templates/marketplace/pl_preview/index.html.twig`:

1. Меню тегов — минимальная ширина под чекбокс и название, максимальная — чтобы длинный тег не
   растягивал меню на экран.
2. Чекбокс внутри меню, рядом с названием; длинное название переносится на следующую строку.

Логика фильтра, параметры запроса, отчёт и остальные элементы формы не меняются.

### Что считаем выполненной работой

- Дефект подтверждён скриншотом «до» с несколькими тегами разной длины.
- После правки все чекбоксы видны и кликабельны, длинный тег переносится, меню не шире заданного.
- Тесты страницы зелёные.

### Чек-лист приёмки

- [x] Скриншот «до»: чекбоксы обрезаны / не видны.
- [x] Скриншот «после»: чекбоксы видны у всех тегов, длинное название перенесено.
- [x] Клик по чекбоксу в меню меняет его состояние (headless).
- [x] `PlPreviewControllerTest` зелёный; `lint:twig` — OK.
- [x] Diff — только стили / классы списка тегов и этот файл.
