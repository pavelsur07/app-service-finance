# Stage 2. Вкладки и оформление

Риск MEDIUM. База `52d0c98f6ecaef08cc93ab3d7e82a9ea248bfb35`. Работа 2.1 выполнена.

Карточка редактирования использует шапку и вкладки дизайн-системы ДДС. Twig отображает отдельные формы компании, налогов, консолидации и пересчёта. `assets/pages/company_edit.js` связывает Bootstrap Tab с якорями и историей браузера. При недоступном Bootstrap формы остаются видимыми.

- Функциональные тесты структуры и ошибки сначала воспроизвели отсутствие вкладок. Набор Company и тесты отчёта по остаткам после реализации прошли. 322 теста, 1362 проверки PHPUnit.
- Twig прошёл. 409 шаблонов, затем повторная проверка 27 шаблонов Company и общих partials. Прошли ESLint, Vite и Vitest. 152 теста. Размер JS `legacy_app` вырос с 123,92 до 125,02 кБ. Добавление к gzip — 0,30 кБ. Использован существующий Vite-вход.
- Chromium на 1440 и 390 px подтвердил переключение, стрелки клавиатуры, историю, открытие сохранённого якоря после перезагрузки, успешное сохранение и ошибку налогов, сохранение группы, модалку удаления и возврат после сохранения компании.
- Внутреннее независимое ревью выявило один IMPORTANT. При возврате из поля скрываемой панели клавиатурный фокус пропадал. Сценарий воспроизведён и исправлен в Chromium. В ответ на MINOR проверена навигация ссылками при отключённом JS Tabler.
- Внешнее ревью выявило один IMPORTANT. При скачке по истории через другой документ браузер мог восстановить панель, которая расходилась с якорем. Дефект воспроизведён. `pageshow` восстанавливает вкладку и фокус при возврате из BFCache. Проверены реальный переход и событие `pageshow`. BLOCKER отсутствуют, повторный внешний раунд не требовался.
