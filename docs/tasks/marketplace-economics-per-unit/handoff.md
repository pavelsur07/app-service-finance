# Экономика SKU. Расходы на единицу

Ветка `feat/marketplace-economics-per-unit`, [PR #3146](https://github.com/pavelsur07/app-service-finance/pull/3146), база `master`. Миграций нет.

- В SkuMetrics знаменатель равен продажам минус возвраты. Числители — себестоимость из витрины, логистика туда и обратно, расходы из колонки «Реклама». Итог рассчитывается из сумм, Money округляет результат до копейки.
- В шаблоне SKU три необязательные колонки объединены в группу «На единицу». Для полного возврата на экране выводится прочерк, в XLSX — пустая ячейка. Сохраняется формат XLSX по категориям: список SKU с названием категории и общий итог. Тот же XLSX используется в еженедельном отчёте.
- Модульные тесты MarketplaceEconomics прошли (19 тестов), функциональные тесты модуля прошли (15). PHPStan, CS, strict types, Twig (435 шаблонов), frontend lint/build и 152 frontend-теста прошли.
- На коммите реализации с последними тестами `600e1ac0d` прошли 18 проверок GitHub, включая unit и все 6 интеграционных и функциональных шардов.
