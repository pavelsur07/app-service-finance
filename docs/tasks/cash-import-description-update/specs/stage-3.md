## Результат и файлы

Доработать `site/src/Cash/Controller/Import/CashFileImportController.php` и существующие `site/templates/cash/file_import_preview.html.twig`, `file_import_queued.html.twig`, связанные экраны результата. Точное место вывода итога подтвердить по текущему пути job/log. Сохранить Twig/дизайн-систему; не переносить страницу целиком в React. JS добавлять только для нужного поведения выбора, без новых зависимостей.

## Work items

### 3.1 — сводка и просмотр

Показывать пять категорий плана, весь результат через пагинацию/фильтры, до 200 строк на страницу. Для предложения: дата, сумма, направление, документ, контрагент, источник, текущий и новый текст, объяснение возможного совпадения. Конфликт имеет понятную причину и недоступен для выбора. Длинный текст читаем полностью, служебный payload/внутренние hash в UI не выводим. Суммы форматируем существующими Twig-фильтрами.

### 3.2 — выбор

По умолчанию ни одно обновление не выбрано. Индивидуальный выбор и «Выбрать все доступные обновления» охватывают все доступные предложения текущего плана, а не только видимую страницу; подпись и общий счётчик делают это явным. Предусмотреть «Снять выбор». Пагинация/фильтр сохраняют выбор, изменение файла/счёта/mapping сбрасывает его. Сервер заново проверяет все rowId. Не добавлять массовое согласие в сохранённый профиль импорта.

### 3.3 — запуск и итог

Перед запуском показывать отдельно «Создать N операций», «Обновить M описаний», пропуски и конфликты. Нулевое число выбранных обновлений не мешает импорту новых строк. Повтор клика возвращает тот же job. Отмена не создаёт задания. Показать состояние ожидания/обработки, ошибку и завершённый фактический результат, включая stale-конфликты. Нельзя показывать прогноз как выполненный итог.

Обработать loading, empty, error; не оставлять кнопку навсегда disabled после ошибки. Сохранять escaped Twig-вывод описаний, доступные label/focus/keyboard, читаемость на мобильном экране. Авторизация/CSRF на сервере, а не только скрытые кнопки.

- [ ] Итог отражает фактическое выполнение, не preview.
