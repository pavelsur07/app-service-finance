## Summary of stages
- Stage 0 — аудит: `docs/plan/ds-legacy-tabler-audit.md`; `site/ui-kit/README.md` помечен неактуальным для легаси.
- Stage 1 — значения `--vf-*` из DS (имена сохранены), слой `--tblr-*` поверх Tabler на `:root,[data-bs-theme=light]`.
- Stage 2 — компоненты по DS-Controls / DS-Feedback; сплошные бейджи сведены к светлым парам; 72 мёртвых `.vf-*` удалены.
- Stage 3 — один источник форматирования денег (U+00A0, запятая, U+2212, копейки и ноль приглушены, приход зелёный, красный для сумм не используется); пресеты периода с серверными датами.
- Stage 4 — один partial пагинации, один partial вкладок (при >6 — «Ещё»); 20 подключений и 16 копий сведены к ним.
- Stage 5 — пилот; реестр 143 легаси-страниц: перенесено 96, на раскатку 47 (`docs/plan/ds-legacy-tabler-pages.md`).
- Сверка с листами DS: все `TODO(ds)` закрыты, кроме палитры графиков (на листах нет); расхождения поручения с листами — аудит §7a.

## Risks, limitations, follow-ups
- Затрагивается визуал всех 143 легаси-страниц (глобальный слой). Логика, роуты, имена полей, `id`/`data-*` не менялись.
- Кнопки `btn-sm` стали 30px по DS (было ~22px) — плотные тулбары станут выше.
- Строки таблиц 14px по вертикали по DS — длинные списки станут выше; компактный режим — `.table-sm`.
- Пресет «Сегодня» из фильтра ДДС убран — в наборе DS его нет.
- Месячные отчёты ДДС/ОПиУ: замена их пресетов на набор DS — вопрос продукту (аудит §7b).
- Граница поля `#c3c8d6` — 1,67:1, ниже 3:1 WCAG 1.4.11; лист её сохраняет — замечание к DS.
- FOLLOW-UP: полная сумма KPI только в `title` (не видна с тача/клавиатуры); KPI показывает код валюты, таблицы — символ; ось графика на дашборде (React) с дефисом; 500 на пустой форме операции (pre-existing, `CashTransactionDTO::$amount`).
- Раскатка остальных 47 страниц — по модулям, после подтверждения Владельца. Stage 6 (вывод `site/ui-kit/`) — отдельно, удаление — отдельное одобрение.
