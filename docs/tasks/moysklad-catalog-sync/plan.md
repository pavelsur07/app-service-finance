# МойСклад: локальная загрузка товаров и модификаций

Owner brief: после контрагентов загрузить каталог МойСклад внутрь модуля MoySklad, с независимыми курсорами, повторяемой загрузкой, статусом и ручным запуском. Контракт: [`product-variant-api-contract.md`](../moysklad-data-sync/product-variant-api-contract.md).

Baseline: `make site-test-unit` — 2945 tests, 16289 assertions, 4 existing deprecations. Первая попытка до `make site-composer-install` не запускалась из-за отсутствующего `site/vendor`; после установки зависимостей повтор пройден.

## Решения

- Храним только идентичность, имя, коды, архив, время источника и загрузки, `variantsCount` товара и нормализованные характеристики модификации. Цены, остатки, штрихкоды, налоги и произвольный ответ API не сохраняем до отдельных потоков.
- `companyId` и `connectionId` обязательны; `(connectionId, externalId)` уникален для каждого типа. Модификация ссылается на товар внутри того же подключения и компании. Если родитель отсутствует, проход модификаций не завершается успешно.
- Полный проход товаров, затем модификаций, отдельно `archived=false` и `archived=true`, страницы по 100. Курсор типа обновляется только после обоих проходов этого типа. Частичная страница сохраняется транзакционно; повтор upsert по внешнему UUID безопасен. Отсутствие в выдаче не удаляет строку.
- `order=id,asc` для модификаций принят API на пустой тестовой выборке, но отсутствует в перечне сортируемых полей документации. Проверяем строго возрастающие UUID, отсутствие повторов и размер прохода; при нарушении курсор не продвигается. Живую непустую модификацию нужно проверить отдельно до заявления о полной гарантии обхода.
- Ни один поток не пишет в МойСклад или другие модули. Запуск через `async_sync`; ошибки и журналы содержат только безопасные категории.

## Handoff

Один запуск полных gates: `make site-stan`, `make site-cs-check`, `make site-cs-strict-types`, `make site-test-unit`, `make site-test`. Затем внутренний и обязательный внешний read-only review, исправления, Draft PR → Ready. Миграция требует отдельного ручного dispatch до автоматического deploy по `docs/workflow/release.md`.
