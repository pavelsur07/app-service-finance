## Финальный внутренний review (свежая сессия)
BLOCKER/IMPORTANT нет. MINOR исправлены:
1. `edit` всегда предлагает текущего родителя. Иначе при расхождении `level`
   несвязанная правка отправила бы пустой вариант и молча вынесла ветку в
   корень.
2. Высота ветки считается по уже загруженному дереву компании, по ссылкам на
   родителя, а не через ленивые `children` (без N+1). `PLCategory::getSubtreeHeight()`
   убран: вызывающих в коде не осталось.
3. Комментарий в миграции: от цикла защищает обход от корней, а не предел.
4. Мёртвая проверка `getLevel() >= 5` в `edit` убрана.

FOLLOW-UP (вне scope, было до задачи):
- `new`: выбор родителя 5-го уровня даёт 500, потому что `setParent` срабатывает
  раньше дружелюбной проверки.
- публичный неиспользуемый `PLCategory::setLevel()` обходит инвариант.
- отчёт ОПиУ определяет группу по `level` соседней строки, а не по связи
  «родитель — потомок».
- при POST `edit` каскад лениво грузит `children` переносимой ветки: один запрос
  на узел, только при сохранении.
