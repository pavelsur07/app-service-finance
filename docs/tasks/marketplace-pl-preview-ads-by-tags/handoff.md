## Что сделано

Реклама Ozon (клики, `ozon_cpc`) и WB («Продвижение») в предпросмотре ОПиУ по тегам:
- колонки тегов — ровно по рекламной статистике модуля «Реклама» по листингам;
- «Итого» — учёт, как прежде (равно проведению);
- «Общие / без тега» — реклама листингов без тегов + остаток «учёт − статистика по листингам»;
- блок «Реклама: учёт и статистика» (учёт, статистика, на товарах, без товара, расхождение) на экране
  и на листе «Сверка» в xlsx; пометка над таблицей.

Попутно исправлен дефект выпущенного предпросмотра (#2703): правило «модуль суммы статьи» шло по
каждой колонке отдельно, и доля с обратным итогу знаком становилась вторым расходом — колонки не
складывались в «Итого». Теперь знак статьи берётся по итогу, доли линейны (`natureBaseColumn`).
