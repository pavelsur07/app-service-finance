## План этапа

### Решения

1. **Пометка над таблицей** (если в отчёте есть сверка рекламы): «Реклама Ozon (клики) и WB
   („Продвижение“) в колонках тегов — по рекламной статистике; реклама без товара и разница с
   учётом — в „Общих“». Без неё пользователь не поймёт, почему «Общие» по рекламе не равны
   прежним.
2. **Блок «Реклама: учёт и статистика»** после «Сверки затрат»: по маркетплейсу — учёт, статистика,
   на товарах, без товара, расхождение (учёт − статистика), суммы `vf_amount`, «₽» в заголовке.
   Расхождение ≠ 0 — без красного (DS-Money), с подсказкой о возможных причинах: учёт за дни, которых
   нет в статистике, недельные удержания WB, предоплата рекламы.
3. **xlsx** — на листе «Сверка» раздел «Реклама: учёт и статистика» с теми же колонками, числами.
4. Блок и раздел не выводятся, если рекламы под статистикой в отчёте нет.
