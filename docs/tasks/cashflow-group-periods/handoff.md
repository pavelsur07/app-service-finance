# ДДС группы по периодам — передача к выпуску

Ветка `claude/cashflow-group-periods`, [PR #3135](https://github.com/pavelsur07/app-service-finance/pull/3135), база `master`. Миграций нет.

## Результат

- Групповой отчёт открывается по месяцам. Доступны недели, кварталы и годы. Один запрос агрегирует движения, одна сверка обслуживает весь диапазон. Для входящих RUB-остатков используется общий с отчётом компании регистр. Число чтений регистра проверено на двух и трёх компаниях.
- Выбор шага ограничивает таблицу 36 колонками, сверх 36 лет экран и прямой URL экспорта возвращают HTTP 200 с формой коррекции. Оба вида требуют права владельца всех компаний группы.
- Ноябрь на фикстуре P1 совпадает с разрезом по компаниям до копейки по каждой строке. Межпериодная пара 40 000,00 ₽ видна в пути в ноябре и декабре и элиминирована в итоге диапазона. Остаток на конец декабря 2 142 283,03 ₽.
- Заголовок или сумма на экране открывают детализацию периода. XLSX сохраняет тип денег единым способом для обоих видов. В книге доступны переходы из заголовков и строк сверки.

Реализация находится в `site/src/Cash/{Application,Controller,Infrastructure,Facade}`, `site/src/Shared/Service/ReportPeriodCalendar.php`, `site/src/Report/Cashflow/CashflowReportBuilder.php` и `site/templates/cash/report/cashflow_group*`. Тесты находятся в Cash Unit, Integration и Functional. Публичный контракт и Changelog обновлены в `ARCHITECTURE.md`. Из PHPStan baseline удалены две более не нужные записи.

## Приёмка и ревью

- Phase 0 — 16 тестов, 125 проверок. Stage 1 — модульные тесты 472/1557 и интеграционные 552/2474. Stage 2 — functional Cash 315/2044, браузерный smoke в Chromium при 390 и 1440 px. По P4 проверены 10 лет кварталов, 36 и 37 годовых колонок. По P6 проверены числовая ячейка 123,45 и точный текст 9007199254740992,01 в реальном XLSX.
- Полные гейты — PHPStan, CS, strict types, unit 5045/27082, полный PHPUnit 9881 тест и 55 470 утверждений. Поправки после ревью проверены отдельно: периоды и чтение регистра 8/102, фасад, исходный ДДС компании и XLSX 55/351. TwigCS и синтаксис 431 шаблона, ESLint, Vite build и Vitest 152/152 прошли.
- Внутреннее ревью — итого 0 BLOCKER, 2 IMPORTANT. Исправлены граничная дата из другой зоны и число гиперссылок, зависевшее от числа статей. Финальная проверка исправлений в отдельной сессии дала REVIEW_GREEN.
- Внешнее ревью — два раунда на двух точках, Stage 1 и handoff. В сумме 0 BLOCKER, 3 IMPORTANT. Уточнён и протестирован P6, устранены отдельные запросы остатков по участникам. Замечание об отсутствии ARCHITECTURE.md в переданном diff отклонено после проверки реального diff к master: контракт и запись 2.254 присутствуют, wrapper передаёт только код. Подтверждённые замечания исправлены и проверены без повторного внешнего раунда. Claude CLI не авторизован, оба раунда — отдельные read-only сессии Codex по переданному diff и синтетическим материалам. Проверки запускала реализующая сторона.
