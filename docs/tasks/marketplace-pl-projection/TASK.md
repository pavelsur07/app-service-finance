# `MarketplacePlProjection`: ОПиУ маркетплейсов из канона

Продолжение `docs/tasks/marketplace-profit-pipeline` (раздел «Дальше»). Решения — `DATA.md` §9.3–9.4
той задачи.

## Задача

Считать ОПиУ маркетплейсов по дням из канона `mo_operation` и показывать рядом с легаси.

## Решения Владельца (16.11.2026)

- **Только реализация, без переключения.** Модуль ничего не пишет в документы ОПиУ, `pl_daily_totals`
  и закрытие месяца. Отчёты, бюджет и план-факт читают легаси. Переключение — отдельной задачей,
  когда сверка сойдётся.

## Как считается

- Строка проекции: компания × кабинет × проект × статья × день → сумма.
- Проект — из настройки кабинета (как в легаси); кабинет без проекта — предупреждение.
- Статья — по правилу компании; приоритет: код источника (`source_type`) → вид × канал → вид (`kind`).
- Правила нет → сумма в строке «не сопоставлено»; правило без статьи → «исключено из ОПиУ».
- Тождество дня: Σ проекции + исключённое + не сопоставленное = Σ канона.
- Знак — как у документов `marketplace_pl`: доходная статья получает сумму канона, расходная — с
  обратным знаком.
- Дерево и итоги для экрана — `FinanceFacade::calculatePlPreview()`, без записи документов.

|---|---|---|---|
| 1 | Правила компании, шаблон платформы, подбор статьи | миграция | в работе |

План и итог этапа — `stages/stage-N.md`.

## Что не делаем

- Переключение ОПиУ на новый расчёт и удаление легаси-закрытия месяца.
- Себестоимость: в каноне её нет, в легаси её считает отдельное закрытие.
- Сверку с выплатами — это `MarketplaceReconciliation`.

## Чек-лист приёмки задачи

- [ ] Тождество «канон = проекция + исключённое + не сопоставленное» по каждому дню каждого кабинета.
- [ ] Повторный пересчёт и повторный перенос не меняют счётчики строк.
- [ ] Смена правила пересчитывает только своё окно; шаблон не перезаписывает правила `custom`.
- [ ] Легаси нетронуто: документы ОПиУ, `pl_daily_totals`, закрытие месяца — счётчики до и после равны.
- [ ] Сверка с легаси по всем кабинетам: расхождения объяснены.
- [ ] PHPat: модуль знает только фасады; канон, переводчики и экономика о маппинге не знают.
