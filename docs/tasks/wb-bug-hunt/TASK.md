# WB bug hunt: поиск и исправление дефектов в интеграции с Wildberries

## Owner brief (чат, 2026-09-04)

«Поиск багов и исправление работа с WB».

Конкретный список дефектов не задан. Источники для поиска, принятые агентом:

- открытые инциденты GlitchTip (`./gt.sh list`);
- бэклог `docs/plan/my_paln_app.md`, раздел «Текущие ошибки системы»;
- read-only аудит кода WB-путей в модулях Ingestion, Marketplace,
  MarketplaceAds, Inventory, MarketplaceAnalytics тремя независимыми
  агентами; каждая находка перепроверена по коду до правки.

## Scope

- Исправлять только дефекты, подтверждённые чтением кода и покрытые
  регрессионным тестом, красным на старом коде.
- Не менять финансовые формулы, знаки, периоды и маппинг категорий.
- Не расширять конвенции модулей (messenger-семантика Inventory) без
  решения Владельца — такие находки идут в FOLLOW-UP.
- Production не трогать; read-only проверка прода не запрашивалась.

## Acceptance criteria

- Каждое исправление доказано красным регрессионным тестом.
- Полный unit-прогон и интеграционные тесты затронутых модулей зелёные.
- PHPStan level 8 и php-cs-fixer по изменённым файлам зелёные.
- Внешнее ревью Codex завершено `REVIEW_GREEN`.
- Неисправленные находки перечислены в handoff с причиной.
