## 1. Какую задачу решаем

Довести исправление до данных прода: маппинги в БД и `source_data` уже
загруженных транзакций by-day (2026-05-17 … сегодня, 4 компании).

## 2. Что будет результатом

- Миграция `Version20261018120000` применена; деплой кода.
- `_ozon_category_*` у транзакций типов 29, 45, 46, 71, 78, 84 указывают на новые
  статьи; суммы и число живых строк не изменились.

## 3. Что считаем выполненной работой

1. Замер «до» в день ремонта (сверить с `measurements/before-transactions.txt`).
2. `gh workflow run deploy.yml --ref master -f production_action=migrations`,
   проверка схемы и маппингов (16 строк изменены, 16 записей аудита), затем
   `-f production_action=deploy`.
3. Для каждой компании: `codex-console app:ingestion:ozon-accrual:daily-maintenance
   --from=2026-05-17 --to=<вчера> --company-id=<uuid> --dry-run`, затем `--execute`.
4. Сверка «после».
