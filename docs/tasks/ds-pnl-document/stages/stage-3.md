# Stage 3 — редактирование: каркас страницы

## 1. Какую задачу решаем
Привести страницу `document_edit` к раскладке макета (SPEC §3, §4, §6) —
заголовок, карточки, правая колонка, sticky-панель, меню «Ещё», модалки —
сохранив роуты, имена полей, CSRF и `data-*`-хуки текущего `_page.html.twig`.

## 2. Что будет результатом
- Заголовок «Документ ОПиУ № …», крошки «Доходы и расходы / Документы ОПиУ /
  № …», бейдж «Есть несохранённые изменения».
- Сетка `minmax(0,1fr) 320px`: слева «Основные данные» (дата, период, номер,
  контрагент, Проект *, ЦФО, описание со счётчиком «N из 500») и «Основание»
  (операция ДДС, только чтение); справа sticky «Сверка с основанием»
  (По ДДС / Распределено / Остаток, статус, «Добавить операцию на остаток»);
  «История» — нет бэкенда, не показываем.
- Проект/ЦФО/Контрагент в шапке — общий вид `.dds-field` и логика поиска
  как на странице операции ДДС.
- Sticky-панель: статус «Все изменения сохранены» / «Есть несохранённые
  изменения», «Отмена», «Сохранить» (неактивна без изменений).
- «Ещё»: только работающее — «Дублировать документ», «Открыть операцию ДДС»
  (если основание есть), «Выгрузить JSON», «Удалить документ».
- Модалки «Выйти без сохранения?» и «Удалить документ?», `beforeunload`.
- Общие partial/CSS/JS страницы — переиспользуемые формой создания (Stage 6).

## 3. Что считаем выполненной работой
Страница правки совпадает с `pnl-refs/01`, `06`, `07` по раскладке и текстам
(шапка и правая колонка; таблица — Stage 4); сохранение, удаление, копия, JSON
работают как раньше; существующие тесты `document_*` зелёные.

## 4. Чек-лист приёмки (CHECKLIST A, B, E)
- [x] Только legacy-слой; `_layout/app.html.twig`, `assets/react/**`, `site/ui-kit/` не тронуты
- [x] Роуты, имена полей, CSRF, `data-*` не изменены (diff по списку из Stage 0)
- [x] «Проект *» и «ЦФО» в «Основных данных», плашка-подсказка на месте
- [x] Проект/ЦФО/Контрагент выглядят как на операции ДДС, поиск работает
- [x] Sticky-панель; «Сохранить» неактивна без изменений
- [x] Модалки «Выйти без сохранения» и «Удалить документ»; `beforeunload`
- [x] Меню «Ещё» — только работающие пункты (functional: ссылки/формы ведут на существующие роуты)
- [x] «История изменений» не показана (нет данных)
- [x] «Сверка с основанием» и «Добавить операцию на остаток» считают как раньше
