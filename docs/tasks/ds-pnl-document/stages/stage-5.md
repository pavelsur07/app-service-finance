# Stage 5 — валидация, удалённый документ, адаптив, гейты, handoff PR 2

## 1. Какую задачу решаем
Довести страницу правки до приёмки: ошибки клиента и сервера в одном виде,
удалённый документ, адаптив 1440/1280/1100/390, доступность, замеры «после»,
гейты, отчёт и handoff PR 1 + PR 2.

## 2. Что будет результатом
- Сводка «Не удалось сохранить: N ошибки. Исправьте отмеченные поля.» со
  списком и фокусом на первом ошибочном; красные рамки и тексты под полями
  (включая рамку виджета категории); ошибки сервера выводятся так же
  (скрин 04); «Шапка: выберите проект».
- Блокировка сохранения при расхождении с основанием — текущее правило.
- Удалённый документ: баннер + «Восстановить» (`document_restore`), поля
  только для чтения — как сейчас ведёт себя сервер.
- Тосты «Документ сохранён» / «Изменения отменены».
- Адаптив: ≤1340 правая колонка под основной; 1100; 390.
- Отчёт `docs/plan/ds-pnl-document.md`: аудит, сделано/отложено, запросы
  до/после, скриншоты «до/после» 01–08 в 1440 и 1280 + 390, заполненный
  чек-лист, открытые решения SPEC §8.
- Гейты и handoff: PR 1 и PR 2, единственный вопрос — «merge and deploy #N».

## 3. Что считаем выполненной работой
CHECKLIST разделов A–E, G, H для правки отмечен с доказательствами; гейты
зелёные (или честно записано, что не прогнано и почему); PR открыты.
