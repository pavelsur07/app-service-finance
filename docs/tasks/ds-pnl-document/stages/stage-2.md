# Stage 2 — виджет «Категория ОПиУ» в строках операций

## 1. Какую задачу решаем
Заменить select «Статья ОПиУ» в каждой строке документа виджетом дерева
«Статьи ДДС», не копируя его: виджет должен жить в нескольких экземплярах,
появляться в строках, добавленных «Добавить операцию» и «Дублировать», и брать
направление из select типа своей строки.

## 2. Что будет результатом
- `assets/dds_tree_picker.js` расширен без второй копии: direction-source
  строится от строки (селектор относительно контейнера строки или атрибут
  с именем поля строки); инициализация новых строк — вызов
  `initDdsTreePickers(row)` из кода добавления/дубля строк
  (`_page_scripts.html.twig`) или MutationObserver; открыт один popover на
  странице; путь выбранной категории под полем; подпись «Категория ОПиУ»,
  тексты «Найти категорию», «Категория не найдена…», «Категории для расхода».
- Дубль строки копирует выбранную категорию и пересоздаёт виджет (без
  ссылок на DOM исходной строки).
- `dds-pickers.css` — только недостающее (ширина popover 440, путь под полем,
  на мобильной — ширина ячейки); цвета через блок алиасов `--vf-*`.
- e2e `site/tests/e2e/pnl-category-picker.e2e.cjs` на демо или стенде:
  несколько экземпляров, динамическая строка, дубль, смена типа строки,
  только листья, поиск, клавиатура, XSS.
- Functional: страница правки рендерит виджет поверх
  `select[name="document[operations][N][category]"]` для каждой строки и в
  `data-prototype`.

## 3. Что считаем выполненной работой
Все пункты CHECKLIST D выполняются на странице правки документа (e2e + functional);
e2e виджета «Статьи ДДС» (`dds-tree-picker.e2e.cjs`) и страница операции ДДС
работают как раньше; без JS форма отправляет обычный select.
