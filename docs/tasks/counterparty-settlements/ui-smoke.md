# Проверка интерфейса взаиморасчётов

Пять HTML-страниц, отрисованных реальным test kernel на синтетическом наборе:
сводка, карточка контрагента, документы, документ, новая форма. Fixture-транзакция
отменена после получения HTML. Бизнес-действия и авторизация проверены отдельно BrowserKit.

Использованы уже имеющиеся Playwright1.56.1 и browser image; зависимости не добавлялись.
Offline snapshots с исходными стилями действующей DS, без внешних сетевых запросов.
Разрешения1440×1000 и390×844, всего10экранов:

- горизонтальное переполнение всей страницы отсутствует, таблицы прокручиваются внутри регионов;
- каждое поле имеет подпись или aria-label; клавиатурный фокус видим;
- нет ошибок JavaScript; формы сохраняют серверные ошибки и введённые данные;
- суммы в копейках через vf_money/vf_amount, поля суммы передают точные строки;
- после внутренних фиксов карточка не содержит неограниченного списка позиций,
  таблица-подсказка формы ограничена50строками с переходом ко всем документам.

Результаты размеров и фокуса: ui-smoke.json. Локальные скриншоты:
site/var/settlement-smoke/{index,card,documents,document,form}-{1440,390}.png.
Снимки используют fallback шрифта и локальную загрузку ресурсов; production assets
не менялись. Внешние шрифты/ресурсы не проверялись этим offline smoke.
