# Передача в выкладку

В ВашФинДир добавлен `hermes-web` для точного HTTPS callback панели `hermes.vashfindir.com`. Docker-конфигурация из штатного пайплайна передаёт в PHP-FPM полный список клиентов. Подтверждение остаётся за фактическим владельцем компании с тарифом.

В CI отслеживается этот commit. После выкладки требуется проверить публичную MCP discovery, наличие точной регистрации и веб-вход в Hermes. Конфигурация удалённой панели на момент передачи отдельно не подтверждена. Владелец сообщил, что доступен только интерфейс Hermes.
