# Веб-вход удалённого Hermes в MCP ВашФинДир

Основание — настроить OAuth для `hermes.vashfindir.com`, оставив пользователю вход и согласие. База `303e861ff`.

Hermes Dashboard v0.23.3 принимает собственный callback `/api/mcp/oauth/callback/{server_name}`. Для MCP-записи `vashfindir` регистрируется один точный HTTPS-адрес и клиент `hermes-web`. В конфигурации Dashboard используется его публичный адрес. Порт loopback относится к отдельной существующей регистрации. [Исходный код Hermes](https://github.com/NousResearch/hermes-agent/blob/v0.23.3/hermes_cli/web_routers/mcp.py#L67-L79)

## Этап 1. Точный HTTPS callback на стороне ВашФинДир

Риск HIGH-LOCAL. База `303e861ff`.

**Результат.** OAuth принимает HTTPS callback, явно зарегистрированный за `hermes-web`, и продолжает принимать три действующих loopback-регистрации.

- [x] Тест Symfony от запроса с PKCE до согласия, редиректа и обмена кода. Другие host/path и callback другого клиента отклоняются.
- [x] Тест конфигурации требует явный HTTPS host и path. Шаблоны, URL с учётными данными, параметрами и fragment отклоняются.
- [x] Тест выкладки проверяет доставку полного списка OAuth-клиентов в PHP-FPM. Тесты подтверждают совместимость новой версии с предыдущим списком клиентов.

## Этап 2. Браузерный OAuth на стороне Hermes

Риски HIGH-LOCAL и HIGH-EXTERNAL.

**Результат.** С веб-страницы Hermes пользователь возвращается автоматически после входа в ВашФинДир и согласия.

- [x] На стенде MCP-запись `vashfindir` использует `hermes-web` и штатный HTTPS callback. Проверены старт авторизации в Dashboard, согласие тестового владельца, callback, обмен кода и MCP-каталог.
- [ ] Ревью и полный CI. Штатная выкладка Finance, применение целевой конфигурации в Hermes и проверка точного callback.
- [x] Для других инстансов требуется отдельный точный зарегистрированный callback. Инструкция для оператора зафиксирована один раз. Пользовательские финансовые данные на стенде отсутствуют.

**Вне текущей настройки.** Саморегистрация произвольных доменов, wildcard callback, изменение прав и тарифов, модельный провайдер и новое разрешение для хранения реестра в БД. Существующие локальные callback сохраняются.
