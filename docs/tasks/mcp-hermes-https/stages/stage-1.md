# Этап 1. HTTPS callback ВашФинДир

База `303e861ff`. Результат этапа — регистрация одного точного HTTPS callback и совместимость с тремя локальными клиентами.

- Исходный набор OAuth — 16 тестов и 200 утверждений. Новый сценарий отклонял HTTPS до исправления. Тест выкладки выявил отсутствующую регистрацию.
- После исправления набор MCP — 60 тестов и 355 утверждений. Проверены чужой хост, другой путь, другой клиент и неверный callback при обмене кода. Отклоняется список с одной невалидной записью.
- Прошли `test-release-pipeline`, `test-deploy-workflow`, `test-frontend-release` и `test-frontend-auth-routing`. Проверена передача списка в PHP-FPM. Миграций нет.
- При откате старый образ выкатывается через revert вместе со списком без HTTPS. Старая версия с новым списком отключит OAuth.

Внутреннее ревью — BLOCKER 0, IMPORTANT 0, MINOR 2 устранены. Дополнены тесты точного адреса и документация провайдера входа.
