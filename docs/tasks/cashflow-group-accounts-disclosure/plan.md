# «Данные по счетам» — понятный раскрывающийся блок

## Задача
Владелец 26.11.2026: в отчёте ДДС группы не видно, что «Данные по счетам» кликабельно. Согласованы практики 1–6.

## Результат
1. Шеврон слева, поворот при раскрытии.
2. Строка-шапка: курсор-рука и фон при наведении, кликабельна вся строка.
3. Сводка в заголовке: «N счетов», бейдж «N отстают», если есть отстающие.
4. Текст действия справа: «Показать» / «Скрыть».
5. Блок открыт по умолчанию, если есть отстающие счета; иначе свёрнут.
6. Нативные details/summary, видимый фокус с клавиатуры.

Компонент `vf-disclosure` в `vf-custom-classes.css` — для повторного использования.
