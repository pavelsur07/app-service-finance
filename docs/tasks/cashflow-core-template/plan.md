# cashflow-core-template: базовые статьи ДДС для новой компании

Класс задачи: Large (межмодульная — Cash и ai-service, контракт ai-task/v1).
Ветка: `feat/cashflow-core-template`. Baseline — в checkpoint.md.

## 1. Задача

При создании компании заводить ядро статей ДДС, одинаковое для всех видов бизнеса и профилей.
У каждой статьи — группа деятельности, направление и описание «Что входит и почему», по
которому ИИ-автораспределение выбирает статью. Связь со статьями ОПиУ сейчас не ставится:
описание заканчивается пометкой «ОПиУ: …» (решение Владельца 08.11.2026).

## 2. Как сейчас (проверено в коде 08.11.2026)

- `CompanyCreatedEvent` диспатчится внутри `wrapInTransaction()` после flush компании
  (`CreateCompanyOwnerAccountAction`, `CompanyController::new`); сбой подписчика откатывает компанию.
- `EnsureCashflowSystemCategoriesAction` создаёт только системный каркас: три группы деятельности,
  «Технические операции» с «Поступления»/«Выбытия», «Не распределено». Рабочих статей нет.
- `CashflowCategory` уже имеет `description` и `operationType` — миграция не нужна.
- ИИ описание статьи не видит: `CashCategorizationQuery::findLeafCategories()` отдаёт путь и
  направление, схема ai-service `Category` — `extra="forbid"`, поля `description` нет.
- В деплое сайт перезапускается раньше ai-service: отправку описания нельзя выпускать в одном
  деплое с приёмом — новый сайт получил бы отказ старого сервиса.

## 3. Результат

- Новая компания видит 30 рабочих статей ДДС в 7 группах поверх системного каркаса,
  у каждой описание с пометкой «ОПиУ: …».
- ИИ-автораспределение получает описание каждой статьи компании.
- Существующие компании не меняются.

## 4. Содержание

Файл `site/config/cash/cashflow_templates/core.yaml` — источник правды для названий и описаний.

| Группа | Статей | ОПиУ напрямую | со сдвигом периода | не попадает |
|---|---|---|---|---|
| Операционная / Поступления | 3 | 1 | 0 | 2 |
| Операционная / Выплаты | 13 | 9 | 3 | 1 |
| Операционная / Выплаты / Налоги | 4 | 1 | 0 | 3 |
| Финансовая / Поступления | 2 | 0 | 0 | 2 |
| Финансовая / Выплаты | 3 | 2 | 0 | 1 |
| Инвестиционная / Поступления | 3 | 2 | 0 | 1 |
| Инвестиционная / Выплаты | 2 | 0 | 0 | 2 |
| Итого | 30 | 15 | 3 | 12 |

Системные «Поступления»/«Выбытия» технических операций новой компании получают описание.
