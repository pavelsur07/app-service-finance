# Этап 2. Переключатель «ИИ» в админке

## Задача
Дать администратору включать и выключать ИИ для кабинета вручную.

## Результат
- В `/admin/users`, столбец «Кабинеты»: у каждого кабинета отметка «ИИ вкл» / «ИИ выкл».
  Нажатие — диалог подтверждения (включение предупреждает о платных вызовах LLM в ближайший
  cron :25), затем POST.
- `POST /admin/ai/companies/{companyId}/access` (ROLE_ADMIN, CSRF) →
  `SetAiCompanyAccessAction`: включить — строка (повтор и гонка → тот же результат),
  выключить — удаление строки. Лог INFO с `companyId` и администратором.
- Возврат на ту же страницу списка с фильтрами, flash.

## Что считаем выполненным
Код в той же ветке, functional-тесты, ручная проверка страницы на локальном стенде.

## Чек-лист приёмки
- [x] functional: админ включает → строка есть, отметка «ИИ вкл»; выключает → строки нет
- [x] повторное включение → одна строка (идемпотентность)
- [x] не-админ → 403; неверный CSRF → 403; несуществующая компания → 404
- [x] страница списка: статус ИИ одним запросом на страницу
- [x] при `AI_SERVICE_ENABLED=false` отметка видна, но подписана «сервис выключен»
