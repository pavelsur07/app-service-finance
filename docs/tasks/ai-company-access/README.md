# Подключение компаний к ИИ из админки

Поручение Владельца 05.11.2026: в админке, в списке кабинетов, администратор вручную
подключает компанию к ИИ-функциям или отключает её. Переменную
`AI_SERVICE_COMPANY_ALLOWLIST` заменить хранением в БД (сделать агенту).

Было: доступ решал `AiServiceAccess` по env `AI_SERVICE_COMPANY_ALLOWLIST` (GitHub variable,
значение — только Вумджой `19621cff-b028-45d9-9193-11f47ad9a8b2`), смена — правка
переменной и деплой.

| Этап | Что | Файл |
|---|---|---|
| 1 | Доступ компании к ИИ хранится в БД, env-список удалён | [stage-1.md](stages/stage-1.md) |
| 2 | Переключатель «ИИ» у кабинета в `/admin/users` | [stage-2.md](stages/stage-2.md) |
| 3 | Выкат: миграция, деплой, сверка, удаление GitHub variable | [stage-3.md](stages/stage-3.md) |

Этапы 1–2 — один PR (миграция), этап 3 — его выкат.

включений. Общий выключатель `AI_SERVICE_ENABLED` остаётся.
