правил WB без статьи (≈72 тыс. ₽ с 01.09). Статей шаблона у компании нет, правил WB

Правило: образцы для `pl_code` шаблона сначала из своего маркетплейса (как в
#2608). Если там нет ни одного — правила других маркетплейсов той же компании,
чей код в шаблоне *их* маркетплейса имеет тот же `pl_code`; только при
единогласии. Разнобой внутри своего маркетплейса чужими образцами не
перекрывается. Только частичный режим (ночной sync-default).

«Логистика возвратов», product_processing → «Хранение на складе МП» (≈55 тыс. ₽);
storage, warehouse_logistics (образцы Ozon разнесены по двум статьям) и penalty (нет
образцов) остаются гейту.
