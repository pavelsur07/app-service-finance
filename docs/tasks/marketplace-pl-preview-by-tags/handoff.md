## Risks, limitations, follow-ups

- Модуль суммы статьи регистр берёт по «дню документа × проект», предпросмотр — по колонке за
  период: на многомесячном периоде, где сторно затрат статьи в одном месяце больше начислений,
  предпросмотр и сумма ежемесячных документов могут разойтись. На одном месяце и одном проекте —
  совпадают.
- «Реализация» Ozon входит, только если документ целиком внутри периода (как у проведения):
  произвольный период внутри месяца реализацию не покажет.
- Предупреждение о подключении без проекта не вычитает такие суммы из предпросмотра — только
  сообщает, что при проведении они в отчёт ОПиУ не попадут.
- Решение Владельца: вкладка открыта всем с `MARKETPLACE_READ` и показывает расчётное дерево ОПиУ
  с KPI. Отчёт ОПиУ в Finance закрыт финансовым доступом. Если пользователи только маркетплейсов
  видеть его не должны — добавить `FINANCE_READ` на оба контроллера (одна строка в каждом).
- Сверка затрат почти тавтологична: ловит только задвоение строк в джойне правил; для продаж
  тождества сумм нет (одна продажа даёт несколько сумм по разным правилам).
- FOLLOW-UP: пресеты периода (`vf-seg`) на 375 px переносятся по ширине компонента — общее для всех
  страниц.
