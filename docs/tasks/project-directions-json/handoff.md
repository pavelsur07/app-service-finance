# Справочник проектов и JSON-обмен

Ветка `feat/project-directions-json`. PR [#3072](https://github.com/pavelsur07/app-service-finance/pull/3072), база `master`.

## Изменения

- Код до 15 символов с нормализацией и уникальностью по компании, многострочное описание до 300 символов. Поля доступны в формах, код также в списке.
- JSON v1 для всего дерева активной компании. Импорт создаёт и обновляет по UUID. Данные проектов вне файла сохраняются. Системный проект сохраняет внутренний `systemCode`.
- Предпросмотр проверяет файл и будущее дерево, показывает итог и ошибки по записям. Последний успешный предпросмотр действует 15 минут для пользователя, сессии и компании. Подтверждение повторно проверяет файл под блокировкой записи и применяет изменения одной транзакцией.

Основные файлы — `site/src/Company/Application/ProjectDirection/`, `ProjectDirectionController.php`, `ProjectDirectionType.php`, `site/templates/project_direction/` и тесты `ProjectDirectionControllerTest`, `ProjectDirectionExchangeControllerTest`, `ProjectDirectionImportTest`.

## Миграция

`Version20261119130000` добавляет nullable-поля, индекс уникальности и ревизию справочника. Применена после миграции воронки `Version20261119120000` на тестовом PostgreSQL 15. Схема соответствует маппингу. Откат удаляет новые поля вместе с заполненными значениями. Для production действуют резервная копия и отдельный ручной `release` по `docs/workflow/release.md`.

## Ревью

- Внутреннее — 0 BLOCKER и 2 IMPORTANT, оба исправлены и перепроверены. При проверке правок подтверждены бюджет разбора JSON, повторная загрузка большой выгрузки, сохранность `systemCode` в БД и отклонение предпросмотра после удаления проекта.
- Внешнее — по одному раунду на этапах 1 и 2 и на передаче. Всего 0 BLOCKER и 4 IMPORTANT. Три исправлены и перепроверены. Пункт о загрузке частями сохранён как FOLLOW-UP за пределами утверждённых двух POST-запросов. Fixed without re-run. Claude CLI не авторизован. Отдельный read-only Codex проверил переданные диффы. Локальное чтение ревьюера ограничивалось bwrap.

## Граница загрузки

Выгрузка охватывает весь справочник. Загрузка использует действующий лимит одного запроса PHP и nginx в 32 МиБ, включая служебные данные multipart. Обмен проверен для 8 000 проектов и выгрузки больше 8 МиБ.
