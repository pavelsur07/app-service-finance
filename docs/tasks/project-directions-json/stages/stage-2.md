# Этап 2. Формы и JSON-обмен через браузер

Риск HIGH-LOCAL. База этапа `da762a6c8`. Задачи 2.1 и 2.2 выполнены.

- Twig-формы принимают код и многострочное описание. Список показывает код, выгрузку и загрузку с проверкой модульных прав.
- Предпросмотр показывает количества и ошибки по записям. Последний успешный предпросмотр хранится в Redis 15 минут и привязан к пользователю, сессии и компании.
- Подтверждение проверяет CSRF, однократно забирает токен, выполняет импорт и выводит итог в списке.

Тесты новых HTTP-маршрутов, импорта, прав и схемы прошли (32 теста, 269 проверок). Twig прошёл для 410 шаблонов. Chromium проверил шесть состояний на ширинах 375 и 1440 px, включая выбор файла, действия в списке, предпросмотр, ошибки и сортировку при выборе родителя. Проверка CSS и JS выполнена на HTML Symfony и собранных ресурсах. Запись через HTTP проверена отдельными функциональными тестами. Сборка Vite, ESLint и 152 теста Vitest прошли.
