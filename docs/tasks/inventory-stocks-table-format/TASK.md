# inventory-stocks-table-format: оформление таблицы отчёта «Остатки»

Дата: 2026-11-06. Владелец: «остатки только целые — делай задачу» после списка
предложений в чате. Классификация — Small (один шаблон, Query без схемы).

## Зачем

Таблица `/inventory/stocks` печатает числа сырыми (`12.000`), заголовки смешивают
русский с английским («Дата-время snapshot», «mappingStatus»), все колонки
выровнены одинаково, статус сопоставления выводится ключом (`unmapped`). Отчёт
читается как отладочный вывод; после появления переключателя FBO / FBS в нём
сравнивают числа, и глазу нужна опора.

## Решения Владельца

- **Остатки — целые.** Количества выводятся без дробной части: `vf_number`
  с нулём десятичных, разряды через U+00A0, минус U+2212. Три знака в колонке
  БД — артефакт типа, в интерфейсе не показываются.

## Результат

- Заголовки по-русски: «Снимок», «Источник», «SKU», «Артикул продавца»,
  «Остаток», «Резерв», «Доступно», колонки разбивки, «Сопоставление».
  Числовые заголовки и ячейки — `text-end`, табличные цифры (`vf-table .vf-num`).
- «Доступно» — главная цифра строки (`vf-strong`); отрицательное «Доступно»
  (резерв больше остатка) — `text-danger`. Ноль в колонках разбивки — «—».
- Статус сопоставления словами: «Сопоставлен» / «Не сопоставлен» /
  «Неоднозначно», цвета прежние (`StockSnapshotMappingStatus::label()`).
- SKU и артикул — `font-monospace`; дата снимка без секунд, полное время в `title`.
- Колонки разбивки сгруппированы вторым рядом шапки под заголовком «В том числе».
- Итоги: строка `tfoot` «Итого на странице» и общий итог по фильтру
  (`InventoryStockReportQuery::getTotals()` → `StockReportTotals` DTO:
  quantity, reserved, available) над таблицей.
- Шапка `sticky-top`, `scope="col"`, скрытый `caption`; «Резерв» и «Артикул»
  скрываются на узких экранах (`d-none d-md-table-cell`).
- Пустое состояние подсказывает сменить дату или схему.

## Не в объёме

- Копирование SKU в буфер, экспорт — отдельно, если понадобится.
- Запросы отчёта, фильтры и данные не меняются; новый метод только суммирует
  те же строки, что и страница.
