«Выручки с СПП» за октябрь у ИП, компания `b57d7682…`.
Реализация кода и изменение production этим запросом не заказаны.

  нетто 9 266 291,33 ₽;

  возвраты 133 488,44 ₽, нетто 18 532 582,66 ₽;

  `REV_SPP_SALES` / `REV_SPP_RETURNS`, типы и природа статей корректны;

Доказана двойная запись обработанной реализации. Код допускает её при
параллельных вызовах: общая блокировка отсутствует в Action, существующая
Redis-блокировка находится только в автоматическом Handler. Конкретные
пересёкшиеся запросы историческими логами не установлены.

Исправление должно сохранить законные повторяющиеся строки исходного
отчёта, формулы денег, маппинги, WB и данные других компаний/месяцев.
Сначала устранить возможность повторения, затем отдельно восстановить
production с резервной копией и явным одобрением по AGENTS.md §3.3.
