# Этап 5. Замер: что не размечено в ОПиУ

## Задача
Снять текущую картину: какие категории затрат маркетплейсов у каких кабинетов остаются без
статьи ОПиУ после ночного `sync-default`, сколько денег за ними, почему автоматика не угадала
(нет образцов, разнобой, нет статьи в дереве компании).

## Результат
`measurements/stage-5.md`: таблица «кабинет × категория × сумма × причина» за текущий и прошлый
месяц; набор для evals — решения Владельца по прошлым случаям (#2608, #2609, #2724, #2822, 19621cff).

## Что считаем выполненным
Понятно, сколько случаев в месяц решает человек и сколько из них ИИ мог бы предложить; если
случаев почти нет — часть B сворачивается с этим выводом, этапы 6–8 не делаются.

## Чек-лист приёмки
- [ ] read-only замер по всем активным кабинетам, дата снятия
- [ ] набор evals ≥ 20 случаев с ответом Владельца
- [ ] вывод «делать / не делать часть B» с цифрами
