# Этап 2. Переводы между своими счетами не уходят в ИИ

## Задача
Операции с фразой перевода собственных средств (`measurements/stage-1.md`) исключить из
кандидатов категоризации до отправки в сервис, если компания сама такие операции никогда не
разносила в статью (иначе её решения станут примерами на этапе 3).

## Результат
Признак в `CashCategorizationQuery` (SQL, без LLM); такие операции не отправляются и не
оплачиваются; на странице «ИИ» кабинета — счётчик «похоже на перевод, не отправлено».

## Что считаем выполненным
Тесты: фраза без образцов компании → не кандидат; фраза при образцах компании, депозит,
«перевод под отчёт» → кандидаты. На проде: у `fbebb285` 110 операций не отправляются, у `b57d7682` — отправляются.

## Чек-лист приёмки
- [ ] тест: «Перевод собственных средств…» у компании без образцов → не кандидат
- [ ] тесты: образцы компании, депозит, «перевод под отчёт» → кандидаты
- [ ] счётчик на странице «ИИ» кабинета
- [ ] гейты CS, PHPStan, затронутые тесты зелёные
