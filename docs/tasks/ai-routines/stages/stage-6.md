# Этап 6. Задача ИИ `suggest_pl_line`

## Задача
Новый тип задачи в ai-service: вход — категория затрат (код, название, маркетплейс, примеры
сумм), листья дерева ОПиУ компании (путь, код, направление), правила компании по соседним
категориям; выход — статья ОПиУ или null, уверенность. Вызов из Marketplace только для
категорий, которые ночная автоматика не разметила.

## Результат
Задача в сервисе с проверками (статья — только лист дерева компании, направление расход);
таблица подсказок в Marketplace (миграция); отправка через `AiTaskFacadeInterface` с учётом
расхода, лимитов и журнала; evals на наборе этапа 5.

## Что считаем выполненным
На наборе этапа 5 точность при уверенности ≥ 0,8 не ниже 80 %; повторный запуск не создаёт
дублей (unique по компании и категории); стоимость в `ai_usage`.

- [ ] Symfony: повтор → те же строки; бюджет исчерпан → не отправляется
- [ ] миграция добавляющая, обратимая
- [ ] evals на наборе этапа 5 в отчёте этапа
