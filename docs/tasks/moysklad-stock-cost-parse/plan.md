# Оценка складов МойСклад падает на себестоимости

**Задача.** 28.11.2026 у Сухоносова (b57d7682) оценка снимка 01a222ff упала за 0,25 с с `invalid_response`
на первой странице `report/stock/all`; оценок 0 — колонка «Остаток по себестоимости» на вкладке «Склады» пустая.
Парсер бросал исключение на всю страницу при отрицательной/`null` себестоимости одной позиции, причину не логировал.

**Результат.** Позиция с отрицательной или `null` себестоимостью — «без себестоимости» (`missing`): склад
оценивается и показывается с предупреждением, в Баланс не проводится. Отказ ответа логируется с `detail`
(`page_meta` / `row_identity` / `price_format`).

**Готово.** Регрессионный тест красный на старом коде и зелёный на новом; unit MoySklad, CS, PHPStan (CI) зелёные; выкачено.
