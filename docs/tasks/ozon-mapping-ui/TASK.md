# Понятная настройка Ozon
Владелец согласовал только предложение UI в чате: понятные подписи четырёх видов
продаж/возвратов, бизнес-описание источника, единый конфликт с кнопкой точечного
исправления и подтверждением, состояние реализации, запрет повторного конфликта.
Область: экран /marketplace/pl-mappings с marketplace=ozon и необходимые обработчики.
WB, другие экраны, формулы, категории, исторические документы, cron/CI/config не менять.
GET ничего не исправляет. Только подтверждённый POST пользователя с MARKETPLACE_WRITE
и CSRF может отключить конфликтующие legacy-правила на тех же статьях, где активны
корректные реализации. Не создавать правила молча, не менять суммы/статьи/знаки.
