# Маппинг МойСклад: доводка по эталону «Операции ДДС»

Продолжение `plan.md` (PR #3083). Эталон — `templates/transaction/index.html.twig`,
`_filter_bar`, `_row`; нейтральные классы DS (`vf-page-head`, `vf-seg`, `vf-bar`,
`vf-applied`/`vf-chip`, `vf-empty`, `vf-sub`/`vf-strong`) — `vf-custom-classes.css`.
Только вёрстка: контроллеры, URL-параметры, Action'ы и миграции не меняются.

## 1. Задача

После #3083 страница отличается от эталона: шапка Tabler вместо `vf-page-head`, два ряда
вкладок подряд, 3–5 блоков до таблицы (плашки, «Параметры»), до трёх кнопок в строке,
фильтры очереди — три select'а с «Применить», дублирующие вкладки, счётчик сбоку,
поиск не виден чипом, пустое состояние строкой таблицы, шапка таблицы не липнет.

## 2. Результат

1. `moy_sklad/layout`: `vf-page-head` — крошки «Интеграции › МойСклад › {заголовок}», `h1`,
   блок `integration_lead`, кнопки `btn-list`. Затрагивает все страницы МойСклад.
2. Разделы «Подключения / Маппинг Ozon / Маппинг WB» — сегмент `vf-seg` (`data-moysklad-tabs`),
   единственный ряд вкладок страницы маппинга — очередь в карточке.
3. Над таблицей: одна плашка-предупреждение (идёт проверка / ошибка / устарело — тексты
   видимы целиком, без тултипов); «Проверено … из …, дата» — в строке итогов `vf-bar`;
   «Параметры сопоставления» — offcanvas по кнопке «Параметры» в шапке, открыт сразу,
   если идёт поиск характеристики (`char_q`/`char_page`).
4. Строка: стрелка «Подробнее» у названия (collapse), кнопка Выбрать/Изменить/Просмотр,
   меню «⋯» с «Историей» (если есть ревизии). Колонка действий уже.
5. Очередь: вместо трёх select — сегмент «Требует проверки / Все» (`diag_manual`), состояние
   и причина задаются вкладками.
6. `vf-bar`: «Найдено N листингов» со склонением (+ «· Проверено …» в очереди).
7. `vf-applied`: чип «Поиск: «…»» с крестиком и «Сбросить всё».
8. Пустое состояние — блок `vf-empty` вне таблицы с действием («Сбросить поиск»,
   «Все листинги»); пагинация и таблица скрыты при нуле строк. Призыв запустить
   диагностику — в строке итогов.
9. `thead.sticky-top`.
10. Вторые строки ячеек — `vf-sub`, название — `vf-strong`; «Требует проверки» —
    `vf-ops-badge-warn`.

## 4. Чек-лист приёмки

1. На всех страницах МойСклад шапка `vf-page-head` с крошками и `h1`, раздел — сегментом.
2. На странице маппинга один ряд вкладок (очередь), до карточки — максимум одна плашка.
3. «Параметры» открывают боковую панель; поиск характеристики открывает её сразу.
4. В строке не больше одной текстовой кнопки; «История» — в меню «⋯».
5. В очереди нет select'ов; «Требует проверки / Все» переключается одним кликом.
6. Строка итогов: «Найдено 1 листинг / 3 листинга / 25 листингов».
7. Поиск виден чипом и снимается крестиком.
8. Ноль строк — блок с действием, без пустой таблицы и пагинации.
9. Шапка таблицы прилипает при прокрутке.
10. Ошибка и устаревание диагностики видны текстом без клика.
11. Тесты MoySklad зелёные.
