# Рефакторинг UI маппинга МойСклад (Ozon / Wildberries)

Страница: `/moy-sklad/connections/{id}/mappings/{ozon|wildberries}`
(`MoySkladListingMappingsController`, `templates/moy_sklad/mappings/index.html.twig`).
Эталон визуала — «Операции ДДС» (`/finance/cash-transactions`) и общий легаси-слой
`vf-card` / `vf-table` / `vf-ops-*` / `partials/_tabs`.

## 1. Задача

Сейчас на странице две таблицы (диагностика и листинги), три поиска, три пагинации
и по абзацу пояснений в каждом блоке. В строке диагностики 5–10 строк «доказательств»
(штрихкоды, количества, кандидаты), строки широкие и нечитаемые. Непонятно, что не
сопоставлено и что нажать.

## 2. Результат

- Одна таблица, две вкладки-режима через `partials/_tabs` со счётчиками `.cnt`:
  - очередь по последней диагностике: «Требует внимания» (по умолчанию, `.cnt.warn`),
    «Предложения», «Несколько кандидатов», «Размер», «Комплектация», «Нет совпадений»,
    «Все проверенные»;
  - «Все листинги» — живой список с поиском.
- Строка в 1–2 линии: Листинг (название с обрезкой + SKU · размер) · Артикул ·
  → Позиция МойСклад (живая связь) · Статус (бейдж `vf-status` + причина) · действия.
- Доказательства и кандидаты — в раскрывающейся строке-деталях (Bootstrap collapse,
  без своего JS); причина видна в строке, не в тултипе.
- Шапка раздела: кнопки «Обновить диагностику» и «Подобрать на странице» (предпросмотр
  автосопоставления, только в режиме «Все листинги» — бэкенд работает по странице).
- Состояние диагностики — короткие плашки (идёт расчёт / ошибка / устарело / нет отчёта).
- «Параметры сопоставления» — свёрнутая панель: одна характеристика размера
  (поиск + выбор, GET, общая для диагностики и предпросмотра), галка W для WB,
  правила автосопоставления списком.
- Одна пагинация: `page` для «Все листинги», `diag_page` для очереди.
- URL-параметры прежние (`q`, `page`, `diag_*`, `char_*`, `sizeCharacteristicId`) +
  `view=queue|all`. Поиск переключает на «Все листинги».

Не трогаем: Action'ы, правила сопоставления, права, CSRF, страницы «Разобрать» и
«История», массовые действия (отдельно, по запросу).

## 4. Чек-лист приёмки

1. После завершённой диагностики страница открывается на «Требует внимания»,
   у вкладок счётчики из отчёта.
2. «Все листинги» — все листинги маркетплейса с поиском и пагинацией по 25.
3. Строка не выше двух линий текста при длинном названии; полный текст — в `title`.
4. Причина спорной строки видна без клика; штрихкоды и кандидаты — по «Подробнее».
5. В очереди колонка «Позиция МойСклад» показывает текущую связь, а не снимок.
6. Характеристика размера выбирается в одном месте и уходит и в диагностику, и
   в предпросмотр.
7. Пользователь с правом чтения не видит кнопок изменения; «Выбрать» → «Просмотр».
8. Без диагностики — режим «Все листинги» и плашка «Запустите проверку».
9. Каталог МойСклад не загружен — плашка с переходом к подключениям.
10. WB: галка W в параметрах сохраняется как раньше; у Ozon её нет.
11. Существующие функциональные тесты MoySklad зелёные (адаптированы к одной таблице).
