# Этап 2 — строка «Не распределено по товарам» (issue #2940)

Этап 1 (подписи) — PR #2939, на проде 08.11.2026.

## Задача
«Итого» таблицы «Unit — Экономика» не включает затраты маркетплейса без привязки
к товару (хранение, маркетинговые акции, отзывы, упаковка), а карточки над
таблицей — включают. Прибыль в «Итого» завышена на эту сумму.

## Результат
- Между строками товаров и «Итого» — строка «Не распределено по товарам»:
  затраты с `listing_id IS NULL`, разложенные по колонкам «Комиссия»,
  «Логистика», «Прочие» по тем же правилам, что у товаров.
- «Итого» включает эту строку; прибыль, маржа, ROI считаются с ней.
- Рекламные статьи учёта, которые покрывает статистика (`ozon_cpc`,
  «WB Продвижение», `AdStatisticsCostCategories`), в строку не входят:
  реклама в «Итого» по-прежнему из статистики (паритет с «Эффективностью»,
  `UnitExtendedAdSpendConsistencyTest`).
- С фильтром по тегам строки нет (затраты без товара к тегу не относятся —
  как в карточках).
- Строка есть в Excel-выгрузке.
- Подписи этапа 1 уточнены: остаточная разница карточек и «Итого» — только
  источник рекламы.

## Решение вне этапа
Перевод рекламы «Итого» на учёт не делается: за октябрь у одного кабинета Ozon
учёт 0,41 млн против статистики 1,52 млн — сначала разобрать эту разницу.
Перенос страницы из `_legacy/` в `modules/` — отдельно, правка точечная, как
в предыдущих PR страницы (#2939, ABC, «Сред. чек»).

## Что считаем выполненным
Код, тесты, ARCHITECTURE.md, PR на handoff; на проде у кабинета из жалобы
(Ozon, ноябрь) «Итого» прибыль = карточки ± (учёт рекламы − статистика).
