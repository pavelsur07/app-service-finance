# Этап 3 (A) — карточки = «Итого» таблицы (issue #2940)

Этапы 1 (#2939, подписи) и 2 (#2941/#2942, строка «Не распределено») на проде.
Решение Владельца 09.11.2026: на экране одна прибыль; реклама везде по статистике
рекламного кабинета, начисления маркетплейса по рекламе — справкой под карточкой;
группы карточек — как колонки таблицы. Пункт 2 issue #2940 («реклама в деньгах —
по начислениям») этим решением отменён.

## Задача
Карточки над таблицей «Unit — Экономика» (`WidgetSummaryQuery`) считают рекламу по
начислениям маркетплейса, а «Итого» таблицы (`UnitExtendedQuery`) — по статистике.
Поэтому на экране две разные «Прибыли», пользователь не понимает, какая верна.
Группы карточек («Вознаграждение», «Услуги партнёров»…) не совпадают с колонками
таблицы, сверить их глазами нельзя.

## Результат
- Карточки: Выручка, Возвраты, Себестоимость, Комиссия, Логистика, Реклама, Прочие,
  Прибыль. Каждая равна одноимённой величине «Итого» таблицы (в P&L-знаке: расход < 0),
  с фильтром тегов и без него.
- Реклама в карточке — статистика: без тегов вся за период (как `totals.adSpend`),
  под тегами — сумма по листингам набора. Под карточкой без тегов — «по начислениям
  маркетплейса: X ₽» (учётные рекламные категории `AdStatisticsCostCategories::codes()`).
- Учётные рекламные категории не входят ни в одну группу затрат — ни в карточках,
  ни в строках товаров таблицы (раньше строки товаров их не исключали: при привязке
  к листингу реклама считалась бы дважды).
- Листинг, у которого в периоде есть только расход на рекламу, — строка таблицы
  (иначе под тегами его реклама терялась в «Итого», но была бы в карточке).
- Сноска «реклама в карточках по начислениям…» убрана.
