# Stage 2. Таблица и действия

Риск MEDIUM. База `0d6be346997d0b65a774e84b5a64afee6380f93b`. Работа 2.1 выполнена.

`site/templates/company/index.html.twig` использует общие классы оформления операций ДДС. В активном списке видны наименование, ИНН, система налогов и НДС. Для отсутствующих значений показан прочерк. Меню ведёт в редактор и на подтверждение удаления. Карточка компаний, ожидающих удаления, показывает дату и кнопку восстановления.

- Два функциональных теста до правки Twig воспроизвели отсутствие новой шапки и пустого состояния. Набор функциональных и интеграционных тестов Company после правки прошёл. 315 тестов, 1291 проверка PHPUnit до добавления двух проверок числа запросов.
- `make site-cs-twig`, `npm run lint`, `npm run build`, `npm run test:unit` прошли. 409 шаблонов Twig и 152 теста Vitest.
- Chromium на ширине 1440 и 390 px. Сверены размер заголовка и радиус карточки со страницей ДДС. Проверены прокрутка внутри карточки, открытие меню с клавиатуры, переход к удалению и восстановление. Первый прогон обнаружил прокрутку всей страницы из-за скрытой подписи столбца действий. После переноса подписи в `aria-label` сценарий прошёл.
- Итоговое внутреннее ревью в отдельной сессии не выявило BLOCKER и IMPORTANT. По MINOR добавлены проверки числа SQL-запросов в `CompanyTaxProfileFacadeTest`. Браузерный сценарий проверил доступность мобильного меню.
- По внешнему IMPORTANT добавлена пагинация активного списка по 20 компаний. Пакет профилей запрашивается для текущей страницы. Тест с 21 компанией до изменения получил 21 вместо 20 строк. После изменения прошли 26 целевых тестов, 205 проверок PHPUnit. Повторные проверки PHPStan, PHP CS Fixer, Twig и Chromium прошли.
- Итоговое внутреннее ревью после пагинации не выявило BLOCKER и IMPORTANT. По двум замечаниям MINOR название компании добавлено в доступное имя кнопки восстановления, а функциональный тест проверяет, что идентификатор компании со второй страницы отсутствует в параметрах запроса первой.
