# Список компаний в дизайн-системе операций ДДС

Исходная проверка `CompanyTaxProfileFacadeTest` и `CompanyDeletionTest` прошла. 13 тестов, 92 проверки PHPUnit.

Визуальные ориентиры — список операций ДДС, список контрагентов на общих классах ДДС и таблица документов взаиморасчётов.

## Stage 1. Данные списка

- Риск MEDIUM. База `0d6be346997d0b65a774e84b5a64afee6380f93b`.
- 1.1 Покрыть интеграционным тестом пакетную выборку и подключить её к списку владельца.
- Критерий приёмки — один запрос профилей по идентификаторам компаний из списка. Для каждой компании выбирается профиль на текущую дату по существующему правилу. Компании без действующего профиля отсутствуют в результате.
- Проверки — интеграционные тесты налоговых профилей, PHPStan, стиль PHP.
- Фокус ревью — изоляция владельца, дата начала периода, пустой список и отсутствие N+1.

## Stage 2. Таблица и действия

- Риск MEDIUM. База `0d6be346997d0b65a774e84b5a64afee6380f93b`. Дифф этапа отсчитывается от реализации Stage 1 в рабочем дереве для выполнения требования одного коммита на задачу.
- 2.1 Добавить функциональное покрытие и применить общие классы шапки, карточки, таблицы и пустого состояния.
- Критерий приёмки — «Наименование», «ИНН», «Система налогов», «НДС». Прочерк для отсутствующих данных. Доступны добавление, редактирование, удаление и восстановление. Горизонтальная прокрутка ограничена карточкой. После внешнего ревью добавлен критерий пагинации активных компаний по 20 строк.
- Проверки — функциональные тесты списка и удаления, Twig, визуальная проверка на широком и узком экране.
- Фокус ревью — доступность действий, экранирование названий, порядок столбцов и пустое состояние.
