# Список компаний

Ветка `feat/company-list-design-system`. [Pull request и проверки GitHub](https://github.com/pavelsur07/app-service-finance/pulls?q=is%3Apr+head%3Afeat%2Fcompany-list-design-system).

- `CompanyController`, `CompanyRepository` и `CompanyTaxProfileRepository` ограничивают список владельцем и текущей страницей. Действующие налоговые профили страницы читаются одним SQL-запросом.
- `site/templates/company/index.html.twig` использует оформление «Операций ДДС» для шапки, таблицы и пагинации. Активный список показывает 20 компаний на страницу. Отдельная карточка даёт восстановить компании, ожидающие удаления.
- Тесты проверяют колонки, данные нескольких компаний, налоговые периоды, изоляцию владельцев, пагинацию и число запросов.
- Миграции и изменения публичного API отсутствуют.

## Проверки

- Итоговые тесты Company прошли. 316 тестов, 1307 проверок PHPUnit.
- Прошли `make site-stan`, `make site-cs-check`, `make site-cs-strict-types`, `make site-test-unit`, `make site-cs-twig`. После замечаний повторно прошли фокусные PHPStan, PHP CS Fixer и Twig. Unit-набор включает 4986 тестов.
- Прошли `npm run lint`, `npm run build`, `npm run test:unit`. 152 теста Vitest. На локальном стенде Chromium проверены ширины 1440 и 390 px, прокрутка, меню, удаление и восстановление.
- Штатный `make site-test` остановился при записи Composer в `vendor`. Прогон с установленными зависимостями показал ошибки записи в `var/storage` и захватил промежуточную редакцию Twig в уже запущенном процессе. Итог повторного полного прогона с отдельным каталогом `var` фиксируется в PR.
