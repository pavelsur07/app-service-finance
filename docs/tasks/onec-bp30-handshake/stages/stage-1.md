# Этап 1. Подключение и рукопожатие

База 66177baf1, риск HIGH-LOCAL. Проверки уровня HTTP, базы и политики поддержки находятся в site/tests/{Functional,Integration,Unit}/OneC. PostgreSQL сериализует рукопожатия одной базы по строке подключения. Уникальный индекс защищает от дублирования базы у одного владельца.

Внутреннее ревью обнаружило отсутствие межмодульных FK в описании схемы и потребность в проверке конкурентных запросов. OneCSchemaExtension добавлена, разница схемы пуста. HandshakeLockTest проверяет ожидание на отдельном соединении. Проверка проходит вместе с функциональным тестом возврата 409. Новая миграция создаёт две таблицы, повторный handshake не удаляет организации. Синтетические номера релизов в тестах нужны для проверки границ совместимости.
