# Удаление подтверждённого мёртвого кода

Ветка `chore/remove-confirmed-dead-code`, база `master`, [PR #3159](https://github.com/pavelsur07/app-service-finance/pull/3159).

## Результат

- Удалены пустые классы scoring, закрытый метод клиента WB, резервный шаблон главной и пять файлов старого экрана аналитики.
- Удалены два устаревших Action Ozon и их делегаты. Внутренний интерфейс обработки целого документа используется в ручном действии и шаге затрат конвейера. В реестре сохранён выбор по типу записи, маркетплейсу и формату. Шесть записей PHPStan сняты вместе с удалённым кодом.
- Проверены продажи и возвраты через processBatch и затраты через process. Интеграционный тест подтверждает запись комиссии заказа при ручном вызове и изменение суммы после шага Messenger.
- Новых миграций и изменений публичного API, формул и CI нет. Ссылки на удалённые символы остались только в исторической документации и комментарии старой миграции.

## Проверки

- Symfony lint:container, проверка WB и главной страницы (46 тестов), twigcs и lint:twig (438 файлов) прошли.
- Vitest 159/159, ESLint и Vite прошли. Имя и размер бандла аналитики совпали с исходными. Chromium отрисовал заголовок и пустое состояние, показал переданный маркетплейс и запросил список. Вывод tsc совпал с исходным построчно (TS2303 и два TS2339 в старом Dashboard).
- Тесты Marketplace 1685/1685, PHPStan по затронутым файлам, PHP CS Fixer и strict_types прошли. Модульный набор PHPUnit — 5066/5066. Для интеграционных тестов временное локальное хранилище смонтировано в контейнере с правами его пользователя.

## Ревью и ограничения

Независимое внутреннее ревью полного diff — 0 BLOCKER, 0 IMPORTANT. Внешнее ревью — отдельные read-only сессии Codex, поскольку Claude CLI не авторизован. Stage 3 — два раунда, окончательный по переданным исходникам и diff после ограничения bwrap. Handoff — один раунд по полному пакету, REVIEW_GREEN. Суммарно 0 BLOCKER, 0 IMPORTANT. Исправлены три MINOR в ожиданиях тестов: null для формата ручного вызова, виды записей как в конвейере, фиксированные адреса обоих исторических API. 24 целевых теста прошли после последней правки.

Ручная переобработка через MarketplaceSyncFacade (включая ReprocessCostsMessageHandler) исторически не передаёт api_endpoint и выбирает v3 для Ozon. Отдельный шаг ProcessRawDocumentStepMessageHandler учитывает формат документа. Приёмка ручного пути проверяет v3. Изменение ручного выбора для by-day требует отдельной задачи.

Полный `make site-stan` прошёл. Первый `make site-test` выполнил 9959 тестов. Четыре сценария чтения журналов упали из-за отсутствия прав записи тестового пользователя в var/log. С отдельным временным каталогом журналов весь класс MarketplaceAdsLogsControllerTest прошёл (8 тестов, 35 проверок). Результат полного повторного прогона и статус CI фиксируются в PR.
