# Этап 2. Категории в реестре листингов

Модуль `Marketplace` · риск MEDIUM (UI и HTTP, схема не меняется).

## Задача

Дать пользователю завести категории, назначить их листингам Ozon и WB и
отфильтровать реестр по категории.

## Результат

- Вкладка «Категории» (`/marketplace/listings/categories`): список с числом листингов, создание,
  переименование, удаление. Обычные формы с CSRF и flash. Удаление используемой категории —
  диалог в blocked-режиме со ссылкой «Показать листинги».
- Реестр `/marketplace/listings`: колонка «Категория», фильтр `?category=<uuid>|none`,
  в панели массовых действий — выбор категории («Снять категорию» — отдельный пункт);
  «все N по фильтру» — через диалог подтверждения, как у тегов.
- `POST /api/marketplace/listings/categories/assign` (`MARKETPLACE_WRITE`):
  `{listingIds (до 500) | filter, categoryId: uuid | null}` → `{matched, changed, categoryName}`.
- `ListingsFilter`: `categoryId`, `withoutCategory`; `MarketplaceListingsQuery` фильтрует по ним.

## Что считаем выполненным

Функциональные тесты зелёные, сценарий прошёл в браузере на локальном стенде,
гейты (stan, cs, twig, frontend lint) по изменённым файлам чистые, ARCHITECTURE обновлён.
