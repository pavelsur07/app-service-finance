# Выдержка: условия подписок Anthropic, OpenAI и Kimi для ночного воркера

Подготовлено агентом 2026-10-13 по поручению Владельца (§9 `TASK.md`).
**Решение Владельца (2026-10-13): вариант C — работа на подключённых CLI
по подписке, без платных API-ключей; риск принят (§9 `TASK.md`).** Это не юридическое заключение; условия меняются,
перед пилотом сверить даты обновления по ссылкам.

## Что говорят условия

1. **Какие условия действуют.** Pro и Max — Consumer Terms; Team, Enterprise и
   API — Commercial Terms ([Claude Code: Legal and compliance][legal]).
2. **Consumer Terms запрещают автоматический доступ**, «кроме доступа по API-ключу
   Anthropic или там, где мы явно это разрешили» (§3.7), и коммерческое
   использование: «не использовать Сервисы в коммерческих или деловых целях»
   (§11) ([Consumer Terms][consumer]).
3. **OAuth-вход по подписке** предназначен «для обычного использования Claude
   Code». Разработчикам, которые строят продукты и сервисы, включая сервисы на
   Agent SDK, следует входить по API-ключу из Claude Console. Лимиты Pro и Max
   рассчитаны на «обычное индивидуальное использование» ([legal]).
4. **Автоматизацию подписка технически поддерживает:** `claude setup-token`
   выпускает токен для скриптов и CI. `claude -p` на подписке расходует лимиты
   плана. Изменения от 15.06.2026 приостановлены ([Agent SDK with your plan][sdk]).
5. **В Max с 07.10.2026 входят ежемесячные API-кредиты:** $100 в Max 5x, $200
   в Max 20x. Они покрывают `claude -p` и Agent SDK, если запуск идёт по
   API-ключу привязанной организации Console. Кредиты не переносятся на
   следующий месяц. В Pro их нет ([API credits][credits]).

## Как это ложится на план

Воркер — функция коммерческого продукта VashFinDir. Он обрабатывает данные
клиентов и работает автоматически по расписанию. Это ближе к случаю
«разработчик строит сервис», для которого предписан API-ключ, чем к «обычному
индивидуальному использованию». Таким образом, вариант «подписка Владельца
через `CLAUDE_CODE_OAUTH_TOKEN`» расходится с пп. 2–3.

## Варианты

| Вариант | Соответствие условиям | Расход |
|---|---|---|
| A. API-ключ Console, привязанной к Max | соответствует: доступ по API-ключу, Commercial Terms | сначала месячные API-кредиты Max, сверх них — по тарифу API |
| B. API-ключ OpenAI или Kimi (§3.5) | у Anthropic вопроса нет; условия OpenAI и Moonshot сверить отдельно | по тарифу провайдера |
| C. Подписка через `setup-token` (текущий §9) | противоречит пп. 2–3 | лимиты плана, общие с разработкой |

Рекомендация агента — **вариант A**. Код не меняется: в `worker.env` вместо
`CLAUDE_CODE_OAUTH_TOKEN` прописывается `ANTHROPIC_API_KEY`. Хватит ли кредитов на пилот (2 компании,
7 ночей), видно по `usage.costUsd` первых ночей. Ночная работа перестаёт делить
лимиты с дневной разработкой.

## OpenAI: подписка ChatGPT и Codex CLI (сверено 2026-10-13)

- Пользовательские условия OpenAI для индивидуальных сервисов запрещают
  «автоматически или программно извлекать данные или Output» ([Terms of Use][oai-tou]).
- Документация Codex: для автоматизации по умолчанию правильный путь — API-ключ.
  Вход по аккаунту ChatGPT в `codex exec` описан как продвинутый вариант
  «только на доверенных раннерах»; `~/.codex/auth.json` требуется беречь как
  пароль ([Codex non-interactive][oai-exec]).
- Токены доступа для неинтерактивной работы от имени аккаунта ChatGPT есть
  только у рабочих пространств Business и Enterprise ([Codex access tokens][oai-tokens]).

Вывод: технически `codex exec` по входу ChatGPT работает, но для личной
подписки это автоматизация вне её назначения. Для бизнеса предусмотрены
API-ключ или Business-пространство.

## Kimi: подписка Kimi Code (сверено 2026-10-13)

- Льготы Kimi Code предназначены «только для личной разработки и не могут
  использоваться в корпоративных сценариях»; для корпоративных задач Kimi
  отсылает на Kimi Open Platform ([Kimi Code benefits][kimi-benefits]). Цитата
  взята из поисковой выдачи по официальной странице; сама страница при проверке
  перенаправила на общий раздел документации — перед пилотом перечитать.
- Подписку можно использовать только в Kimi CLI и в агентах, которые Kimi
  разрешает. Подмена идентификатора клиента (User-Agent) считается нарушением
  и может привести к приостановке льгот ([Kimi Code docs][kimi-docs]).
- Квоты: окно 5 часов и недельные кредиты; модель K3 доступна с тарифа Moderato.

Вывод: запрет самый явный из трёх. Ночная обработка данных клиентов
коммерческого сервиса — корпоративный сценарий.

## Итог по трём провайдерам

Все три подписки рассчитаны на личное использование. Воркер — автоматическая
функция коммерческого продукта на данных клиентов, и с этим назначением он
расходится у всех трёх; сильнее всего у Kimi. Санкции — от ограничения
лимитов до приостановки аккаунта, без предупреждения (Anthropic это пишет
прямо). Владелец принимает риск (решение 2026-10-13).
