# Браузерная приёмка

Chromium 1234 из уже установленного Playwright 1.62.1, ширины 1440 и 375 px.
Проверяются реальные HTML, полученные Symfony functional rendering с изолированными
тестовыми компаниями, и собранный production legacy bundle с Tabler CDN. Это
проверка DOM/CSS/JS; отправка бизнес-форм проверена функциональными HTTP-тестами.
Новых зависимостей не установлено. Временные harness, HTML и снимки находятся
в игнорируемом `site/var/balance-smoke/`.

20 экранов: Баланс, Счета, Документы, Движения, Сравнение, Периоды, Настройка,
Права, Статьи, создание статьи/счёта/документа, изменение счёта, карточки
счёта/статьи, установка остатка, проведённый документ, сторно, история, ошибка.

Проверки:
- Legacy shell и Tabler загружены; ошибок JS нет.
- Document не прокручивается по горизонтали; 11 таблиц имеют локальную
  прокрутку на мобильной ширине.
- «Ещё» открывается, Escape закрывает; active состояния дополнительно проверены HTTP-тестами.
- Пресеты меняют исходные from/to без навигации.
- Добавление/удаление строки, фокус на новом select, предварительный итог 100,25.
- Диалог архивации переносит action/CSRF/archive, фокусируется на «Отмена».
- Мобильное меню изначально закрыто, открывается/закрывается по кнопке.

Найдены и исправлены: subtitle слипался с h1 из-за display:flex Tabler;
общий d-flex sidebar обходил collapse (правка действует только на balance_*).
Финальный повторный рендер из исходников и browser smoke 15.11.2026: PASS, 40/40 экранных проверок. Ошибок JS и горизонтального выхода документа за viewport нет.
