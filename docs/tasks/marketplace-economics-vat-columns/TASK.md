# Экономика SKU: выручка с СПП, НДС, СМ % и выбор колонок

Поручение Владельца 21.11.2026, согласовано в тот же день.

## 1. Задача

Отчёт `/marketplace/economics` («Экономика SKU»):

- столбцы «Выручка с СПП», «НДС к уплате», «Выручка без НДС»;
- СМ1, СМ2, СМ3 — за вычетом НДС (каскад как в ОПиУ эталонного кабинета Владельца):
  `Выручка → НДС = Выручка с СПП × ставка / (100 + ставка) → Выручка без НДС = Выручка − НДС → СМ1 → СМ2 → СМ3`;
- столбцы «СМ1, %», «СМ2, %»; «Маржинальность СМ3, %» → «СМ3, %»; проценты и ДРР — от выручки до СПП;
- окно выбора отображаемых столбцов.

## 2. Результат

- `SkuMetrics`: `vat`, `revenueWithSpp()`, `revenueNet()`; `gross()` и уровни СМ — от выручки без НДС.
- Ставка — `CompanyTaxProfileFacadeInterface::taxProfileOn()` на начало каждого месяца периода
  (`VatMode::ratePercentOn`); смена режима внутри периода учитывается.
- НДС — в SQL точной арифметикой, округление по SKU × день: R1 и R2 (любой шаг) дают один итог.
- «СПП, ₽» = СПП + соинвестирование; удержание WB за рекламу (`ads_settlement`) туда больше не попадает.
- Колонки: обязательные — SKU, Наименование, Продано, Выручка, СМ1, СМ2, СМ3 (с разнесением), СМ3 % (без разнесения — СМ2 %);
  остальные — галочками, по умолчанию все включены, выбор в `localStorage`.
- Те же уровни в «Динамике», xlsx и еженедельном отчёте (общий `SkuMetrics`); xlsx — все колонки.
