## Что сделано
- Ночной `sync-default` (частичный режим): если статьи шаблона у компании нет вовсе,
  правило получает статью, куда компания единогласно относит свои включённые правила

- Аудит INFO `код => статья` выведенных правил; вывод команды «по образцу компании».
- UI и ручная команда без изменений.
