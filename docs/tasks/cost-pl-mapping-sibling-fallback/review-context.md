## Решения
- Один образец считается единогласным: Владелец согласовал таблицу, где корректировка
  услуг следует единственному образцу (утилизация → «Прочие удержания МП»).
- `is_negative`/`include_in_pl` берутся из шаблона, не из образца.
- Выведенное правило следующей ночью само становится образцом с той же статьёй —
  стабильно; если человек перенесёт образец, возникнет разнобой и вывод прекратится
  (fail-safe).
- Схема: категория уникальна по (company_id, marketplace, code); маппинг — по
  (company_id, cost_category_id).
