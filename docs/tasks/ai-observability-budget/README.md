## Решения по умолчанию (меняются без кода, кроме общего лимита)
- Лимит компании — 500 ₽ в календарный месяц (МСК), администратор меняет на странице кабинета.
  Порядок цен: deepseek-flash ≈ 6 ₽ за 1000 операций, т. е. лимит — предохранитель, а не тариф.
- Общий лимит на все компании — 5000 ₽/мес, параметр `ai.monthly_limit_rub` в `services.yaml`.
- Глубина выгрузки — 7 / 30 / 90 дней (по умолчанию 90, как сейчас).
- Лимит проверяется перед запуском по компании: стоимость приходит с импортом раз в 5 минут,
  поэтому перерасход — не больше одного запуска (до 200 операций, порядка 1 ₽ на deepseek-flash).

Вне задачи: пункты 3–6 разбора (согласие и маскирование, правила до LLM, поэтапное включение,
запасной провайдер), уведомления владельцу кабинета о лимите.
