# Этап 1. Учёт результатов и стоимости

## Задача
Знать, сколько стоит ИИ каждой компании: сейчас токены приходят в результате ai-service, но
нигде не сохраняются, а записи задач удаляются после импорта.

## Результат
- Таблица `ai_usage` (ServiceGateway): строка на принятый результат — `task_id` (unique),
  компания, тип задачи, статус, модель, токены вход/выход, стоимость в ₽ (null — цена модели
  неизвестна), время результата.
- Запись — в `ImportAiResultsAction`, в той же транзакции, что потребитель результата
  (`ON CONFLICT (task_id) DO NOTHING` — повтор импорта не задваивает).
- Цены — параметр `ai.prices` в `config/packages/ai_prices.yaml` (копия `services/ai-service/config/prices.yaml`);
  тест сверяет копию с файлом сервиса.
- `AiTaskFacadeInterface::spentThisMonth(companyId)` и `spentThisMonthTotal()`.

## Что считаем выполненным
Код, миграция, тесты в ветке `feat/ai-observability-budget`.

## Чек-лист приёмки
- [ ] импорт результата пишет строку `ai_usage` с токенами и стоимостью
- [ ] повторный импорт того же `task_id` — одна строка
- [ ] сбой потребителя — строки нет (откат вместе с ним), результат остаётся в сервисе
- [ ] неизвестная модель — стоимость null, токены сохранены, warning
- [ ] тест: цены в Symfony совпадают с `prices.yaml` сервиса
- [ ] сумма за месяц считается по МСК-месяцу
