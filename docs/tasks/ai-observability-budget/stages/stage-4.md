# Этап 4. Страница «ИИ» кабинета в админке

## Задача
Администратор видит работу ИИ по кабинету и задаёт лимит и глубину.

## Результат
- `GET /admin/ai/companies/{companyId}`: статус подключения, последний запуск и его итог,
  запуски за 7 дней, подсказки за 7 дней по статусам и доля принятых, расход за месяц /
  лимит, токены; форма «лимит, глубина» (POST, CSRF).
- В диалоге подключения в `/admin/users` — выбор глубины выгрузки и лимит.
- Отметка «ИИ вкл» в `/admin/users` дополнена ссылкой на страницу кабинета и пометкой
  «лимит исчерпан».

## Что считаем выполненным
Код, functional-тесты, скриншот страницы со стенда.

## Чек-лист приёмки
- [ ] страница: данные кабинета, без N+1 (фиксированное число запросов)
- [ ] форма лимита: сохраняет, неверные значения → ошибка, не 500
- [ ] не-админ → 403, чужой/несуществующий id → 404
- [ ] подключение из списка с глубиной 30 → `lookback_days = 30`
- [ ] пометка «лимит исчерпан» при расходе ≥ лимита
