## Итог

Факты, изменившие план:
- `path_name` и `code` пусты у всех складов — правила работают только по названию.
- Типовой справочник даёт **счета** `ACC_INV_WAREHOUSE`, `ACC_INV_OZON`, `ACC_INV_WB`, `ACC_INV_FF`, `ACC_INV_TRANSIT`;
  `INV_*` — статьи. Предложение хранит код счёта. Склады ФФ — отдельный счёт `ACC_INV_FF`.
- «FBS …» — товар продавца на своём или ФФ-складе, не на складе площадки. Правило «ozon/wb → склад площадки»
  дало бы ошибку на «FBS OZON», поэтому FBS уходит в ИИ.
- Слова площадок встречаются внутри брака, транзита и ФФ («Недостачи Ozon», «ФФ К2 Рнд WB») — порядок правил важен:
  исключение → транзит → ФФ → FBS (в ИИ) → офис → площадка.
