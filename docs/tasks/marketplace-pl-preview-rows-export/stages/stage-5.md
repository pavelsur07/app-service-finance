# Stage 5: UI — меню «Скачать xlsx» с двумя форматами

stage_base_commit: `4d57d5cc2`. Risk: LOW — блок на существующем паттерне страницы.

## 1. Какую задачу решаем

На вкладке «Предпросмотр ОПиУ» одна ссылка «Скачать xlsx». Нужно дать вторую выгрузку там же, не
сдвигая привычное действие и не добавляя вторую кнопку в и без того плотную строку фильтра.

## 2. Что будет результатом

`templates/marketplace/pl_preview/index.html.twig`: ссылка заменена кнопкой-меню Bootstrap
(`data-bs-toggle="dropdown"` — тот же механизм, что у фильтра «Теги» на этой странице, нового JS и
CSS нет):

- кнопка `btn btn-outline-secondary dropdown-toggle`, `type="button"` (внутри формы фильтра не
  отправляет её), иконка `ti-file-spreadsheet`, подпись прежняя — «Скачать xlsx»;
- меню `dropdown-menu-end`, связано с кнопкой `aria-labelledby`;
- пункты — обычные GET-ссылки с `base_query` (открываются в новой вкладке, копируются, работают без JS):
  1. «Таблица как на экране» — «Статьи × теги — для просмотра и печати» (`data-testid="pl-preview-xlsx"`, как раньше);
  2. «Строками для план-факта» — «Одна сумма — одна строка, по каналам и тегам» (`pl-preview-rows-xlsx`);
- меню выводится при тех же условиях, что ссылка раньше (`report is not null`).

Видимое поведение страницы не теряется: прежняя выгрузка доступна тем же кликом + выбор пункта;
ничего не уходит в тултип.

## 3. Что считаем выполненной работой

Меню на странице, обе ссылки несут текущий фильтр и отдают файлы; существующий тест
`testXlsxMatchesTheScreen` зелёный без правок; скриншот светлой темы и узкого экрана проверен.

## 4. Чек-лист приёмки

- [x] Кнопка «Скачать xlsx» открывает меню из двух пунктов с подписями.
- [x] `href` обоих пунктов содержит даты, канал и теги текущего фильтра.
- [x] Пункт «Строками…» отдаёт `pl-rows_*.xlsx`; «Таблица…» — `pl-preview_*.xlsx`.
- [x] При ошибке периода меню нет (как раньше ссылки).
- [x] `testXlsxMatchesTheScreen` проходит без изменений.
- [x] Скриншот: меню не уходит за правый край, подписи читаются; узкий экран (390 px) — без горизонтального скролла страницы.
- [x] Ни нового JS, ни инлайн-стилей, ни своих цветов.
