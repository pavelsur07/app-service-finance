## Итог (29.10.2026)

**Запись контрагента операции (`DocumentOperation::setCounterparty`):**
- форма `DocumentOperationType` (поле `counterparty`, подстановка шапки через
  `header_counterparty_id` и скрипт `_page_scripts.html.twig`);
- копия документа — `DocumentController` (копирует контрагента каждой операции);
- `CreatePLDocumentAction::createOperation()` — из
  `CreatePLDocumentOperationCommand::$counterpartyId` (единственный вызывающий,
  `FinanceFacade::createPLDocument`, передаёт `null`);
- `FinanceFacade::createDocumentFromCashTransaction` — тот же контрагент, что у
  шапки;
- `Cash\Service\Transaction\CashTransactionToDocumentService` — контрагент
  транзакции ДДС, тот же, что у шапки;
- `Loan\Service\LoanScheduleToDocumentService` — контрагента не ставит нигде;
- фикстуры `DataFixtures/PLDocumentsFixtures.php`.

**Чтение:** `op.counterparty ?? document.counterparty` — списки документов,
журнал операций (`DocumentOperationRepository`), экспорт JSON
(`PlOperationJsonExporter`), `show`; `RawPlReportController` — только
операции. Фильтры по контрагенту — по шапке. Регистр ОПиУ контрагента не
хранит: починка данных сумм не меняет, пересчёт не нужен.
