# Этап 1 — коды ядра в модели (`group_code`)

## Какую задачу решаем

Коды утверждены (`chart.md`, 17.11.2026), но их нет ни в `core.yaml`, ни в БД. Без кода
статью не к чему привязать и сводить в консолидации нечего. Ещё нужны два уточнения описаний
(решения Владельца 1–2).

## Что будет результатом

1. **`core.yaml` v2:** у каждого из 37 узлов есть `code`. Добавлены уточнения описаний:
   «Возвраты покупателям» — для селлеров, «Продажа оборудования» — про остаточную стоимость.
2. **`CashflowCoreTemplateReader`** принимает v2: `code` обязателен, формат
   `^(OP|FIN|INV)_(IN|OUT)(_[A-Z0-9_]+)?$`, до 64 символов, уникален в файле, префикс совпадает
   с секцией и направлением узла. v1 больше не читается.
3. **Миграция:** `cashflow_categories.group_code varchar(64) NULL` и unique
   `(company_id, group_code)`. Существующие строки получают NULL.
4. **`CashflowCategory`:** поле `groupCode` и метод `assignGroupCode()`. Назначить код можно
   один раз. Статью с кодом нельзя удалить (`assertCanDelete`, срабатывает и в `PreRemove`) и
   нельзя перенести (`setParent`). Переименовывать можно.
5. **Онбординг** (`ApplyCashflowCoreTemplateAction`) ставит коды новым компаниям.
6. **Существующие компании на ядре** (на проде 17.11: Максимедиа, Информ-ТВ, Телегис — у
   каждой 37 статей): если дерево совпадает с ядром по путям названий,
   `app:cash:cashflow-core:apply` проставляет коды статьям без кода. Это та же команда и тот
   же wrapper, только ветка «уже применено» теперь дописывает коды. Повтор ничего не меняет.
7. **Форма и экран статей:** код не редактируется. Удаление и перенос статьи с кодом
   отклоняются с понятным сообщением (через доменное исключение, как для системных статей).
8. **`ARCHITECTURE.md`:** контракт `group_code`, версия шаблона.

Группа консолидации в настройках головной компании — этап 1b, отдельным PR со своей
миграцией.

## Что считаем выполненной работой

PR влит, миграция применена на проде, код выкачен. Владелец запустил
`app:cash:cashflow-core:apply` для трёх компаний на ядре. У каждой из них 37 статей с
`group_code`, у остальных компаний `group_code` пустой, операции не тронуты.
