# Этап 3 — экран сопоставления с эталоном группы

## Какую задачу решаем

Синхронизация (этап 2) есть только командой на сервере. Пользователь не видит, что его дерево
ДДС расходится с эталоном, не может применить план сам и не может привязать статью, которую
синхронизация оставила конфликтом или не узнала по названию. Новая статья головной компании
никуда не сообщает о себе.

## Что будет результатом

1. **Экран «Эталон группы»** — `GET /cashflow-categories/group-chart`, активная компания, ссылка
   со страницы статей ДДС:
   - эталон: дерево головной компании (название) или базовое дерево;
   - план dry-run: «Будет привязано», «Будет создано», «Конфликты»;
   - кнопка «Применить» (`POST …/group-chart/apply`, FINANCE_WRITE, CSRF) — та же
     `SyncCashflowGroupChartAction` в транзакции `ApplyCashflowGroupChartAction`;
   - «Не сопоставлено»: статьи компании без кода (несистемные) и выбор кода эталона, который у
     компании ещё свободен → `POST /cashflow-categories/{id}/group-code` (FINANCE_WRITE, CSRF).
2. **Ручная привязка** — `SyncCashflowGroupChartAction::bind(companyId, categoryId, code)` под теми
   же блокировками, что синхронизация (кабинет → головная → компания). Отказ, если: статья не
   найдена, системная, уже с кодом; кода нет в эталоне или он у компании занят; другое направление
   или вид деятельности. Только ставит код, дерево не перестраивает. Пишет строку журнала.
   Транзакцией владеет `BindCashflowCategoryGroupCodeAction`; отказ — значением из транзакции,
   потом `CashflowGroupChartBindingException` (flash).
3. **Ночная проверка** — подписчик `DirectoryIntegrityCheckEvent` (cron 07:37): для каждой
   компании группы (головной и участников) — dry-run; если есть что привязать, создать,
   конфликты или статьи без кода — справочная строка `info` (на exit code не влияет).
   Компании вне групп не проверяются: у старых деревьев расхождения с ядром ожидаемы.
   Состав одним запросом — `ConsolidationGroupFacadeInterface::headsOf(list)`.
4. `ARCHITECTURE.md`: экран, ручная привязка, кто коммитит, `headsOf`, changelog.

Вне этапа: отвязка кода (ошибочную привязку снимает команда по решению Владельца — пока
нет случаев), подсказки «похожие названия» в выборе кода.

## Что считаем выполненной работой

PR влит и выкачен (миграции нет). На проде экран открывается у Максимедиа, Телегиса и
