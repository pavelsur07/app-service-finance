# Stage 5 — ТЗ интеграции, общей приёмки и выпуска

Статус: ТЗ перед началом проверок Stage 5. Risk HIGH-LOCAL.
Base commit реализации: 8a1f51cac4dacac4d49dd6b5cf72e0940d26a895.

## Цель

Подтвердить интеграцию Python, ServiceGateway, Cash и Telegram, исключить
повторную/чужую запись денег, подготовить доказательства качества и handoff.
Использовать общую матрицу §10 plan.md; не выдавать stub за проверку модели.

## Работы

1. Сверить payload/output, actor binding, company routing, stable ID и revision.
2. Применить миграции к локальной тестовой БД, проверить ORM/schema sync.
3. Исправить найденные интеграционные дефекты с targeted regression tests.
4. Запустить полные PHP gates один раз на handoff; Python gates по итогам
   интеграции при изменениях, затрагивающих ранее проверенные области.
5. Провести независимый internal review и обязательный external review,
   исправить подтверждённые BLOCKER/IMPORTANT и безопасные MINOR.
6. Описать recovery, rollout, rollback, миграционный dispatch и ограничения
   непроверенных живых вызовов. Нужные отдельные approval не подменять общим
   поручением на локальную реализацию.

результаты, которые указываются отдельно.
