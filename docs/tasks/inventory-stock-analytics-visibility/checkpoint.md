## Что уже действует после Stage 1–3

Протухший снапшот (старше 2 дней) не участвует в расчёте остатков. Для компании
с таким снапшотом остаток в отчёте показывается как `0` — промежуточное состояние,
прочерк появится в Stage 3.

Листинг с остатком > 0 даёт строку в юнит-экономике даже без движения за период:
на PROD это **177 новых строк** по 4 компаниям. Остатки отфильтрованы по
маркетплейсу вместе с остальными источниками.

Неизвестный остаток больше не показывается нулём: в таблице прочерк, в XLSX пустая
ячейка, в JSON `null`. Свод по тегам суммирует только известные значения и сообщает,
сколько листингов в сумму не вошло. В ответе есть дата снапшота и список отброшенных
источников.

Гейт `app:inventory:stock-freshness-check` существует, но **в cron не поставлен**.

## Открытые вопросы к Владельцу

- Внешних потребителей API нет — подтверждено 2026-09-06, поэтому `stockQty: number | null`
  в Stage 3 не является ломающим изменением за пределами репозитория.
- Поведение сумм в `TagSummaryTable` при неизвестных значениях — решать в Stage 3.
- ~~**`costPriceUnit` остаётся `0.0` при неизвестной себестоимости**~~ — **закрыто
  Stage 5** (`stages/stage-5.md`): поле стало nullable, различие «известный ноль» и
  «неизвестно» доведено до контракта и покрыто парой тестов.
- **Миграция `marketplace-analytics` из `_legacy` в `modules/`** — отдельная задача,
  не предусловие этого PR. Оценка объёма (2026-09-06): модуль 35 файлов / 4399 строк,
  это 44% всего легаси-React (9911 строк). Не автономна: модуль зависит от
  `_legacy/shared` (9 файлов, 854 строки), который используют ещё 22 файла четырёх
  других модулей, а ESLint-границы запрещают и `modules/ → _legacy`, и
  `shared/ → _legacy`, и `_legacy → modules/`. Отсюда развилка: нарушить §16.4 двумя
  копиями shared либо тащить весь `_legacy` разом. Целевой инфраструктуры нет вовсе
  (`modules/`, `entrypoints/`, `app/providers.tsx`, `mountIsland`; в `shared/` один
  файл, в React-обёртках UI Kit только `Button`). Задевает **6 обязательных STOP**
  из `CLAUDE.frontend.md` §6. Страховки нет: **0 фронтенд-тестов** в репозитории и
  нет скриптов `test`/`typecheck`. **Начинать следует с `shared/` и каркаса**, а не
  с этого модуля.
