# Пользовательский UI site: единый legacy-интерфейс

Поручение владельца: перевести пользовательские страницы `site/` на legacy.
Админку и `apps/` не менять. План согласован в чате; реализация разрешена.

Scope: `/finance`, шесть маршрутов `/settings/api*`, совместимость
`POST /settings/ui-mode`, пользовательский переключатель интерфейса.
Вход/регистрация уже используют отдельный legacy auth-слой. Бюджет и Unit
уже используют legacy-shell; React-острова сохраняются.

Приёмка: старые UI-cookie не включают новый слой; формы и таблицы API на
Tabler; сохранены URL, CSRF, company scope, права, секреты и финансовые данные;
админка и apps отсутствуют в diff; desktop/mobile smoke и проектные гейты.
