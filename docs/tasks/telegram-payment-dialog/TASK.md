# Telegram: управляемый разбор платежей Tony

Основание: поручение владельца «Делай» после анализа двух экспортов Tony
и production read-only проверки 17.11.2026. Экспорты и ПДн не копировать в Git.

Первый выпуск охватывает управление черновиком, общие уточнения и проверку
списка (этапы 1–3 согласованного предложения). Работа в существующих Cash /
Telegram; без новых зависимостей, миграций, production config и LLM-вызовов.

Приёмка:
- [ ] Из постоянного меню можно открыть и отменить свой активный черновик;
      несколько черновиков требуют выбора, чужие компании/actors недоступны.
- [ ] Отмена останавливает отложенную рассылку; поздний результат не возобновляет её.
- [ ] Изменение строки не рассылает заново весь список; есть компактная сводка.
- [ ] Ответ на общий вопрос меняет весь выбранный пакет одной ревизией,
      исключённые строки не меняются, повтор reply не применяется повторно.
- [ ] Явные общие дата/проект/ЦФО/направление применяются без обхода строк;
      неясные названия/даты и финансовые противоречия не угадываются.
- [ ] Общие вопросы видны перед деталями; пользователь может ответить на сводку.
- [ ] Кнопки читаются на телефоне; сохранение остаётся явным и идемпотентным.
- [ ] Исходные суммы, личные средства, факт оплаты и закрытые периоды защищены.

Вне первого выпуска: файловый импорт, новая модель учёта личных денег,
учётная политика ОПиУ, самостоятельное обучение модели. Ночной eval — проверка,
а не автоматическое обучение. Изменение его финансового scorer не входит сюда.
