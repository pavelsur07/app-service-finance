## Находка

DeepSeek объявил имена `deepseek-chat`/`deepseek-reasoner` выводимыми с
24.07.2026 (api-docs.deepseek.com/updates, 24.04.2026); в прайсе — только
`deepseek-flash` и `deepseek-v4-pro`. Старое имя 31.10 ещё отвечает, но может
пропасть без предупреждения. У `deepseek-flash` размышление включено по
умолчанию (`"thinking": {"type": "enabled|disabled"}` в теле запроса): +54%
токенов ответа и +1 с на пачку при той же точности.

## Результат

- Провайдер в `routes.yaml` может нести `extra_body` — поля, которые
  OpenAI-совместимый адаптер добавляет в тело запроса. Ключи тела, которые
  задаёт сам адаптер (`model`, `messages`, `max_tokens`, `temperature`), в
  `extra_body` запрещены — конфиг не загружается.
- `deepseek`: `extra_body: {thinking: {type: disabled}}`; маршрут
  `categorize_transactions` — `deepseek/deepseek-flash` → `openai/gpt-4.1-mini`
  (DeepSeek первым: быстрее и дешевле при равной точности).
- `prices.yaml`, ₽ за 1 млн токенов по курсу ЦБ 31.10.2026 (80,5573):
  `deepseek-flash` — дневной тариф $0,30 / $1,20 → 24,17 / 96,67 (ночью вдвое
  дешевле, считаем по верхней границе); `gpt-4.1-mini` — $0,40 / $1,60 →
  32,22 / 128,89. У каждой модели маршрута цена задана.
