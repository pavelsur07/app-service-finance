# Налоговые настройки компании и ставка НДС

Поручено Владельцем 01.11.2026 («Делай, начинай с этапа 1») после проверки
модуля Company.

## Как сейчас

- Одно поле `Company.taxSystem` (`CompanyTaxSystem`: `USN_NO_VAT`,
  `USN_VAT_5`, `USN_VAT_7`, `OSNO`) объединяет режим налогообложения и режим
  НДС; ставка выводится из него в `Cash\Service\Vat\VatPolicy`.
- Ставка ОСНО зашита как 20%; с 01.01.2026 общая ставка 22%.
- НДС выделяется только из расходов ДДС (`OUTFLOW`), только в ручных
  операциях (`AddCashTransactionAction`, `UpdateCashTransactionAction`);
  `vatRatePercent`/`vatAmount` нигде не читаются.

Прод 01.11.2026 (read-only): компаний `OSNO` — 0, `USN_VAT_5` — 2 (24 операции
2026 г. с НДС, все 5%), `USN_NO_VAT` — 2, без режима — 17. Операций 2026 г. со
ставкой 20% — 0, ремонт данных не нужен.

## Этапы

1. **Ставка по дате операции** — общая ставка из справочника с датой действия
   (20% до 2026, 22% с 01.01.2026), тесты на `VatPolicy`. `stages/stage-1.md`.
2. **Модель настроек** — режим налогообложения и режим НДС раздельно,
   допустимые сочетания, `CompanyTaxProfile` с `validFrom`, миграция текущих
   значений, мастер в карточке компании.
3. **Расчёт** — исходящий НДС с продаж, входящий с флагом вычета (УСН 5/7% —
   без вычета), цепочка ставки «строка → SKU → договор → профиль», расчёт в
   документах ОПиУ по дате отгрузки.
4. **Отчёты и контроль** — ОПиУ без НДС, предупреждения о порогах УСН,
   пересчёт задним числом с предпросмотром.

Этапы 2–4 меняют учётную семантику: перед каждым — решения Владельца по
правилам (что считать, где показывать).
