# Этап 4. Формы и разбор операций

База 42491e98c, риск MEDIUM. Работа 4.1–4.2.

- Формы создания, редактирования и повторного включения показывают результат до подтверждения. Старый маршрут включения ведёт к форме. В детализации по полям доступны примеры платежей и причины пропуска.
- Из раздела кандидатов можно открыть платежи, уточнить черновик и проверить его обычным способом. Список правил показывает значения по версиям за выбранный период со ссылками на детализацию.
- Переиспользованы текущие Twig-шаблоны Cash и контроллер Stimulus. Проверены пустые результаты, недоступный ИИ, отказ шлюза, межфирменный доступ. HTML-поведение проверено через Symfony BrowserKit. Новый Vite entry не требуется.
- ESLint прошёл, Vitest — 152 теста, Vite собрал существующий legacy_app (37.16 kB gzip). Для сборки использован Node на Debian с установленным GNU-бинарником Rollup.
