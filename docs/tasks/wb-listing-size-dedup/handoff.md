## Миграции

`Version20260728120000` — слияние дублей WB-листингов `size='0'` / `size='UNKNOWN'`.

- **up:** временная карта `_wb_size_merge_map` → разрешение конфликтов уникальных ключей → суммирование строк рекламных документов → переключение 14 таблиц с `listing_id` → удаление дублей → перенос идентичности на канонический листинг → `size='0'` → `'UNKNOWN'` для WB → `DROP TABLE` карты.
- **down:** необратима (`IrreversibleMigrationException`).
- **Деструктивные операции:** удаление 140 дублирующих листингов; удаление конфликтующих строк себестоимости/тегов/срезов/рекламных затрат в пользу канонического; удаление слитых строк рекламных документов после суммирования.

Ожидаемый эффект на проде (замер 28.07.2026): 140 пар, 280 листингов → 140; переезжают продажи 3925, затраты 27240, рекламные строки 220 (из них 212 сливаются суммированием), баркоды 168, себестоимость 10, возвраты 7. Конфликтов по себестоимости на текущих данных нет.

## Риски

- Миграция необратима и трогает денежные данные — только Production Gate, с бэкапом.
- `'0'` трактуется как «без размера». Проверено на проде: у компании с настоящими размерами (Вумджой) листингов с `size='0'` нет.
