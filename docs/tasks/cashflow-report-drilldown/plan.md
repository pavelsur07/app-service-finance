# Отчёт ДДС → Транзакции ДДС по двойному клику

Класс: Large (затронуты два модуля: отчёт `Report/Cashflow` + `Finance` и список `Cash`), один Stage.
Риск: MEDIUM — UI-блок и новые фильтры списка; схема, Messenger и финансовые формулы не меняются.

## 1. Какую задачу решаем

Владелец видит в отчёте ДДС сумму «статья × период × валюта», но не может сразу
посмотреть, из каких операций она сложилась. Нужно, чтобы двойной клик по сумме
открывал «Транзакции ДДС» с уже установленными фильтрами, и сумма операций в
списке совпадала с цифрой в ячейке.

Решения (согласованы 20.11.2026):

| Вопрос | Решение |
|---|---|
| Родительская статья | фильтр «статья и вложенные» (`includeChildren=1`) |
| Проекты и ЦФО отчёта | передавать в список, фильтры добавить в этой задаче |
| Куда открывать | та же вкладка; сумма — ссылка `<a>` (Ctrl/средняя кнопка — новая вкладка), двойной клик по всей ячейке |
| Матрица «Проект × ЦФО» | вне scope, отдельной задачей |

## 2. Что будет результатом

- Ненулевая сумма статьи в отчёте ДДС — ссылка на `cash_transaction_index` с параметрами
  `categoryId`, `includeChildren` (только у статьи с вложенными), `dateFrom`, `dateTo`
  (границы колонки, обрезанные периодом отчёта), `currency`, `projectIds`, `centerIds`
  (только если фильтр проектов/ЦФО в отчёте активен).
- Двойной клик по ячейке открывает ту же ссылку; курсор и подсказка «Двойной клик — операции».
- Нулевые ячейки, сальдо и режим сверки с дашбордом (`dashboard_reconciliation`) — без ссылок:
  в режиме сверки отчёт исключает переводы и технические статьи, а список — нет.
- В списке транзакций новые фильтры:
  - `includeChildren=1` — `categoryId` вместе с поддеревом статьи;
  - `projectIds` — CSV UUID направлений, `IN` по `t.projectDirection` (отчёт уже раскрыл поддерево);
  - `centerIds` — CSV UUID ЦФО, `IN` по `t.responsibilityCenterId`.
  Невалидный UUID → flash + redirect (как для валюты). Фильтры видны чипами и сохраняются
  при пагинации и в экспорте (общий `CashTransactionFilters`).

CSV вместо `[]`: `CashTransactionFilters` — `array<string, string|null>`, на нём держатся
экспорт, чипы и пагинация; список не меняет контракт.

## Известное ограничение

Список показывает полную сумму операции. У операции с разбивкой по нескольким статьям
сумма строки в списке больше доли в ячейке — набор операций при этом верный.
