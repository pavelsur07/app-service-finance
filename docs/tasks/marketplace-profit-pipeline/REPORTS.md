# Отчёты и показатели нового контура маркетплейсов

**Утверждено Владельцем 13.11.2026** (приоритеты и определения D1–D7 — как в тексте). Приоритеты:
**P1** — первая очередь (под неё проектируем данные), **P2** — следом,
**P3** — потом или не нужно. «Сейчас» — что есть в легаси (`/marketplace-analytics/unit-extended`,
`ListingDailySnapshot`, `MarketplaceAds`, `Inventory`).

## 1. Уровни прибыли SKU

Ответ на «экономика товара без разнесённых затрат»: каждый уровень — отдельная колонка,
режим «полная» — просто последние строки каскада.

| Уровень | Формула | Смысл | Сейчас | Приоритет |
|---|---|---|---|---|
| Выручка | продажи − возвраты (цена продавца) | | есть | P1 |
| Валовая прибыль | выручка − себестоимость | наценка товара | нет | P1 |
| **МД1 — до рекламы** | валовая − комиссия − логистика туда/обратно − эквайринг − приёмка | экономика товара на площадке | нет | P1 |
| **МД2 — после рекламы** | МД1 − реклама этого SKU (CPC, оплата за заказ, акции) | окупается ли продвижение | ≈ «Прибыль» строк товаров | P1 |
| **Прибыль полная** | МД2 − доля общих затрат (хранение без SKU, подписки, штрафы кабинета, внешние) по ключу | вклад с учётом накладных | нет | P1 |
| Прибыль после налога | полная − налог по профилю компании | | нет | P2 |

Инвариант: Σ по SKU (полная) + нераспределённое = итог кабинета.

## 4. Определения, которые нужно утвердить

| # | Вопрос | Предложение |
|---|---|---|
| D1 | Дата признания продажи в экономике | дата начисления МП (выкуп / by-day); заказы — отдельный показатель по дате заказа |
| D2 | Что считается выручкой | цена продавца, на которую МП начисляет комиссию; СПП — справочно, не уменьшает выручку |
| D3 | Ключ распределения общих затрат | по умолчанию — доля выручки SKU; хранение без SKU — доля среднего остатка (шт. × объём, если есть); ключ хранится с результатом |
| D4 | Налог | из налогового профиля компании (УСН 6 % — от выручки, УСН 15 % — от прибыли, ОСН — после этапа НДС) |
| D5 | Себестоимость | действующая на дату продажи из истории листинга (живая зона `Marketplace`) |
| D6 | Неделя для R3 | пн–вс, отправка в пн 09:00 МСК, данные — с поправкой на D+2 у рекламы Ozon (пометка «предварительно») |
| D7 | Пересчёт задним числом | изменения МП за прошлые даты переписывают витрину окна; R3 за прошлую неделю не переотправляется, а в следующем отчёте строка «корректировка прошлых периодов» |
