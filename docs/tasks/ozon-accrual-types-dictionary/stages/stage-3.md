# Stage 3: закрытый список групп и подсказка группы правилами

## 1. Какую задачу решаем

Статья из справочника (Stage 2) всегда попадает в «Требует классификации»: в API
Ozon группы нет. Нужны:
- закрытый список групп — сейчас группа маппинга свободный текст, и на проде уже
  есть дефект («Другие услуги и⏎штрафы» с переводом строки, 1 маппинг);
- подсказка группы для нового типа по `name`/`description` правилами, которые
  хранятся данными (правка без деплоя).

Факты Stage 0: правила по словам дают 92,5% на встреченных типах, но
повторяют ошибки каталога, если подгонять их под каталог. Поэтому стартовые
правила выверены по группам Ozon из xlsx (52 → Продвижение, 74 и 76 → Услуги
партнёров), а точная группа придёт из xlsx в Stage 3b.

## 2. Что будет результатом

- Таблица `ingest_category_groups` (`source`, `code`, `label`, `ozon_label`,
  `sort_order`) + Entity `CategoryGroup`. Сид Ozon: Продажи, Возвраты, Вознаграждение
  Ozon, Услуги доставки, Услуги партнёров, Услуги FBO, Продвижение и реклама,
  Компенсации (`ozon_label` «Компенсации и декомпенсации» — так в xlsx),
  Другие услуги и штрафы, Требует классификации. Метки — как в текущих маппингах
  прода, чтобы ничего не переименовать.
- Таблица `ingest_category_group_rules` (`source`, `priority`, `pattern` — регулярное
  выражение по `name + description`, без учёта регистра, `group_code`,
  `confidence` high|medium, `active`, `note`) + Entity `CategoryGroupRule`. Сид —
  выверенный набор Stage 0.
- `OzonAccrualGroupSuggester`: активные правила Ozon по приоритету, кэш на прогон,
  невалидное выражение пропускается с WARNING → `GroupSuggestion` (`groupLabel`,
  `confidence`, `ruleId`) или null.
- Резолвер: статья из справочника получает группу подсказки, если `confidence =
  high`; иначе «Требует классификации». `known` остаётся `false`, тип транзакции —
  запасной (инвариант Stage 2).
- Миграция двух таблиц с сидом (обратима: DROP).

Не входит (отступление от plan.md): таблица `ingest_ozon_accrual_type_usage` — по
Stage 0 блок by-day группу не определяет; где встречается тип, очередь Stage 4
покажет запросом по транзакциям. Проверка группы маппинга по списку — Stage 4
(там же форма админки).

## 3. Что считаем выполненной работой

- Unit-тесты подсказчика: приоритет, регистр, кириллица/«ё», invalid regex,
  medium не применяется, нет совпадения → null.
- Integration-тест на сиде миграции: эталон групп Ozon из xlsx Stage 0 (23 типа)
  — подсказка `high` совпадает ≥ 90%, расхождения перечислены в тесте явно.
- Integration-тест резолвера: тип из справочника получает группу подсказки,
  `known=false`, тип транзакции не изменён; неактивное правило не применяется.
- Гейты, миграция up/down/up, ревью.
