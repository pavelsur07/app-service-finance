# Production: Вумджой ООО / Ozon / СПП

## Scope и доступ
Подготовлено, НЕ выполнено. SQL writes требуют отдельного именованного одобрения §3.3.
Агент имеет только codex-psql-ro: им этот SQL не запускать. Исполнение — владельцем
через разрешённый write-channel; не расширять wrappers/sudoers и не обходить read-only.
Сначала повторить read-only preflight по четырём ID из repair.sql; сохранить их исходное состояние.
repair.sql меняет только is_active/updated_at двух legacy-правил, проверяет компанию,
маркетплейс, источник, вид операции, статью, знак и активность правильных правил.
При расхождении — rollback транзакции. Повторный запуск идемпотентен.
rollback.sql возвращает активность legacy-правил, не удаляет данные и не меняет документы.
