# Оплата за заказ Ozon в расширенной юнит-экономике

## Stage 1. Расчёт и расшифровка
Risk: HIGH-LOCAL
Definition of Done:
- Оплата за заказ включена в рекламу карточек, таблицы и XLSX. Действующее правило вычета статистики из начислений без товара сохраняется.
- Расходы без привязки видны в строке кабинета. Теги ограничивают расчёт выбранными товарами.
- Расшифровка показывает начисления по кампаниям и дням, покрытие начислений, расходы по товарам и расчётное распределение. Исторические данные без кампании остаются в сверке.
- Тесты проверяют частичное и полное покрытие, сторно, расчётное и отсутствующее разнесение, фильтры и изоляцию компании.
Work items:
- 1.1 — регрессионные тесты и группировка расходов.
- 1.2 — расшифровка из сохранённых начислений и статистики.
Stage checks: MarketplaceAnalytics unit, integration и functional, проверка стиля и PHPStan по изменённым файлам.
Reviewer focus: знаки, повторный учёт, принадлежность компании, даты, соответствие отчётов.

## Stage 2. Карточка и таблица
Risk: MEDIUM
Definition of Done:
- Карточка «Реклама» показывает оплату за заказ без привязки и даёт открыть расшифровку с клавиатуры.
- Существенные суммы, дата начислений и источник видны без открытия дневных строк.
Work items:
- 2.1 — карточка, расшифровка и строка таблицы.
- 2.2 — проверки фронтенда и сверка сквозного сценария.
Stage checks: lint, Vite build, Vitest, проверка страницы и адаптивности.
Reviewer focus: понятность названий, загрузка и отсутствие данных, доступность.
