# Оплата за заказ Ozon в расширенной юнит-экономике

**Ветка:** `fix/unit-extended-ozon-ad-expenses` · **PR:** [#3062](https://github.com/pavelsur07/app-service-finance/pull/3062)

- «Оплата за заказ Ozon» входит в рекламу карточки, строки кабинета и XLSX. Статистика по листингу покрывает начисления по нему, остаток статистики покрывает начисления без листинга по правилу периода. Сторно уменьшает расходы.
- Расшифровка показывает суммы по товарам и без привязки, часть по продажам, последние начисления и разрез по номеру кампании и дню. Исторические начисления без номера видны отдельной строкой.
- Контракт внутреннего widgets API расширен полем `orderAds`. В ответе таблицы `unallocated.adSpend` содержит рекламные расходы без привязки. Эти маршруты используют типы фичи, в генерируемой спецификации их нет.
- Миграций на ветке относительно master нет.

Проверки: PHPStan, PHP CS Fixer и strict types, PHP unit, тесты затронутых модулей в изолированной БД, ESLint, Vite build, 152 Vitest-теста, синхронность типов OpenAPI. Chromium с тестовыми ответами API проверил доступность раскрытия, разбивку, мобильную ширину, фильтр тегов и WB. Итог полных гейтов приведён в PR.

Релиз раскрывает сумму по товарам и начисления по кампании и дню. Внешнее — 0 BLOCKER, 1 IMPORTANT, исправлено и проверено без повторного раунда.
