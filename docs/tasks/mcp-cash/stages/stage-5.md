# Stage 5. Карточка сотрудника

База `1efc57d60`. Риск HIGH-LOCAL. Карточка и финансовый сценарий готовы к проверке вместе с внешним доступом.

- Из реестра ДДС открываются ожидающие и завершённые черновики. Сотрудник видит дату, источник, внешний ID и подключение. В карточке проведённого черновика доступна связанная операция.
- Действия сотрудника защищены правом записи, принадлежностью черновика, CSRF и версией. Подтверждение требует явной отметки об оплате. Счёт и статья повторно проверяются под блокировками Cash.
- Новый функциональный сценарий сначала упал на отсутствующем маршруте. Исправления после ревью дополнительно воспроизвели смещение даты, отсутствие перехода к факту, обход отметки об оплате и ошибку направления наследуемой статьи.
- Целевой набор — 183 теста, 1312 утверждений. Включает два одновременных запроса, переход к факту, историю, отказ после закрытия периода или отзыва прав, чужой черновик, прямую проверку уникального индекса, миграции и Telegram. Целевой PHPStan и проверки Twig прошли.
- Сквозной прогон через Codex CLI и Claude Code относится к общей приёмке с OAuth.
