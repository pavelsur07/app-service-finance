# Stage 1. Внешний доступ к MCP

База интеграции `970112d5e`. Риск HIGH-LOCAL.

- [x] HTTPS Streamable HTTP поддерживает инициализацию с сессией и современное stateless discovery. Вызовы ограничены авторизованной компанией, scopes и частотой. Без конфигурации маршруты отвечают 404.
- [x] OAuth с PKCE S256 и зарегистрированными публичными клиентами. Фактический владелец выдаёт и отзывает доступ в кабинете. При статусе `NONE` доступ закрыт. При статусе «только чтение» доступны разрешённые инструменты чтения. Проверка прав и тарифа выполняется на действующем токене.
- [x] Код авторизации одноразовый, refresh ротируется. При повторе старого refresh семейство токенов отзывается. Токены и аргументы исключены из логов и Sentry. В журнале вызова есть идентификаторы запроса и подключения, результат и длительность.
- [x] HTTP-тест проходит OAuth, discovery, вызов, отзыв и финансовый сценарий. Codex CLI 0.171.0 проверил все три инструмента, Claude Code 2.1.326 прошёл OAuth и discovery на HTTPS-стенде.

Основные файлы — `site/src/Mcp/`, `site/contracts/mcp/v1/`, `site/tests/{Functional,Integration,Unit}/Mcp/`, `oauth.md`, `ARCHITECTURE.md` и техническая миграция `Version20261121110000`.

Внутреннее ревью выявило 2 IMPORTANT. Выделен канал аудита MCP и расширена очистка контекста Sentry. Повтор параметров OAuth отвергается до их свёртки в Symfony. Проверка UUID компании выполняется в `CompanyFacade::financialAccess()` до обращения к БД.

Внешнее ревью Stage 1 прошло один раунд. Замечание IMPORTANT о видимости неожиданных ошибок исправлено и покрыто регрессионным тестом. Сбой инструмента пишет ERROR с безопасными полями и общим идентификатором события аудита. Сообщения SDK фильтруются. Результат — fixed without re-run. Очистка накопленных записей OAuth остаётся отдельной эксплуатационной задачей с учётом срока защиты от повтора токенов.
