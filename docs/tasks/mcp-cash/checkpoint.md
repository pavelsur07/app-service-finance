# Реализация MCP для ДДС

**Статус** — этапы 1–5 реализованы и проверены на тестовом стенде. Ветка `feat/mcp-cash`, PR #3088. Изначальная база `56252d618`, актуальная база PR `master`.

- Baseline PaymentIntake и Telegram — 112 тестов, 685 утверждений.
- Stage 2 и Stage 3 — CashFacade отдаёт справочники и фактические операции с разбивкой. Stage 4 — создание, повтор, подтверждение и отмена структурированного черновика.
- Stage 5 — проверены карточка, защита действий, история, происхождение и переход к факту. Объединённый Cash-прогон — 183 теста, 1312 утверждений.
- Владелец подтвердил правило выдачи доступа и отказ при `NONE`. Для приёмки выбраны Codex CLI и Claude Code с предварительной регистрацией клиентов и фиксированными callback.
- Ревью — внутреннее 0 BLOCKER / 7 IMPORTANT, внешнее 0 BLOCKER / 3 IMPORTANT за четыре раунда. Подтверждённые замечания исправлены.
- Codex CLI прошёл OAuth и использовал три инструмента. Claude Code прошёл OAuth и получил каталог. Выполнены проверка повторов, подтверждение и отмена на синтетических данных.
- После объединения с `master` чистая PostgreSQL применила обе миграции задачи. Сверка схемы прошла. Доказательства и условия выпуска собраны в `handoff.md`.

**Следующее действие** — итоговые гейты PR, затем решение владельца о релизе с миграциями.
