# Техническое задание. Внешний доступ к ДДС через MCP

**Цель.** Внешняя система получает справочные данные и фактические движения денег по своей компании и передаёт платёж на проверку. Сотрудник VashFinDir решает, отражать ли этот платёж в учёте.

## Что получает пользователь

| Возможность | Ожидаемый результат |
|---|---|
| Прочитать справочники | Внешняя система получает активные денежные счета с валютой и статьи ДДС с принадлежностью к родительской статье. Их идентификаторы можно использовать при чтении операций и вводе платежа с учётом правил ДДС. |
| Прочитать операции | Внешняя система видит фактические операции компании за выбранный период. По каждой операции доступны дата, счёт, направление, сумма, валюта и распределение по статьям. |
| Передать платёж | Внешняя система получает номер черновика. VashFinDir фиксирует источник `mcp`, подключение и внешний идентификатор платежа. Повторная отправка того же платежа возвращает тот же черновик. |
| Принять решение | Сотрудник, которому принадлежит черновик, видит данные платежа и его происхождение. Подтверждение факта оплаты создаёт одну операцию ДДС. Отмена закрывает черновик без движения денег. |

## Когда задача готова

На тестовой компании внешний клиент проходит весь путь от выбора счёта до получения подтверждённой операции. Сотрудник может установить, откуда пришёл платёж и кто его подтвердил. До подтверждения реестр, остатки и обороты совпадают с исходными. Данные другой компании недоступны на каждом шаге. Подробные критерии приведены в [плане приёмки](plan.md), точные поля и ответы — в [контракте v1](contract-v1.md).

## Что вне задачи

- Изменение справочников, исправление или удаление существующих операций, массовый импорт и проведение платежей из внешнего клиента.
- Платёжные поручения банку, загрузка выписок, конвертация валют, изменение правил закрытия периода, расчёта остатков, ДДС или ОПиУ.
- Изменение Telegram-ввода, обработки исторических данных, ролей и тарифов. Поддерживаемые клиенты и правила выдачи подключения определяет [базовый проект MCP](../mcp-access/TASK.md).
- Административный MCP, инфраструктура и действия на production. Предмет этой поставки — ТЗ и критерии будущей приёмки.
