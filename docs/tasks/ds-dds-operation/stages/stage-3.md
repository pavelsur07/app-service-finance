# Stage 3 — страница «Операция ДДС»: каркас

## 1. Какую задачу решаем
Страница правки — по-прежнему «Редактирование транзакции» на сетке Tabler
3/2/2 с одной карточкой. Нужна раскладка SPEC §2.1: шапка с названием и
бейджем, две колонки (карточки слева, «Сведения» справа), sticky-панель
действий, меню «Ещё».

## 2. Что будет результатом
- `site/templates/transaction/edit.html.twig` — своя вёрстка формы (форма
  создания остаётся на `_form.html.twig`): breadcrumbs «Деньги / Операции ДДС /
  Редактирование», `<title>`/`<h1>` «Операция ДДС от ДД.ММ.ГГГГ», бейдж
  «Приток/Отток + сумма» (`vf_amount`), «Ещё» → «Удалить операцию»;
  карточки «Операция», «Аналитика», «Документы ОПиУ на основании операции»
  (таблица пока прежняя); правая колонка «Сведения»: источник, создана,
  изменена (автора в модели нет — строки нет) и пояснение про «Не
  распределено»; sticky-панель «Все изменения сохранены / Отмена / Сохранить».
- CSS страницы `site/assets/styles/pages/dds-operation.css` (классы
  `.dds-op*`, цвета через `--vf-*`), подключён в `legacy-app.js`.
- Источник «Сведений» — из полей операции: `importSource` (код банка →
  «Банковская выписка (Альфа-Банк)», `file` → «Импорт из файла»,
  `telegram` → «Telegram»), выписка 1С (`externalId` без `importSource`) →
  «Банковская выписка (1С)», иначе «Вручную».

## 3. Что считаем выполненной работой
Страница рендерится в новой раскладке на 1440, все поля формы на месте и
сохраняются как раньше; существующие тесты страницы зелёные; новый тест на
шапку/«Сведения».
