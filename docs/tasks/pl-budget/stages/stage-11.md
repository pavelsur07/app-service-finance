# Stage 11: DS-пакет — шапка экрана варианта и разрез (PR 2)

**Risk:** MEDIUM. Новый endpoint переименования, сумма по одному измерению
разреза; без миграции. План пакета — `docs/plan/ds-budget-ui.md` (5–10, F1, F4).

## 1. Какую задачу решаем

Шапка экрана варианта не совпадает с макетом (refs 10–12, 14, 15): нет
переименования, действия не по статусу, индикатор сохранения и кнопки
помощников живут внутри карточки сетки, «⋯» нет, причина недоступности — только
`title`. Разрез выбирается одним списком пар; «все проекты» или «все ЦФО» по
отдельности посмотреть нельзя.

## 2. Что будет результатом

| Часть | Что |
|---|---|
| Название | карандаш рядом с h1 (только черновик и право записи): поле на месте, Enter — сохранить, Esc — отмена, ошибка под полем; F1 `RenameBudgetVersionAction` + `POST /finance/budget/versions/{id}/name` (JSON, CSRF `budget_cells`, FINANCE_WRITE, черновик, ≤ 120, повтор с тем же именем — без изменений) |
| Кнопки по статусу | черновик — «Утвердить» (акцент), «Помощники ▾», «⋯» (Копировать, В архив); утверждён — «Вернуть в черновик», «⋯» (Копировать); архив — «Восстановить», «⋯» (Копировать); недоступное — неактивно, причина строкой 12 px под кнопками |

| «Помощники ▾» | только черновик; меню острова: пять помощников (открывают текущую панель, окно — этап 13), разделитель, «Правило «% от строки»», «Загрузить из Excel»; недоступно — пункты неактивны, причина строкой вверху меню |

Вне этапа: вид сетки (этап 12), окно помощников (этап 13), план–факт.

- PHPStan, CS, Budget, полный набор, внешнее ревью; `ARCHITECTURE.md`.
