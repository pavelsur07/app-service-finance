# Stage 15: DS-пакет — план–факт: мультивыбор проекта и ЦФО (F3, PR 6)

**Risk:** MEDIUM. Новый срез план–факта (списки проектов и ЦФО), новый метод
`FinanceFacade`; без миграции. Решение Владельца (`docs/plan/ds-budget-ui.md`
§5, F3): мультивыбор как в отчёте ОПиУ — проект с поддеревом; отдельного
«Не задано» нет, «Общий» подписан «Общий (включая «Не задано»)» (вариант A);
по умолчанию — вся компания.

## 1. Какую задачу решаем

План–факт фильтруется одной точной парой «проект × ЦФО» или всей компанией.
Нельзя посмотреть, например, «Wildberries и Сайт» вместе или проект вместе с
дочерними, а цифры факта не совпадают с отчётом ОПиУ, который берёт проект с
поддеревом. Макет (BUDGET-SPEC §6, refs 19–25) — две пилюли «Проект: …» и
«ЦФО: …» с флажками.

## 2. Что будет результатом

| Часть | Что |
|---|---|
| Адрес | `?projects[]=…&centers[]=…`; нет списка, пустой или выбраны все — «все»; неизвестные и чужие id отбрасываются; старый `?project=&center=` читается как списки из одного значения |
| Проект | выбранные проекты вместе с дочерними (как отчёт ОПиУ) — и план, и факт |
| ЦФО | выбранные ЦФО; если среди них системный «Общий» — факт без ЦФО тоже (вариант A); «Не задано» отдельным пунктом нет |
| План | сумма ячеек бюджета всех пар, попавших в фильтр (`BudgetCellsQuery::fetchSlice`) |
| Факт | `FinanceFacade::getPlFactAmountsByMonthForSlice(companyId, year, ?projectIds, ?centerIds, includeUnassigned)` — `PlFactMonthlyAmountsQuery`, проекты уже развёрнуты вызывающим |
| Ссылка «факт → отчёт» | всегда с теми же фильтрами (`projectDirectionIds`, `responsibilityCenterIds`), кроме выбора ЦФО с «Общим»: отчёт с фильтром ЦФО не видит операций без ЦФО — ссылок нет, пояснение в легенде |
| UI | пилюли «Проект: Все ▾» / «ЦФО: Все ▾» (одно значение — название, несколько — «N из M»); меню: «все / ни одной», флажки (проекты — с отступом по дереву, подпись «включая вложенные»), «Применить»; без выбора «Применить» неактивна; на телефоне пилюли переносятся |
| JSON `/versions/{id}/plan-fact` | без изменений (точная пара) |

Вне этапа: память фильтра проекта/ЦФО (адрес — источник), мультивыбор в
сетке ввода плана.

- Smoke: пилюли, выбор, «Применить», ссылка в отчёт ОПиУ даёт ту же сумму
