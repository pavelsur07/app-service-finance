# Stage 7: импорт плана из Excel

**Risk:** MEDIUM (запись плана; без миграции)

## 1. Какую задачу решаем

План, поправленный в Excel (или выгруженный и заполненный офлайн), нужно
загрузить обратно в черновик без ручного перебивания и без риска молча
затереть введённое.

## 2. Что будет результатом

| Часть | Что |
|---|---|
| API | `POST /finance/budget/versions/{id}/import` (multipart: `file`, `project`, `center`, `apply`, `confirmOverwrite`; `X-CSRF-Token` `budget_cells`; запись FINANCE) → `{cells, changed, overwrite, skipped, applied, warnings, ignored}` — тот же ответ, что у `/fill`, плюс предупреждения и пропущенные строки файла |
| Infrastructure | `BudgetPlanXlsxReader` — читает лист «План» формата этапа 6: строки по «ID статьи», без ID — по коду; числа и строки «1 200,50»; пустая ячейка = 0 |
| Application | `BudgetImportPlanner` — ячейки пары из файла (только листья ввода, деньги; знак — по направлению статьи; `sales_plan` — пропуск, комментарий сохраняется); `ImportBudgetCellsAction` — предпросмотр или запись тем же путём, что помощники (блокировка, перепроверка статуса, пересчёт, `BudgetLinesWriter`) |
| Остров | кнопка «Загрузить из Excel» рядом с «Помощниками» (те же условия доступности) → панель: файл → предпросмотр (N ячеек, предупреждения, пропущенные строки) → «Применить» / «Перезаписать заполненные (N) и применить» → сетка перечитывается |

## 3. Что считаем выполненной работой

- TDD: unit ридера (ID, код, пустые, строки с запятой, мусор, не тот лист);
  integration планировщика (знак, пропуски, `sales_plan`, комментарий,
  перезапись, другая пара → предупреждение); functional эндпоинта
  (предпросмотр не пишет, применение пишет, повтор без изменений, 409 без
  подтверждения, утверждённый 409, без права 403, CSRF, не xlsx / > 2 МБ →
  422, круговой тест «экспорт → импорт = 0 изменений»).
- Smoke в браузере, скриншоты `screenshots/stage-7/`.
- PHPStan/CS; Budget + Finance; полный набор; lint/tsc/vite build.
- `ARCHITECTURE.md`, итог; внешнее ревью; PR «Excel».
