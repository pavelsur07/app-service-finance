# Stage 10: DS-пакет — список вариантов и «Заполнить из факта» (PR 1)

**Risk:** MEDIUM. Новая точка входа записи (создание варианта с заполнением),
без миграции. План пакета — `docs/plan/ds-budget-ui.md` (пункты 1–4, F2).

## 1. Какую задачу решаем

Экран «Варианты» отстаёт от макета пакета `budget-pack` (refs 01–09):
действия строки — ряд кнопок, на телефоне таблица не читается, пустой год —
одна строка текста, у окна «Новый вариант» ошибки приходят флешем после
закрытия. Пустой год не даёт быстрого старта: план приходится вводить с нуля,
хотя факт прошлого года уже есть.

## 2. Что будет результатом

| Часть | Что |
|---|---|
| Шапка | крошки «Доходы и расходы / Бюджет ОПиУ», h1, описание; справа переключатель года «‹ [2027 ▾] ›» (годы с вариантами + текущий и следующий) и «Новый вариант» |
| Таблица | колонки: Название (ниже «копия «…»») · Статус · «Чистая прибыль, ₽» (`vf_money`, копейки приглушены; колонки нет без строки `NET_PROFIT`) · Изменён · «⋯»; архив — свёрнутый блок «Архив (N)» в той же карточке; сноска «Утверждённый вариант показан первым. «Итог года» — строка «Чистая прибыль» дерева ОПиУ.» |

| Пустой год | «На {год} год вариантов нет», «Создайте вариант и заполните план…», кнопки «Создать пустой» и «Заполнить из факта {год−1}» (открывают окно с выбранным способом); нет факта за прошлый год — вторая неактивна, причина «За {год−1} нет факта ОПиУ» |

| F2 backend | `CreateBudgetVersionFromFactAction` (точка входа, одна транзакция): создаёт черновик года и под блокировкой варианта для каждой активной пары «проект × ЦФО» считает помощник «Из факта прошлого года» (`BudgetFillPlanner`, все листья, 12 месяцев) и пишет `BudgetLinesWriter`; повтор с тем же `versionId` — тот же вариант без дозаписи; итог — флеш «Заполнено N ячеек в K парах»; `CreateBudgetVersionController` — `method=fact` |
| Наличие факта | `BudgetVersionListController` на пустом году спрашивает, есть ли факт за год−1 (`FinanceFacade::getPlFactAmountsByMonth`) |

Вне этапа: экран варианта, сетка, помощники, план–факт (этапы 11–15).
Состояния «загрузка» и «ошибка» у серверной страницы — штатные (страница целиком), отдельный скелетон не нужен — отметить в отчёте.

## 3. Что считаем выполненной работой

- Integration `CreateBudgetVersionFromFactActionTest`: пары с фактом
  заполнены суммами факта того же месяца (знак отчёта), пара «Общий» с фактом
  без ЦФО (вариант A), повтор — тот же вариант и то же число строк, нет факта —
  пустой вариант и 0 ячеек, чужая компания не видна.
- Functional: создание `method=fact` → редирект на вариант; ошибка имени →
  редирект на список с открытым окном и значениями; меню «⋯» с причинами для
  роли без записи и не владельца; пустой год — обе кнопки, неактивная без факта.
- PHPStan, CS, Budget + Finance, полный набор; `ARCHITECTURE.md`.
- Smoke со скриншотами 1440 и 390/360: список, меню, меню без прав, окно с
  ошибкой, копия, пустой год, мобильная; сверка с refs 01–09.
