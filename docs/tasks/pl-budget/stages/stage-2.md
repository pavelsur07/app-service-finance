# Stage 2: сетка ввода плана (frontend, React-остров)

**Risk:** MEDIUM
**Stage base commit:** `af9032dcc`

## 1. Какую задачу решаем

На экране варианта (`/finance/budget/versions/{id}`) пока пустое место под
сетку. Пользователю нужно быстро заполнить план по статьям ОПиУ на 12 месяцев
и сразу видеть итоги дерева — с клавиатуры, вставкой из Excel, без кнопки
«Сохранить». Экран 3 `ui-ux.md`, визуал — DS раздела ОПиУ.

## 2. Что будет результатом

| Часть | Что |
|---|---|
| API (малое) | `BudgetGridRow::$format` (`MONEY` / `PERCENT` / `RATIO` / `QTY`) — сетка показывает показатели в формате статьи; итоговые строки отдаются с 4 знаками (у `RATIO` их 4) |
| `assets/api/client.ts` | `apiFetch()` — JSON-запрос с cookie, заголовком `X-CSRF-Token` и разбором ошибки `{error:{code,message}}` в `ApiError` (правило `CLAUDE.frontend.md` «все запросы через `apiFetch`» — функции не было) |
| Модуль | `assets/react/modules/budget/features/budget-grid/`: типы, `amount.ts` (разбор ввода, знак по `flow`, формат DS-Money), `useBudgetGrid` (загрузка, правки, автосохранение), `BudgetGridWidget` (smart: выбор ячейки, клавиатура, вставка, комментарий), `BudgetGridView` (dumb: панель и таблица), CSS Module (закреплённые шапка и колонка) |
| Entry | `assets/react/entrypoints/budget_grid_page.tsx`, остров `budget-grid`, `ErrorBoundary`; `vite.config.js` |
| Twig | `show.html.twig` подключает entry |

Поведение:
- Пара «проект × ЦФО» — список над сеткой в `vf-card-bar`; по умолчанию
  системная пара «Общий × Общий»; «Все проекты» — только просмотр суммы; одна
  пара у компании — списка нет. Выбор — в адресе (`?project=&center=`).
- Ввод: клик/Enter/F2/печать — правка; Enter — вниз, Tab/Shift+Tab — вправо/
  влево, стрелки, Esc — отмена, Delete — очистить. Принимаются `600000`,
  `600 000`, `600000,50`, `-1 000`; иное — ошибка у ячейки и текст под сеткой.
- Знак (решение Владельца): в расходной статье вводится положительное число,
  хранится и показывается с минусом; в доходной — как есть; без направления —
  как ввёл.
- Вставка из Excel с текущей ячейки, итог «Вставлено N ячеек, пропущено M».
- Автосохранение пачкой через 1 с после правки и при уходе со страницы
  (повтор безопасен — upsert); ошибка → «Не сохранено — повторить»,
  предупреждение браузера при уходе; 409 «не редактируется» → только чтение
  с баннером и списком несохранённых ячеек.
- Комментарий: Shift+Enter или контекстное меню → поповер до 500 символов;
  у ячейки с комментарием — маркер, текст — в `title`.
- Итоговые строки и показатели пересчитывает сервер: после сохранения сетка
  перечитывается, несохранённые правки поверх ответа не теряются. Итог строки
  листа — сразу на клиенте.
- Свёртка групп (▾/▸) запоминается в браузере (`localStorage` в try/catch).
