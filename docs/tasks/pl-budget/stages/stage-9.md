# Stage 9: правило «% от выручки» в сетке

**Risk:** MEDIUM (frontend)

## 1. Какую задачу решаем

Правило нужно видеть и задавать там, где вводится план: какая статья
считается сама, от чего и сколько процентов.

## 2. Что будет результатом

| Часть | Что |
|---|---|
| Сетка | строка с правилом: метка «12,5 % от Выручки» под названием, ячейки только для чтения (подсказка «Считается по правилу»), стили DS |
| Панель | кнопка «Правило %» рядом с «Помощниками» (те же условия) → панель: статья (листья без правила), база (по умолчанию первая строка с «выручк»), процент → «Сохранить правило»; список правил пары со «Снять» |
| После записи | сетка перечитывается, сообщение «Правило сохранено» / «Правило снято» |
