# Stage 14: DS-пакет — план–факт: «Все показатели», «Итого», подсветка, мобильная (PR 5)

**Risk:** LOW–MEDIUM. Серверная страница `budget/plan_fact.html.twig` и её
контроллер: новые значения параметров `show=all` и `layout`, память вида в
сессии. Расчёт (`BudgetPlanFactBuilder`, `BudgetVariance`) и JSON
`/versions/{id}/plan-fact` не меняются. План пакета —
`docs/plan/ds-budget-ui.md` (пункты 20–23); фильтр проекта/ЦФО мультивыбором —
этап 15.

## 1. Какую задачу решаем

Экран «План–факт» показывает за раз один показатель (план, факт, отклонение или
%), а сравнить план и факт месяца рядом нельзя. Отклонение помечено только у
значимых ячеек и без подсветки; KPI показывает разницу в «%», а не в п. п.;
блок «С начала года» назван иначе, чем в макете; на телефоне таблица — 12
месяцев с прокруткой вбок. По макету (BUDGET-SPEC §6, refs 19–25) нужны режим
«Все показатели» с двумя раскладками, блок «Итого», подсветка > 10 % и мобильная
версия только с итогом.

## 4. Чек-лист приёмки

- [ ] Фильтры в одну строку; переключатели показателя и раскладки справа.
- [ ] «Все показатели» · Колонками: двухуровневая шапка закреплена, кварталы с «%».
- [ ] «Все показатели» · Строками: три строки на статью, метки метрик.
- [ ] Выбор показателя, раскладки, периода запоминается; раскладка по умолчанию — от периода.
- [ ] «Итого» из четырёх колонок в конце, не закреплён; «План года» сохранён.
- [ ] «+», ▲/▼ с текстом, подсветка > 10 %; KPI в п. п.
- [ ] Будущие месяцы: факт пуст, отклонения нет.
- [ ] Шеврон сворачивает группу.
- [ ] 390/360: только итог, «Откл.» и «%» видны без прокрутки; страница не прокручивается вбок.
- [ ] Тесты, гейты, внешнее ревью — зелёные.
