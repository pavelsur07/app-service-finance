# Stage 12: DS-пакет — вид сетки плана (PR 3)

**Risk:** LOW–MEDIUM. Только фронт острова `budget-grid` и токены легаси-слоя;
backend и контракты не меняются. План пакета — `docs/plan/ds-budget-ui.md`
(пункты 11–15, часть 27).

## 1. Какую задачу решаем

Сетка выглядит не по макету (refs 10, 11, 16–18): у групп, итогов и KPI нет
фонов из пакета, ширины колонок плавают, «не сохранено» закрашивает ячейку
вместо точки, у комментария синий, а не оранжевый уголок, загрузка — строка
текста без скелетона, ошибка загрузки без «Повторить», подсказки горячих
клавиш нет, комментарий — панель над сеткой, текст ошибки ввода не по SPEC.
Логика вставки из Excel и свёртки групп живёт внутри компонента без тестов.
