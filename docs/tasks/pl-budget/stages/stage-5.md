# Stage 5: помощники заполнения (экран 4 `ui-ux.md`)

**Risk:** MEDIUM
**Stage base commit:** `087daf484`

## 1. Какую задачу решаем

План по сотне статей на 12 месяцев вручную вводить долго. Нужны помощники,
которые заполняют выбранные статьи и месяцы одним действием — из факта
прошлого года, средним, распределением годовой суммы, копированием вправо и
процентом от другой статьи, — с предпросмотром и подтверждением перезаписи.

## 2. Что будет результатом

| Часть | Что |
|---|---|
| API | `POST /finance/budget/versions/{id}/fill` (`budget_version_fill`, `X-CSRF-Token` `budget_cells`, запись FINANCE): `{helper, project, center, categoryIds, months, params, apply, confirmOverwrite}` → `{cells, changed, overwrite, skipped, applied}`; без `apply` — только предпросмотр |
| Domain | `BudgetFillMath` — распределение с остатком копеек в декабрь, среднее и процент с округлением половины от нуля, знак по направлению статьи |
| Application | `BudgetFillPlanner` — считает ячейки помощника по текущему плану пары и факту (`FinanceFacade::getPlFactAmountsByMonth`); `FillBudgetCellsAction` — предпросмотр или запись через `SaveBudgetLinesAction` (одна транзакция, та же блокировка и проверка статуса) |
| Остров | меню «Помощники ▾» в панели сетки (черновик, право записи, выбрана пара) → окно: помощник, его поля, статьи (по умолчанию — все листы), месяцы; «Показать изменения» → «Будет изменено N ячеек» → «Применить» (при перезаписи — подтверждение) → «Заполнено N ячеек», сетка перечитывается |

Помощники:

| Код | Поля | Что делает |
|---|---|---|
| `last_year_fact` | статьи, месяцы | факт того же месяца прошлого года той же пары |
| `average` | N = 3/6/12, статьи, месяцы | среднее факта пары за N последних закрытых месяцев (по Москве) |
| `distribute` | годовая сумма, статьи | поровну на 12 месяцев, остаток копеек — в декабрь; в статье расхода сумма вводится положительной и пишется с минусом |
| `copy_right` | исходный месяц, статьи | сумма месяца — во все месяцы правее |
| `percent_of` | X %, статья-база, статьи, месяцы | X % от плана базы в том же месяце; знак — по направлению целевой статьи |

Правила:
- Меняются только выбранные листовые статьи и месяцы; ячейка, где новая
  сумма равна текущей, не считается изменённой.
- Строки с источником `sales_plan` не трогаются (`skipped`).
- Комментарий ячейки сохраняется.
- Перезапись непустых ячеек — только с `confirmOverwrite: true`, иначе 409
  `budget_fill_overwrite_unconfirmed` (защита от применения без
  подтверждения).
- Повтор безопасен: запись — upsert тем же ключом ячейки.
