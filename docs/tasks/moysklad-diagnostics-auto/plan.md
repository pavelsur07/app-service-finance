# МойСклад: диагностика маппинга обновляется сама

## Задача

Отчёт диагностики («Требует внимания», «Предложения») пересчитывался только кнопкой
«Обновить диагностику». После пакета, ручной связи или синхронизации отчёт помечался
устаревшим, пакет блокировался, а что нажать — было неочевидно (Владелец, 21.11.2026).

## Результат

- Устаревший или отсутствующий отчёт пересчитывается без участия пользователя:
  - сразу после пакета и после отмены пакета;
  - при открытии страницы, если данные изменились;
  - фоновым проходом `app:moysklad:mapping-diagnostics:refresh` каждые 5 минут
    (синхронизация МойСклада и маркетплейсов, ручные связи, настройки) — один механизм
    вместо подписки на каждое событие.
- Повторные запуски для тех же данных не плодят расчётов: `runId` = UUIDv5 от
  (кабинет, площадка, характеристика размера, отпечаток входа, последний завершённый отчёт).
- Пока идёт расчёт или пакет, страница обновляется сама (не прерывая открытый диалог,
  отмеченные строки и ввод).
- Кнопка — «Проверить заново», второстепенная.

Отдельный ночной запуск не нужен: проход каждые 5 минут его покрывает, а автоприменение
(05:30) отчёт не читает — сканирует кабинет само.

## Что выполнено

- [x] `MappingDiagnosticsRefresher::refreshIfStale()` — решение «нужен ли пересчёт» и dispatch.
- [x] Команда `app:moysklad:mapping-diagnostics:refresh`, cron `*/5`.
- [x] Пересчёт после финализации пакета и отмены (после commit; страховка — проход cron).
- [x] Страница: пересчёт при открытии устаревшего отчёта, автообновление, тексты, кнопка.
- [x] `ARCHITECTURE.md`: раздел, cron, Changelog.

## Чек-лист приёмки

- [x] Нет отчёта → проход запускает расчёт; свежий отчёт → не запускает.
- [x] Данные изменились → запускает; повтор прохода → тот же `runId`, второй расчёт не создаётся.
- [x] Идёт расчёт → не запускает; подключение выключено → не запускает; нет листингов → не запускает.
- [x] Характеристика размера берётся из последнего завершённого отчёта.
- [x] После пакета в очередь уходит пересчёт.
- [x] Открытие страницы с устаревшим отчётом ставит пересчёт; страница со статусом «идёт» обновляется сама.
- [x] Гейты: PHPStan, CS, twigcs, тесты MoySklad, `MessengerRoutingTest`.
