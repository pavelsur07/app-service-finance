# Handoff — типовой справочник счетов

## Сделано

- Шаблоны v4: 28 счетов (универсальный — 24), статья `INV_FULFILLMENT`.
- `SyncStandardChartAction` (замена `EnsureBalanceAccountsAction`): добор статей и счетов по коду, отметка `chart_sync` на версию.
- Ленивый добор: Баланс (`EnsureBalanceStructureAction`), «Склады» МойСклад (`BalanceFacade::ensureStandardChart`).
- Бэкфилл онбординга (`BackfillBalanceSetup`) считает и добирает тем же действием. Миграции нет.

## Внешнее ревью (Codex)

Принято: группы не воссоздаются, родитель проверяется по правилам `setParent()`, профиль — из аудита сида, бэкфилл
пишет добор строкой `balance_chart`. Отклонено: пересев после удаления всего дерева пользователем — прежнее поведение
ленивого сида, задачей не меняется.
