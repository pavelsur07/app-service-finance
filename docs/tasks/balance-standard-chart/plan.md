# Баланс: типовой справочник счетов

Утверждено Владельцем 25.11.2026. У компаний, созданных до 20.10.2026, в Балансе 0 счетов (структура статей есть) —
остатки и проводки без счетов невозможны (`balance_operation_lines.account_id NOT NULL`); склады МойСклад не к чему привязать.

## 1. Задача

Каждой конечной статье шаблона — типовой счёт со стабильным кодом; новая статья «Склады ФФ (фулфилмент)».
Справочник у всех компаний: новых — при создании, существующих — добором по коду.

## 2. Результат

- Шаблоны `marketplace.yaml` / `universal.yaml` версии 4: `accounts` у всех конечных статей (28 счетов маркетплейсного,
  без счетов маркетплейсов — универсального), статья `INV_FULFILLMENT` в «Запасах» после «Складов маркетплейсов».
- `SyncStandardChartAction` (вместо `EnsureBalanceAccountsAction`): под блокировкой книги добавляет недостающие статьи
  шаблона (родитель по коду; нет или в архиве — поддерево пропускается с warning) и недостающие счета (по коду счёта,
  статья по коду; нет/архив/не конечная — пропуск). Существующие статьи и счета не меняются.
- Однократно на версию шаблона: отметка `balance_audit_events` (book, `chart_sync`, `{template, version}`) — удалённое
  пользователем не возвращается при следующем открытии.
- Запуск: создание компании и бэкфилл онбординга (как сейчас); у существующих — лениво при открытии Баланса
  (`EnsureBalanceStructureAction`) и страницы «Склады» МойСклад (`BalanceFacade::ensureStandardChart`). Миграции нет.
