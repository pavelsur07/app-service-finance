# Рукопожатие v1

Обработка ВФ_Обмен отправляет HTTPS POST на `/api/onec/v1/handshake` с заголовками `Authorization: Bearer <token>` и `Content-Type: application/json`. Кодировка UTF-8. Лимиты — 10 МиБ и 60 рукопожатий за минуту на действующее подключение. Владелец получает токен в кабинете.

Пример полного снимка справочника организаций:

```json
{
  "base_id": "26c4bc0e-58e8-4411-84f8-e434b7387894",
  "config_name": "БухгалтерияПредприятия",
  "config_synonym": "Бухгалтерия предприятия",
  "config_version": "3.0.100.1",
  "platform_version": "8.3.24.1",
  "processor_version": "1.0",
  "organizations": [
    {"guid":"23c15967-e31e-49bb-afa7-8441c7784b63","name":"Тестовая организация","inn":null,"kpp":null}
  ]
}
```

`base_id` — постоянный UUID базы. При первом валидном рукопожатии он закрепляется за подключением. Имя конфигурации — идентификатор метаданных. Версии — строки из чисел, разделённых точками. В MVP поддерживается только «БухгалтерияПредприятия» редакции 3.0. Номера выше приведены для примера. `config_synonym` необязателен. Лимит строки названия или версии — 255 символов. Неизвестные поля игнорируются.

`organizations` — обязательный массив. В каждой записи обязательны уникальный в пределах базы UUID и название. ИНН и КПП передаются строками либо null. Пустая строка принимается как отсутствие значения. ИНН физического лица в справочнике не сохраняется. Отсутствие GUID в полном снимке помечает организацию исчезнувшей. При пустом массиве исчезнувшими становятся все организации базы. Если обработка не смогла прочитать полный справочник, ей следует повторить запрос после успешного чтения.

Ответ 200:

```json
{
  "connection_id": "01949708-b318-75a3-a4f6-aa776cba619a",
  "status": "connected",
  "server_time": "2026-11-25T12:00:00+00:00",
  "support": {"level":"supported","message":"Поддерживаемая редакция БП 3.0."},
  "organizations": [{"guid":"23c15967-e31e-49bb-afa7-8441c7784b63","mapped":false,"company_name":null}],
  "messages": []
}
```

Ответ содержит организации текущего снимка. Привязки к компаниям владельца и флаг загрузки сохраняются при обновлении. Новая организация появляется без привязки. `mapped` отражает наличие доступной компании, независимо от флага загрузки. При `support.level=warning` подключение получает статус `connected`, при `unsupported` — `error` и пояснение в ответе 200. Это действительное рукопожатие и оно также закрепляет базу.

Ошибка имеет форму `{"error":"base_conflict","message":"Подключение уже привязано к другой базе."}`.

| HTTP | Код | Что сделать обработке |
|---|---|---|
| 401 | invalid_token | Проверить токен подключения |
| 403 | disabled | Обратиться к владельцу подключения |
| 409 | base_conflict | Проверить базу и подключение. Повтор с теми же параметрами конфликт не разрешит |
| 413 | payload_too_large | Проверить размер отправляемого снимка |
| 422 | invalid_handshake | Исправить JSON или реквизиты и отправить полный снимок |
| 429 | rate_limited | Повторить через интервал из заголовка Retry-After в секундах |

При потере ответа повторить рукопожатие с тем же UUID базы. Ограничение уникальности базы действует внутри владельца. Два разных владельца могут независимо подключить базы с одинаковым UUID. Изменения v1 добавляющие.
