# Подключение 1С:Бухгалтерии предприятия 3.0

1. Владелец активной компании открывает «Компания → Подключить 1С» в кабинете или переходит на `/onec/connections/new`.
2. Вводит название базы. В ответе появляются адрес рукопожатия и одноразово показываемый токен. Их нужно сохранить в настройках обработки ВФ_Обмен.
3. Обработка отправляет параметры базы и полный справочник организаций по [контракту handshake](api-contract.md). Поле support показывает совместимость, organizations — какие организации уже имеют привязку.
4. После изменения справочника обработка повторяет рукопожатие. Если вернулся 409, проверьте, что токен принадлежит этой базе.

PHP-модуль находится в `site/src/OneC`. Данные о базе и времени рукопожатия хранятся в `onec_connection`, организации — в `onec_organization`. Аудит создания записывается в общий журнал с контекстом активной компании и ID владельца.

Минимальные рекомендуемая версия конфигурации и допустимая версия обработки задаются параметрами `onec.minimum_config_version` и `onec.minimum_processor_version` в `site/config/services.yaml`. Пустое значение означает отсутствие подтверждённого нижнего порога. Проверка семейства и редакции действует всегда.

Текущий этап заканчивается рукопожатием. Приём счетов, пользовательская настройка привязок и перепроведение пакетов входят в последующие этапы.
