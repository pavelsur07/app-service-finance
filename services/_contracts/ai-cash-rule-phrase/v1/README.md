# Поиск фразы для автоправила ДДС

Тип задачи `cash_rule_phrase`, конверт `ai-task/v1`. Symfony передаёт до 60 примеров одного контрагента и направления. Признак `target` отмечает вручную выбранную статью. Цифры и знаки заменены на `#`, слова вне общего словаря платежей заменены на локальные псевдонимы. Идентификаторы операций, контрагента и статьи в payload отсутствуют.

Модель возвращает повторяющийся фрагмент или `null` при недостатке данных. Symfony сверяет фрагмент с историей компании перед предзаполнением черновика. Финансист проверяет и подтверждает правило.
